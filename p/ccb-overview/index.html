기초 — 개요·터미널·CLAUDE.md

이 자료는 "Claude Code 기초 / 황민호" 실습 강의를 영상 순서대로 정리한 것입니다. 개발자가 아닌 분들에게 터미널은 낯선 환경이지만, 딱 하나의 고비 — "폴더를 만들고 그 위치에서 claude 를 실행하는 것" 만 넘으면 그 다음부터는 AI가 대부분의 일을 대신 해 줍니다. 오늘의 목표는 터미널과 친숙해지는 것입니다.

이 강의로 할 수 있게 되는 것

  • 터미널에서 폴더를 만들고 Claude Code를 실행한다.
  • CLAUDE.md 로 나만의 작업 지침을 준다.
  • 웹 조사 → 파일 저장 → 웹사이트 생성까지 한 번에 시킨다.
  • 반복 작업을 스킬(Skill) 로, 전문 작업을 에이전트(Agent) 로 만들어 재사용한다.
  • 플러그인을 설치해 PDF·PPT·엑셀 문서를 다룬다.
  • 사용량·컨텍스트·세션을 관리해 품질과 비용을 조절한다.

한 걸음 더 — 하네스(Harness)

프롬프트 몇 줄로 팀 구성부터 집필·삽화·변환·웹사이트까지 약 1시간에 완성됩니다.

기초 고비를 넘으면 그 다음에는 하네스(Harness) 가 기다립니다. 하네스를 쓰면 몇 줄의 프롬프트만으로 200~300페이지가 넘는 책 한 권을 만들어 낼 수 있습니다. 강의에서 보여준 예시는 이렇게 동작합니다.

  • 책을 쓸 에이전트 여러 개(예: 5개)를 만든다.
  • 리서치 에이전트가 책의 소스를 준비한다.
  • 에이전트들이 병렬로 집필하고 완료 보고를 한다.
  • 필요한 삽화 이미지까지 생성해 정확한 위치에 삽입한다.
  • 결과물을 마크다운·PDF로 변환하고, 페이지를 넘겨 보는 웹사이트까지 만든다. — 총 소요 약 1시간.

즉, "클로드 코드 시작하는 사람들을 위한 나만의 책"도 직접 만들 수 있습니다. 하네스 자체는 이후 별도 세션에서 다룹니다.

Claude Code란 무엇인가

Claude Code는 내 로컬 환경(내 PC)에서 돌아가는 AI 에이전트라고 생각하면 됩니다. 웹 채팅과 달리 내 컴퓨터의 파일을 직접 읽고 수정하고, 명령을 실행하며 일을 처리합니다. 작업은 프로젝트마다 폴더 하나를 만들고 그 폴더 안에서 진행합니다. Windows에서는 보통 PowerShell 터미널에서 실행합니다.

기존 서비스와의 차이

형태특징자유도
웹 브라우저(Claude·ChatGPT·Gemini)브라우저 안의 제약된 환경에서 AI 사용. 파일을 일일이 업로드해야 함가장 제한적
Claude 데스크톱 앱로컬에서 동작하지만 터미널 대비 제약이 있음중간
Claude Code (터미널)실행한 폴더의 파일에 직접 접근. 내가 원하는 대로 자유롭게 작업가장 자유로움

터미널 환경에 조금만 익숙해지면, 평소 AI 채팅을 쓰듯이 훨씬 자유롭게 사용할 수 있습니다.

시연 — 회의록 세 개를 한 보고서로

파일 목록을 알려 주지 않아도 스스로 탐색·읽기·분석해 보고서를 만듭니다.

회의록 파일 3개가 든 폴더에서 Claude Code를 실행하고 이렇게 요청합니다.

이 회의록 세 개를 합쳐서 한 개의 보고서로 요약해줘. 한국어로.

여기서 핵심은 어떤 파일이 있는지 알려 주지 않았다는 점입니다. 웹 채팅이라면 파일을 직접 업로드해야 하지만, Claude Code는

  • 현재 폴더에 어떤 파일이 있는지 먼저 탐색(search) 하고,
  • 그 파일들을 하나하나 읽어 들이며,
  • 내용을 분석한 뒤 결과(보고서)를 만들어 줍니다.

즉, "실행한 위치의 폴더"가 곧 작업 공간이 되고, 그 안의 파일을 스스로 다룹니다.

기억할 점 Claude Code는 claude 를 실행한 그 폴더 전체에 접근합니다. 그래서 프로젝트별로 폴더를 나누고, 작업할 폴더 안에서 실행하는 습관이 중요합니다.

터미널 기초 명령어

터미널이 낯설어도 괜찮습니다. 우리의 목표는 딱 "새 폴더를 만들고 그 위치로 가서 claude 를 실행" 하는 것까지입니다. 그 다음은 AI가 다 해 줍니다. Windows는 PowerShell 을 실행하면 보통 사용자 폴더에서 시작합니다.

딱 네 가지만 기억하세요

명령뜻하는 일
pwdprint working directory지금 내가 어느 폴더에 있는지 보여줌
cd <폴더>change directory다른 폴더로 이동 (예: cd Downloads)
mkdir <이름>make directory새 폴더 만들기 (예: mkdir kist-test)
claude—현재 폴더에서 Claude Code 실행

실습 순서

새 폴더를 만들고 그 위치로 이동해 claude 를 실행하는 것이 오늘의 관문입니다.
# 1. 지금 위치 확인
pwd
# 2. 다운로드 폴더로 이동
cd Downloads
# 3. 새 폴더 만들기
mkdir kist-test
# 4. 만든 폴더로 이동
cd kist-test
# 5. 그 폴더에서 Claude Code 실행
claude

이렇게 새로 만든 폴더에서 claude 를 실행하면, 이제 Claude Code는 그 폴더 안에서 모든 작업을 하게 됩니다.

오늘의 관문 "폴더 만들기 → 그 위치로 이동 → claude 실행" — 여기까지만 넘어오면 이후로는 AI의 도움을 받을 수 있습니다. 막히면 주저 말고 도움을 요청하세요.

CLAUDE.md — 작업 지침 파일

Claude Code는 항상 참조하는 파일로 CLAUDE.md 라는 마크다운 파일을 사용합니다. AI에게 어떤 명령을 하든 항상 함께 포함되는 파일이라고 생각하면 됩니다. 그래서 너무 길지 않게, 중요한 내용을 명료하게 담아야 합니다.

네 가지 레이어

같은 CLAUDE.md라도 위치에 따라 적용 범위가 다르며, 아래 계층일수록 우선합니다.

같은 CLAUDE.md 라도 어디에 두느냐에 따라 적용 범위가 달라집니다.

  • 회사(매니지드) — 회사 안의 모든 멤버에게 적용.
  • 유저 전역 — 내 PC에서 어떤 프로젝트를 하든 항상 적용.
  • 프로젝트 — 해당 프로젝트에서만 적용(동료와 공유).
  • 프로젝트 로컬 — 프로젝트 안이지만 공유하지 않는, 내 PC만을 위한 지침.

실습 — 지침 만들기

새 폴더에서 claude 를 실행한 뒤, 이렇게 요청해 CLAUDE.md 를 만듭니다.

이 폴더에 CLAUDE.md 파일을 만들어줘.
지침: 답변은 항상 한글로 작성하고,
새로 만드는 파일 이름에는 항상 _new 를 붙여줘.

파일이 만들어지면 그 안에는 방금 준 지침("한글로 작성한다", "새 파일에 _new 를 붙인다")이 기록됩니다. 이후의 모든 작업은 이 폴더 하위에서 항상 이 지침을 따릅니다. 예를 들어 "간단한 시를 텍스트 파일로 저장해줘" 라고 하면, 결과는 한글로 작성되고 파일명에는 _new 가 붙습니다.

무엇을 담으면 좋은가

  • 원본 파일을 수정하지 못하게 하는 규칙
  • 코드(예: Python) 작성 시 지켜야 할 규칙
  • 출력 형식 · 파일 저장 방식
  • 작성물의 문체 · 언어
팁 CLAUDE.md 는 AI에게 만들게 해도 되고, 직접 열어 수정해도 됩니다. Windows에서는 프롬프트에 줄바꿈이 잘 안 될 수 있는데, 줄바꿈 없이 쭉 이어서 써도 무방합니다.

여기까지가 기초입니다 — 폴더를 만들고, 실행하고, 지침을 심었습니다. 다음 편 실습에서는 웹 조사부터 디자인 시스템 추출, 논문 정리까지 실제 작업을 한 흐름으로 돌려 봅니다.
