강의 개요와 목표

이 자료는 "Claude Code 기초 / 황민호" 실습 강의를 영상 순서대로 정리한 것입니다. 개발자가 아닌 분들에게 터미널은 낯선 환경이지만, 딱 하나의 고비 — "폴더를 만들고 그 위치에서 claude 를 실행하는 것" 만 넘으면 그 다음부터는 AI가 대부분의 일을 대신 해 줍니다. 오늘의 목표는 터미널과 친숙해지는 것입니다.

이 강의로 할 수 있게 되는 것

  • 터미널에서 폴더를 만들고 Claude Code를 실행한다.
  • CLAUDE.md 로 나만의 작업 지침을 준다.
  • 웹 조사 → 파일 저장 → 웹사이트 생성까지 한 번에 시킨다.
  • 반복 작업을 스킬(Skill) 로, 전문 작업을 에이전트(Agent) 로 만들어 재사용한다.
  • 플러그인을 설치해 PDF·PPT·엑셀 문서를 다룬다.
  • 사용량·컨텍스트·세션을 관리해 품질과 비용을 조절한다.

한 걸음 더 — 하네스(Harness)

프롬프트 몇 줄로 팀 구성부터 집필·삽화·변환·웹사이트까지 약 1시간에 완성됩니다.

기초 고비를 넘으면 그 다음에는 하네스(Harness) 가 기다립니다. 하네스를 쓰면 몇 줄의 프롬프트만으로 200~300페이지가 넘는 책 한 권을 만들어 낼 수 있습니다. 강의에서 보여준 예시는 이렇게 동작합니다.

  • 책을 쓸 에이전트 여러 개(예: 5개)를 만든다.
  • 리서치 에이전트가 책의 소스를 준비한다.
  • 에이전트들이 병렬로 집필하고 완료 보고를 한다.
  • 필요한 삽화 이미지까지 생성해 정확한 위치에 삽입한다.
  • 결과물을 마크다운·PDF로 변환하고, 페이지를 넘겨 보는 웹사이트까지 만든다. — 총 소요 약 1시간.

즉, "클로드 코드 시작하는 사람들을 위한 나만의 책"도 직접 만들 수 있습니다. 하네스 자체는 이후 별도 세션에서 다룹니다.
