온보딩 (실습)

스타터 킷에는 온보딩 스킬이 들어 있어, /onboard(또는 "온보딩 해줘") 한마디로 개인 맞춤 세팅이 시작됩니다.

릴리스 받기부터 그래프 뷰로 볼트를 여는 순간까지 — /onboard 한 번으로 개인 맞춤 세팅.

준비 — 릴리스 받기

  • 강의에서 안내한 LLM Wiki 페이지(GitHub 레포지토리) 에서 최신 릴리스(예: 1.7.0) 파일을 다운로드합니다.
  • zip을 풀면 폴더 하나(= 위키 볼트, 곧 Obsidian 볼트) 가 생깁니다.
  • 실제로 쓸 경로(내 문서·바탕화면 등)에 이 폴더를 먼저 위치시킵니다.

온보딩 실행

# 폴더 경로 복사 — Windows: Ctrl+Shift+C / Mac: Cmd+Option+C
# 그 폴더에서 Claude Code 실행 후
/onboard        # 또는 "온보딩 해줘"

정해진 질문들이 이어집니다 — 어떤 목적으로 쓰는가, 뭐라고 불러야 하는가, 메인 볼트와 연결할 것인가 등. 컨텍스트를 많이 줄수록 더 똑똑해지므로 성의껏 답합니다. (약 5분 소요)

  • 메인 볼트가 있으면 연결 — 인공지능이 위키를 만들 때 내가 썼던 노트들을 참조합니다.
  • 없으면 단독으로 시작해도 됩니다.

Obsidian에서 볼트 열기

  1. Obsidian 왼쪽 아래 → 볼트 관리 → Open folder as vault 로 그 폴더를 엽니다.
  2. 왼쪽 아래에 내 폴더명이 맞는지 확인합니다.
  3. Ctrl/Cmd + G 로 그래프 뷰를 열면 임베딩된 노트 관계가 보입니다.
깔끔하게 시작하려면 예시 데이터 없이 시작하고 싶으면 concept·entity·article 폴더의 예시 파일만 지우면 됩니다. 코덱스용 파일도 준비돼 있지만, Claude Code에서 쓰는 편이 더 유리합니다.
