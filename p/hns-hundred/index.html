하네스 100

일상과 업무에 필요한 100가지 사례의 하네스를 미리 구성해 공개한 모음입니다. ("하네스 100" 으로 검색, 한국어 버전 제공) 분야는 다음과 같습니다.

  • 콘텐츠 제작(유튜브 기획·팟캐스트·뉴스레터·온라인 강의)
  • 소프트웨어 개발, 데이터 분석
  • 비즈니스 전략(스타트업 아이디어 검증~피칭, 정부 지원 사업계획서)
  • 교육·학습, 법률(위험 평가), 건강·라이프스타일, 커뮤니케이션, 운영 프로세스, 전문 도메인

예를 들어 "정부 지원 사업계획서 작성"에는 공고문 분석 전문가 · 사업성 파트 작성자 · 예산 편성 도우미 같은 에이전트와 관련 스킬이 미리 만들어져 있습니다. 사용자들은 비슷한 구성을 찾아 커스터마이징하는 식으로 활용합니다.

실습해 볼 만한 10가지 아이디어

  1. 논문 PDF → 한 장 요약 카드
  2. 실험 데이터 정제 → 시각화 → 리포트 파이프라인
  3. 선행 기술 특허 조사(강력한 리서치 기반)
  4. 연구계획서 작성
  5. 시뮬레이션 환경 세팅·검증
  6. 레거시 코드 리팩토링
  7. 문서화
  8. 발표자료 통합 제작
  9. 국가 과제 보고서 작성
  10. 연구 데이터 큐레이션

가져올 사이트가 API 연동이 필요하면, 그 자체를 스킬로 만들어 에이전트에 연결하면 됩니다.

성능 측정 — 수치화

실제 측정값이 아니라 경향입니다 — 난이도가 오를수록 하네스의 격차가 커집니다.

체감 효과를 수치로 확인하기 위해, 난이도별(기초·중급·고급) 개발 과제 15개를 하네스 없을 때 vs 있을 때로 비교하고, 최종 코드를 LLM judge 로 평가했습니다.

결과 평균 약 60% 성능 향상, 하네스 구성 시 승률 100%. 특히 과제가 어려울수록 — 도구 하나만 쓰면 점수 하락폭이 컸지만, 하네스는 품질이 유지되는 효과가 있었습니다.
수치 참고 위 수치는 공개 벤치마크가 아니라 강연자의 자체 측정치입니다. 참고로 Anthropic도 멀티에이전트 구성이 단일 에이전트 대비 내부 평가에서 90.2% 성능 향상을 보였다고 발표한 바 있습니다(multi-agent research system).
