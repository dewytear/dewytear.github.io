OMC 소개

oh-my-claudecode(이하 OMC)는 Claude Code에 자율 실행, 멀티 에이전트 협업, 자동 검증 기능을 더해주는 플러그인입니다.

OMC는 Claude Code에 자율 실행·멀티 에이전트·자동 검증을 명령어 한 줄로 더합니다.

세 가지 개념

  • Claude Code란 — 터미널이나 IDE에서 Claude에게 코딩 작업을 맡기는 CLI 도구입니다. 파일을 읽고 수정하고, 명령을 실행하며 개발을 돕습니다.
  • 플러그인이란 — Claude Code에 새 기능을 더하는 확장팩입니다. 한 번 설치하면 전용 명령어와 동작이 추가됩니다.
  • OMC가 더하는 것 — "끝까지 알아서 구현", "여러 작업자가 분담", "작업 후 자동 검증" 같은 고급 작업 방식을 명령어 한 줄로 쓰게 해줍니다.

이 문서는 로컬 환경에서 직접 설치해 일부 검증 및 공식 문서·릴리스 노트·플러그인 문서를 대조해 작성한 요약본입니다. Windows PowerShell, WSL2, macOS, Linux에 따라 일부 명령어와 동작이 달라질 수 있어, 환경에 의존적인 항목은 별도로 구분해 표시했습니다. 기준 버전은 v4.15.2(2026-07-05 확인)입니다. 릴리스가 월 3~5회로 잦은 편이라, 세부 동작은 읽는 시점의 최신 릴리스 노트와 다를 수 있습니다.
