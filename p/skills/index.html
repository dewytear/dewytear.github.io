확장 기능 — Skills · MCP · Hooks

Claude Code를 기본기만으로 써도 충분히 일하지만, 팀과 프로젝트에 맞춰 늘리는 순간부터 진가가 나옵니다. 확장 통로는 세 갈래입니다. 반복되는 노하우를 패키지로 묶는 스킬, 외부 시스템으로 손을 뻗는 MCP 서버, 정해진 시점마다 어김없이 실행되는 훅 — 셋은 성격이 달라서 서로를 대신하지 못하고, 함께 쓸 때 가장 잘 맞물립니다.

Skills — 재사용 가능한 능력

스킬(Skill)은 특정 작업을 위한 전문 지식과 워크플로를 Claude Code에 부여하는, 재사용 가능한 패키지 형태의 능력입니다. 지시문(선택적으로 스크립트·리소스까지)을 하나로 묶어 두면, 요청이 그 스킬의 용도와 맞을 때 Claude가 필요한 만큼만 불러와 씁니다. 스킬은 여느 슬래시 명령처럼 / 뒤에 스킬 이름을 쳐서 직접 부르거나, Claude Code가 작업을 알아보고 관련 스킬을 자동으로 발동하기도 합니다. 스킬이 할 수 있는 일의 예:

  • 현재 diff에 대한 구조화된 코드 리뷰 실행
  • 여러 출처를 뒤지는 심층 리서치와 출처 표기된 보고서 작성
  • 훅·키바인딩·설정의 설계와 구성
  • 일관된 디자인 시스템을 따르는 데이터 시각화 제작
자세한 노하우가 매번 치는 메시지가 아니라 스킬 안에 살기 때문에, 프롬프트는 짧아지고 결과는 일관돼집니다. Claude Code에 기본 탑재된 스킬을 쓰거나, 플러그인으로 설치하거나, 직접 만들 수 있습니다.

MCP 서버 — 바깥세상과 연결

MCP(Model Context Protocol)는 AI 어시스턴트를 외부 도구·데이터 소스와 연결하기 위한 개방 표준입니다. Claude Code에 MCP 서버를 붙이면 로컬 파일 너머까지 손이 닿게 됩니다 — 데이터베이스, 이슈 트래커, 클라우드 서비스, 브라우저 등. MCP 서버가 연결되면 그 서버의 도구들이 내장 도구와 똑같이 Claude Code에서 쓸 수 있게 됩니다. 예를 들어 적절한 서버가 구성되어 있으면 Claude는:

  • GitHub 이슈·PR을 읽고 만들 수 있습니다.
  • 데이터베이스나 사내 API에 질의할 수 있습니다.
  • 이메일·캘린더·문서를 검색할 수 있습니다.
  • 헤드리스 브라우저를 조작해 웹 페이지를 테스트할 수 있습니다.
서버 관리는 claude mcp 명령(add, list, remove)이나 설정 파일로 합니다. 각 서버는 자신이 노출하는 도구를 선언하고, Claude Code는 그중 규칙에 걸리는 행동만 멈춰 세웁니다 — 2026년 8월 14일부터 auto 모드가 기본값이 되면서, 매번 허락을 묻는 방식 대신 미리 적어 둔 거부 규칙과 안전 검사가 판정을 맡습니다(묻지 않는 기본값). 외부 시스템에 닿는 범위는 그 규칙과 설정으로 통제합니다.

Hooks — 매번 실행되는 자동화

훅(Hook)은 Claude Code가 수명주기의 특정 시점마다 자동으로 실행하는, 사용자가 정의한 셸 명령입니다. 규칙을 강제하고 동작을 결정론적으로 자동화할 수 있습니다 — 하네스가 직접 실행하므로 Claude가 기억할 때만이 아니라 매번 실행됩니다. 훅은 settings.json에 설정하며, 다음과 같은 이벤트에 붙습니다:

  • PreToolUse — 도구 실행 직전 (예: 보호된 파일의 수정 차단)
  • PostToolUse — 도구 실행 직후 (예: 방금 고친 파일을 자동 포맷·린트)
  • SessionStart — 세션이 시작될 때 (예: 테스트가 돌 수 있게 의존성 설치)
  • Stop — Claude가 응답을 마쳤을 때 (예: 알림 발송)
대표적인 쓰임새는 수정할 때마다 포매터 실행, 커밋 전 테스트 스위트 실행, 민감한 경로 보호, 긴 작업이 끝나면 데스크톱 알림 보내기 등입니다. 훅은 결국 그냥 셸 명령이므로, 프로젝트가 이미 쓰는 어떤 도구와도 Claude Code를 이어 붙일 수 있습니다. 스킬이 아는 법을, MCP가 닿는 곳을 늘린다면, 훅은 지켜지는 규칙을 만듭니다. 셋을 어떻게 조합하는지는 Claude Code 튜토리얼에서 손으로 익힐 수 있습니다.
