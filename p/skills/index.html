Skills

스킬(Skill)은 특정 작업을 위한 전문 지식과 워크플로를 Claude Code에 부여하는, 재사용 가능한 패키지 형태의 능력입니다. 지시문(선택적으로 스크립트·리소스까지)을 하나로 묶어 두면, 요청이 그 스킬의 용도와 맞을 때 Claude가 필요한 만큼만 불러와 씁니다. 스킬은 여느 슬래시 명령처럼 / 뒤에 스킬 이름을 쳐서 직접 부르거나, Claude Code가 작업을 알아보고 관련 스킬을 자동으로 발동하기도 합니다. 스킬이 할 수 있는 일의 예:

  • 현재 diff에 대한 구조화된 코드 리뷰 실행
  • 여러 출처를 뒤지는 심층 리서치와 출처 표기된 보고서 작성
  • 훅·키바인딩·설정의 설계와 구성
  • 일관된 디자인 시스템을 따르는 데이터 시각화 제작
자세한 노하우가 매번 치는 메시지가 아니라 스킬 안에 살기 때문에, 프롬프트는 짧아지고 결과는 일관돼집니다. Claude Code에 기본 탑재된 스킬을 쓰거나, 플러그인으로 설치하거나, 직접 만들 수 있습니다.
