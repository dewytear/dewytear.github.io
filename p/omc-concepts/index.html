핵심 용어

OMC 문서에는 다음 용어가 자주 나옵니다. 사전에 이해해두면 이후 내용이 훨씬 쉽게 읽힙니다.

  • 슬래시 명령어 — Claude Code 입력창에 / 로 시작하는 특수 명령입니다. 일반 대화 대신 정해진 기능을 바로 실행합니다. 예: /plugin install ...
  • 네임스페이스 — 명령어 앞에 플러그인 이름이 붙는 형식입니다. 다른 플러그인과 이름이 겹치지 않게 해줍니다. 예: /oh-my-claudecode:autopilot
  • 에이전트(Agent) — 특정 역할을 맡은 AI 작업자입니다. 탐색·구현·검증처럼 역할이 나뉘어 있어, 큰 작업을 분담시킬 수 있습니다. 예: explore, executor, qa-tester
  • 스킬(Skill) — 하나의 작업을 수행하는 기능 단위입니다. 자율 실행이나 반복 수행 같은 동작이 스킬로 제공됩니다. 예: autopilot, ralph, skillify
  • Hook(훅) — 정해진 시점(예: 파일 수정 전후)에 자동으로 끼어들어 실행되는 동작입니다. 키워드 감지나 완료 검증 등에 쓰입니다. 예: PreToolUse, PostToolUse
  • 프로젝트 메모리 — AI가 프로젝트 구조를 기억하도록 정리해 둔 문서입니다. 매번 처음부터 탐색하는 비용을 줄여줍니다. 예: deepinit, AGENTS.md
