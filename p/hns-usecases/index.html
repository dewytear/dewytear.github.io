소설 — "에이전트 시대"

SF 소설을 쓰자고 했더니, 소설을 쓰기 위한 에이전트와 스킬이 만들어졌습니다.

  • 캐릭터 설계 에이전트 — 인물 창조·발전.
  • 세계관 설계 에이전트 — 배경(예: 2028~2032년)의 기술 체계·사회 구조 구축.
  • 과학자문 에이전트 — 원고의 과학적 오류·비현실 요소를 식별·강화.
  • 브레인스토밍·과학 검증 등은 스킬로 만들어 에이전트에 주입.

흐름: 한 줄 로그라인 → 전체 플롯 아웃라인(챕터별 긴장·복선 회수 계획) → 캐릭터·세계관 재료 사전 생성 → 챕터별 내용이 정해져 있어 병렬 집필 → 과학 검증(예: 무작위 문자열을 실제 알고리즘상 해석 가능한 문자열로 교정해 반영).

웹툰

같은 소설로 웹툰을 만들자 웹툰 아티스트 에이전트가 생기고, 이상한 컷을 잡아내는 품질 검증 에이전트(캐릭터 일관성·말풍선·오류 확인)가 추가됐습니다. 검증 실패 시 다시 그리도록 루프가 만들어져, "2장부터 12장까지 그려줘" 한 번으로 진행됐습니다.
