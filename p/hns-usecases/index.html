활용과 확장 — 사례·하네스 100·도구

하네스는 개발에만 쓰기 아까울 만큼 활용 폭이 넓습니다. 강사가 만들어 본 사례들입니다.

소설 — "에이전트 시대"

SF 소설을 쓰자고 했더니, 소설을 쓰기 위한 에이전트와 스킬이 만들어졌습니다.

  • 캐릭터 설계 에이전트 — 인물 창조·발전.
  • 세계관 설계 에이전트 — 배경(예: 2028~2032년)의 기술 체계·사회 구조 구축.
  • 과학자문 에이전트 — 원고의 과학적 오류·비현실 요소를 식별·강화.
  • 브레인스토밍·과학 검증 등은 스킬로 만들어 에이전트에 주입.

흐름: 한 줄 로그라인 → 전체 플롯 아웃라인(챕터별 긴장·복선 회수 계획) → 캐릭터·세계관 재료 사전 생성 → 챕터별 내용이 정해져 있어 병렬 집필 → 과학 검증(예: 무작위 문자열을 실제 알고리즘상 해석 가능한 문자열로 교정해 반영).

웹툰

같은 소설로 웹툰을 만들자 웹툰 아티스트 에이전트가 생기고, 이상한 컷을 잡아내는 품질 검증 에이전트(캐릭터 일관성·말풍선·오류 확인)가 추가됐습니다. 검증 실패 시 다시 그리도록 루프가 만들어져, "2장부터 12장까지 그려줘" 한 번으로 진행됐습니다.

그 밖의 사례

  • 온보딩 가이드 — 2022년 12월 ChatGPT 이후의 일들을 조사·정리.
  • 마크다운 뷰어(mdview.kr) — 하네스로 40분~1시간 만에 첫 배포. HWP 가져오기 지원, 문서는 서버 전송 없이 브라우저에만 저장.
  • 국가 AI 데이터센터 조사 — 수치·타임라인 정리에, 비판/긍정 언론 분석과 문제점(사업성·GPU 수급·전력·데이터 주권)까지. 출처 기반이라 할루시네이션 대폭 감소.
  • 뉴스 신문 스타일 정리, 시험 출제 서비스 기획 리서치, UI 템플릿 여러 개 생성해 비교(눈에 보이는 성과물로 기획).
공통점 "그냥 써줘"가 아니라, 그 일을 하기 위한 에이전트·스킬·워크플로우가 먼저 만들어지고, 사전 계획된 재료와 검증 루프 위에서 결과물이 나옵니다.

하네스 100 · 실습 아이디어 · 성능

하네스 100

일상과 업무에 필요한 100가지 사례의 하네스를 미리 구성해 공개한 모음입니다. ("하네스 100" 으로 검색, 한국어 버전 제공) 분야는 다음과 같습니다.

  • 콘텐츠 제작(유튜브 기획·팟캐스트·뉴스레터·온라인 강의)
  • 소프트웨어 개발, 데이터 분석
  • 비즈니스 전략(스타트업 아이디어 검증~피칭, 정부 지원 사업계획서)
  • 교육·학습, 법률(위험 평가), 건강·라이프스타일, 커뮤니케이션, 운영 프로세스, 전문 도메인

예를 들어 "정부 지원 사업계획서 작성"에는 공고문 분석 전문가 · 사업성 파트 작성자 · 예산 편성 도우미 같은 에이전트와 관련 스킬이 미리 만들어져 있습니다. 사용자들은 비슷한 구성을 찾아 커스터마이징하는 식으로 활용합니다.

실습해 볼 만한 10가지 아이디어

  1. 논문 PDF → 한 장 요약 카드
  2. 실험 데이터 정제 → 시각화 → 리포트 파이프라인
  3. 선행 기술 특허 조사(강력한 리서치 기반)
  4. 연구계획서 작성
  5. 시뮬레이션 환경 세팅·검증
  6. 레거시 코드 리팩토링
  7. 문서화
  8. 발표자료 통합 제작
  9. 국가 과제 보고서 작성
  10. 연구 데이터 큐레이션

가져올 사이트가 API 연동이 필요하면, 그 자체를 스킬로 만들어 에이전트에 연결하면 됩니다.

성능 측정 — 수치화

실제 측정값이 아니라 경향입니다 — 난이도가 오를수록 하네스의 격차가 커집니다.

체감 효과를 수치로 확인하기 위해, 난이도별(기초·중급·고급) 개발 과제 15개를 하네스 없을 때 vs 있을 때로 비교하고, 최종 코드를 LLM judge 로 평가했습니다.

결과 평균 약 60% 성능 향상, 하네스 구성 시 승률 100%. 특히 과제가 어려울수록 — 도구 하나만 쓰면 점수 하락폭이 컸지만, 하네스는 품질이 유지되는 효과가 있었습니다.
수치 참고 위 수치는 공개 벤치마크가 아니라 강연자의 자체 측정치입니다. 참고로 Anthropic도 멀티에이전트 구성이 단일 에이전트 대비 내부 평가에서 90.2% 성능 향상을 보였다고 발표한 바 있습니다(multi-agent research system).

도구 확장과 마무리

Claude Code vs Gemini(Antigravity)

AI 도구는 엎치락뒤치락 발전합니다. 현재는 Claude Code가 가장 좋지만, 강사는 Antigravity CLI(agy 명령)도 병행합니다.

항목Claude CodeAntigravity (Gemini 3.5 Flash)
생성 속도초당 약 50~60 토큰약 4배 빠름
이미지 생성모델 자체는 불가(codex-image 스킬로 가능)가능(나노바나나)
결과 퀄리티강사 소감상 더 예쁘게 나옴빠르지만 다듬음 필요

모델별 성능·속도·가격은 Artificial Analysis 사이트에서 비교할 수 있습니다. (Opus·GPT 5.5는 가격이 비싼 편)

수치 참고 표의 "약 4배 빠름"은 공개 벤치마크가 아니라 강사의 경험치입니다. 참고로 병렬 에이전트 구성의 속도 향상은 작업의 독립성에 따라 약 2배에서 최대 10배까지 보고됩니다(Anthropic은 복잡한 쿼리에서 소요 시간 90% 단축을 보고).

Codex CLI로 2차 검증

단일 모델 검증은 편향될 수 있어, Codex CLI(GPT 5.5) 를 연결하는 스킬로 QA 에이전트에 2차 검증을 붙일 수 있습니다.

# 구성 변경이 필요할 때 /harness 로 지시
/harness QA 에이전트는 Codex CLI를 이용해 검증하도록 수정
  • QA 에이전트가 이중 검증 프로토콜로 업데이트 — Claude로 1차, Codex CLI로 2차, 두 의견을 통합.
  • 워크플로우를 알아야 하므로 오케스트레이터도 함께 갱신됩니다.
  • 이런 하네스 구성 변경 이력은 CLAUDE.md 에 기록됩니다.

실행 환경도 조직 안으로 — 셀프호스트 러너

확장되는 것은 도구만이 아닙니다. 2026년 8월 공개 베타로 열린 셀프호스트 환경을 쓰면 원격 세션이 Anthropic 클라우드가 아니라 조직의 인프라에서 돌아요 — claude self-hosted-runner 한 명령으로 내 머신이 실행층이 되고, 하네스가 내부망의 서비스·보안 통제 옆에서 일합니다. 데이터 상주 규제 때문에 도입이 막혀 있던 조직에 열린 통로입니다(8월의 릴리스들).

에이전트 1:1 (원온원)

특정 에이전트와 커피챗하듯 대화하며 재설계할 수 있는 기능도 있습니다. 에이전트 목록에서 상대를 고르면 그 에이전트가 자기 역할·원칙을 설명하고 "어떤 부분을 수정할까요?"라고 물어봅니다.

마무리 — 사람이 집중할 것

에이전트가 많은 일을 대신하는 초입에서, 사람은 다음에 집중해야 합니다: 목표 설정, 맥락적 판단, 품질 기준, 책임·윤리, 좋은 질문, 시스템적 사고, 도메인 전문성, 평가·피드백, AI 협업.

Q&A 요점 · 에이전트가 /agents 에 안 뜨면 리스트만 안 보일 뿐 재시작하면 로딩됨(동적 로딩 실패 시 일반 서브에이전트로 뜨기도).
· 오토 모드 — Shift+Tab 으로 auto/accept/plan 모드 전환. 오토 모드는 권한을 매번 묻지 않아 더 자율적으로 동작(중간에 언제든 전환 가능). 안 보이면 클로드 코드 업데이트 필요(native 설치는 자동 업데이트, npm 설치는 수동).
· 2026-08-14부터 오토 모드가 기본값(Pro·Max·Team 신규 세션). 묻지 않는 대신 하드 디나이 규칙과 프롬프트 인젝션 스크리닝이 판정하고, 되돌릴 수 없거나 파괴적인 행동만 사람에게 올라옵니다 — 상세는 묻지 않는 기본값.
· 에이전트·스킬은 프로젝트별 .claude 에 생기므로 Git으로 공유; 플러그인은 환경(PC)마다 각각 설치.
· 실무에서는 데모와 달리 상세 요구사항과 데이터를 함께 주면(길면 마크다운으로) 의도 전달이 확실해집니다.
