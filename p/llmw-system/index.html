시스템 파일과 rules

볼트에는 노트뿐 아니라 AI의 동작을 규정하는 시스템 파일이 함께 들어갑니다. 강사가 공들여 깎아 둔 이 파일들은 한 번 정독해 볼 가치가 있습니다.

저자와 모델 명시

  • 메인 볼트의 주 저자는 사람(나) 입니다.
  • LLM 위키에는 내 이름과 함께 어떤 모델이 작성했는지도 명시합니다. 예: "Opus 4.8 · effort X-high", "Fable", "Codex Fugu · Ultra" 등.
  • 어떤 모델이 만든 위키인지 기록해 품질을 비교·최적화합니다. 인제스트는 토큰·시간을 많이 쓰므로, 정말 중요한 자료만 모으는 것이 좋습니다.

메인 볼트의 시스템 파일

클로드가 읽을 문서, 다른 에이전트가 읽을 문서, CMDS(컨텍스트) 관련 내용, 볼트 규칙, 작성·포매팅 규칙, 연구 주제, 페르소나(brain dump) 등이 들어갑니다.

LLM 위키의 core-context

LLM 위키는 어떤 목적으로 위키를 쓰려는지를 담는 컨텍스트 파일을 씁니다. 온보딩을 시작하면 core-context.md 를 수정하며 이름·소속·부서·취미·취향 등을 채웁니다. 여기서도 모든 걸 한 파일에 쓰지 않고 "취향은 취향.md, 전문 페르소나는 여기" 처럼 주소를 명시해 컨텍스트를 최적화합니다.

.claude/rules — 헌법처럼 읽는 규칙 .claude 폴더 안 rules 폴더의 마크다운 파일은, Claude Code가 세션 시작 즉시 먼저 읽습니다(헌법처럼 엄밀히 준수). 반면 CLAUDE.md 는 가이드처럼 참고합니다. 그래서 편집 규칙·취향·중요한 강제 규칙은 rules 에 담아 두면 좋습니다.
