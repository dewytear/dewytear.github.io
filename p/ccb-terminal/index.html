터미널 기초 명령어

터미널이 낯설어도 괜찮습니다. 우리의 목표는 딱 "새 폴더를 만들고 그 위치로 가서 claude 를 실행" 하는 것까지입니다. 그 다음은 AI가 다 해 줍니다. Windows는 PowerShell 을 실행하면 보통 사용자 폴더에서 시작합니다.

딱 네 가지만 기억하세요

명령뜻하는 일
pwdprint working directory지금 내가 어느 폴더에 있는지 보여줌
cd <폴더>change directory다른 폴더로 이동 (예: cd Downloads)
mkdir <이름>make directory새 폴더 만들기 (예: mkdir kist-test)
claude—현재 폴더에서 Claude Code 실행

실습 순서

새 폴더를 만들고 그 위치로 이동해 claude 를 실행하는 것이 오늘의 관문입니다.
# 1. 지금 위치 확인
pwd
# 2. 다운로드 폴더로 이동
cd Downloads
# 3. 새 폴더 만들기
mkdir kist-test
# 4. 만든 폴더로 이동
cd kist-test
# 5. 그 폴더에서 Claude Code 실행
claude

이렇게 새로 만든 폴더에서 claude 를 실행하면, 이제 Claude Code는 그 폴더 안에서 모든 작업을 하게 됩니다.

오늘의 관문 "폴더 만들기 → 그 위치로 이동 → claude 실행" — 여기까지만 넘어오면 이후로는 AI의 도움을 받을 수 있습니다. 막히면 주저 말고 도움을 요청하세요.
