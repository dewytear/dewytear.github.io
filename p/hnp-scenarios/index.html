하네스100 · 성능

하네스100은 자주 쓰이는 100가지 사례의 하네스를 미리 구성해 공개한 모음입니다. 매번 팀을 처음부터 짜는 대신, 비슷한 구성을 찾아 커스터마이징하면 훨씬 빠릅니다.

어떤 사례가 있나

영역예시
콘텐츠 제작유튜브 · 팟캐스트 · 뉴스레터 · 온라인 강의
소프트웨어 개발기능 개발 · 리팩터링 · 버그 수정 · 테스트
데이터 분석수집 · 정제 · 분석 · 리포트
비즈니스 전략스타트업 검증~피칭 · 정부 지원 사업계획서
교육 · 학습커리큘럼 · 강의안 · 문제 출제
법률 · 운영 · 전문 도메인위험 평가 · 운영 프로세스 · 도메인별 전문 구성

예를 들어 정부 지원 사업계획서 구성에는 공고문 분석 전문가 · 사업성 파트 작성자 · 예산 편성 도우미 같은 에이전트가 미리 들어 있습니다.

ERP 커스텀에 맞게 바꾸는 법

가장 가까운 구성을 고른 뒤, 역할을 ERP 커스텀 흐름으로 치환하면 됩니다.

본문 작성자커스텀 설계자 · 개발 에이전트
검수·팩트체크회귀 QA · 수치 정합 검증

※ 실행은 /harness 에 의도를 주고, 제안된 팀을 위 표대로 수정 요청하면 됩니다.

성능 — 얼마나 좋아지나

개발 과제 15개(기초·중급·고급)를 하네스 없이 vs 하네스로 풀게 하고, 최종 결과물을 LLM 심판(judge)이 채점했습니다. 결과는 평균 약 60% 성능 향상, 하네스 구성 시 승률 100%. 특히 과제가 어려울수록 단일 도구 점수는 크게 떨어지는 반면 하네스는 품질이 유지됐습니다.

수치의 출처 위 "60% 향상 · 승률 100%"는 강연자의 자체 측정치입니다. 참고로 Anthropic도 멀티에이전트 구성이 단일 에이전트 대비 내부 평가에서 90.2% 성능 향상을 보였다고 발표한 바 있어, "역할을 나누면 어려운 과제에서 유리하다"는 경향 자체는 부합합니다.
개념도 — 실제 값이 아닌 경향입니다. 어려운 과제일수록 격차가 커집니다.
주의 위 그래프는 경향을 보여 주는 개념도이며, 정확한 수치는 배포된 벤치마크 자료를 확인하세요. ERP 커스텀은 도메인 특성상 표준 영향도·회귀가 품질을 좌우하므로, 벤치마크 수치보다 자기 현장 기준의 검증이 더 중요합니다.
어디서 찾나 검색어 "하네스 100" (한국어 버전)으로 사례 모음을 찾을 수 있습니다. 마켓플레이스 주소와 함께 설치 문서의 주의사항을 참고하세요.

명령어 · 빠른 참조

하네스를 쓰며 자주 찾게 되는 명령·조작·설정을 한자리에 모았습니다.

핵심 명령어

명령하는 일
/plugin marketplace add <repo>하네스 마켓플레이스 등록 (예: lev-factory/harness)
/plugin install harness하네스 플러그인 설치
/reload설치한 플러그인을 현재 세션에 반영
/harness <의도>의도를 주고 하네스 실행 (팀 구성 시작)
진행시켜제안된 팀을 검토한 뒤 실행 승인
