운영 — 사용량·세션과 마무리

Claude Code를 잘 쓰려면 사용량(토큰) 과 컨텍스트, 그리고 세션(맥락) 을 관리할 줄 알아야 합니다. 토큰이 아주 중요한 시대가 되었습니다.

사용량 — /usage

  • /usage — 현재 세션과 이번 주 사용량을 보여줍니다.
  • 세션 한도: 최초 실행 시점부터 5시간 단위로 책정됩니다. 5시간 안에 100%를 다 쓰면, 그 5시간이 끝날 때까지 기다려야 합니다.
  • 주간 리밋도 있습니다. 개발자들이 가장 고통스러워하는 한도이니 알뜰하게 쓰는 것이 핵심입니다.

컨텍스트 — /context

/context 는 지금 Claude Code에 어떤 내용이 실려 가는지 시각화해 보여 줍니다. 컨텍스트 윈도우 크기는 모델에 따라 다릅니다 — 기본은 대부분 20만(200K) 토큰이고, 최신 모델(Fable 5·Sonnet 5·Sonnet 4.6, Opus 4.6 이후)은 100만(1M) 토큰을 지원합니다. Max·Team·Enterprise 플랜에서는 Opus가 자동으로 1M 컨텍스트로 업그레이드되며, /model opus[1m] 처럼 [1m] 접미사를 붙여 직접 선택할 수도 있습니다.

  • 시스템 프롬프트·도구 정의 등이 일부를 차지하고, 일을 시킬 때마다 조금씩 찹니다.
  • 어느 정도 차면 콤팩트(compact) 가 일어나 내용이 압축·축소됩니다.
  • 콤팩트가 일어나면 일부 데이터 손실이 생겨 성능이 조금 떨어질 수 있습니다.
  • 그래서 다 찰 때까지 기다리지 말고, 적정 시점에 /compact 로 수동 압축하는 것이 권장됩니다.

에이전트를 활용하면 메인 컨텍스트를 아끼면서 품질을 유지할 수 있습니다.

세션(맥락) 관리

웹 채팅과 달리 Claude Code는 /exit 로 나가면 맥락이 끊깁니다. 다시 이어가려면 다음 명령을 씁니다.

명령하는 일
claude --continue가장 최근 세션을 그대로 이어서 시작
claude --resume과거 세션 목록에서 골라 그 맥락으로 복귀
/clear나가지 않고도 맥락을 비워 새 세션 시작

세션 기록은 사용자 폴더 하위 ~/.claude/projects/ 에 프로젝트별·세션별로 저장됩니다. 즉 오래전 작업도 --resume 으로 되살릴 수 있습니다. 단, 이 기록은 로컬에만 저장되므로 다른 PC에는 없습니다.

캐싱 주의 AI에는 캐싱이 있어, 이어서 요청하면 새 요청분에만 과금됩니다. 하지만 캐싱에는 유효 시간이 있어, 시간이 지난 뒤 --resume 으로 다시 요청하면 쌓아둔 내용을 전부 다시 실어 보내 캐싱 이점을 못 받습니다. 이럴 때는 새 세션을 여는 편이 유리할 수도 있습니다.

유용한 기능과 마무리

마지막으로 Claude Code를 더 잘 쓰기 위한 명령·스킬 몇 가지와, 다음 학습 방향을 정리합니다.

내 사용 습관 분석 — /insight

/insight 는 내가 평소 Claude Code를 어떻게 쓰는지 분석하고, 더 효율적으로 쓸 수 있는 리포트를 만들어 줍니다.

강의에서 공유된 유용한 스킬

  • 워크로그(worklog) — 최근에 한 작업들을 주간 보고서처럼 정리. 예: "최근 일주일 동안 한 작업을 정리해줘" 하면 로그를 분석해 어떤 프로젝트를 했는지 깔끔하게 정리해 줍니다.
  • 맨파워(manpower) — 내가 AI를 얼마나 잘 쓰고 있는지 분석해 팔각형(레이더) 차트로 시각화. 부족한 부분과 주간 성장 추이를 보여 줍니다. 직원들의 AI 활용도(AX) 측정에도 유용합니다.
  • GPT Image 2 / HWP 등 — 이미지 생성·한글 문서 처리용으로 직접 만든 스킬.

다른 형식의 문서

PDF·PPT·엑셀은 document-skills 플러그인에 포함됩니다. 공식에 없는 HWP 는 별도로 만든 스킬을 등록해 쓸 수 있습니다. 특정 형식도 변환 라이브러리가 있으면 그것을 이용하는 스킬을 만들어 처리할 수 있으나, 순수 바이너리 형식은 어려울 수 있습니다.

Cowork(코워크)

앱에서 제공되는 Cowork 는 Claude Code보다 늦게 나와 아직 다소 불안정하고 기능이 부족하지만, 최근 1.0 이 런칭되었습니다. 터미널이 부담스러우면 Cowork로 시작해 보는 것도 방법입니다.

정리 — 오늘 한 것

  1. CLAUDE.md로 지침 만들고, 시를 써서 파일로 저장(지침 동작 확인)
  2. 미토스 모델 조사 → 파일 → 사이트 생성, 블랙→화이트 테마 변경
  3. 화이트 사이트에서 디자인 시스템 추출 → my-design 스킬 생성
  4. 허깅페이스 논문 16편 정리 → 스킬로 논문 소개 사이트 제작
  5. document-skills 설치 → 논문 분석 에이전트 생성 → PDF 분석 → 상세 페이지 연결
다음 단계 자주 쓰는 명령어를 담은 핸드아웃과 스킬 압축 파일을 참고해 복습하세요. 다음 세션에서는 이런 에이전트들을 여러 개 두고 서로 협업시키는 하네스(Harness) 를 다룹니다.
