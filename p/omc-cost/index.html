비용·성능과 명령어 참조

OMC의 핵심은 작업을 여러 에이전트로 나눠 동시에 처리하는 것입니다. 그래서 전체 작업 시간은 줄일 수 있지만, 동시에 여러 작업자가 돌면 그만큼 AI 사용량(토큰)이 늘어 비용은 커질 수 있습니다. 속도와 비용은 함께 움직인다고 이해하면 됩니다.

왜 비용이 달라지나

OMC의 비용은 고정값이 아니라 작업 방식에 따라 크게 달라집니다. 아래 요인들이 비용을 좌우합니다.

  • 병렬화 가능 여부 — 작업을 여러 개로 쪼갤 수 있으면 빨라지지만, 동시에 여러 작업자가 돌기 때문에 같은 시간에 쓰는 토큰이 늘어납니다.
  • 재시도 횟수 — 검증에 실패하면 에이전트가 다시 시도합니다. 재시도가 많을수록 그만큼 토큰을 추가로 소모합니다.
  • 모델 단가와 문맥 크기 — 더 큰 모델을 쓰거나 한 번에 다루는 문맥(코드·문서)이 길수록, 호출 1회당 드는 비용이 올라갑니다.
  • 빌드·테스트 실패 — 빌드나 테스트가 자주 실패하면 고치기 위한 재작업이 반복되고, 반복되는 만큼 토큰이 더 쓰입니다.
  • 외부 CLI 워커 사용 — Codex, Gemini 같은 외부 모델을 함께 부르는 모드(CCG 등)는 모델 호출 자체가 늘어 비용이 추가됩니다.
  • 작업 규모 — 큰 작업을 자율 모드로 끝까지 돌리면 누적 사용량이 커집니다. 작은 수정 작업과는 비용 차이가 큽니다.
한 줄 정리 빠르다고 해서 항상 저렴한 것은 아닙니다. 작은 작업은 일반 대화로 가볍게 처리하고, 병렬·자율 모드는 그만한 가치가 있는 큰 작업에만 쓰는 식으로 조절하면 속도와 비용의 균형을 맞출 수 있습니다.

명령어 모음

자주 쓰는 명령을 한눈에 정리하고, 각 명령이 실제로 무엇을 하는지 설명을 함께 적었습니다. 슬래시 명령어는 가능한 한 네임스페이스(/oh-my-claudecode:) 형식으로 표기합니다.

구분명령어수행 내용
설치/plugin marketplace add <repo> → /plugin install oh-my-claudecode플러그인 저장소를 등록한 뒤 OMC를 설치합니다. 두 줄을 순서대로 실행합니다.
프로젝트 설정/oh-my-claudecode:omc-setup --local현재 프로젝트에만 적용되는 OMC 설정을 만듭니다. 전역 설정은 건드리지 않습니다.
전역 설정/oh-my-claudecode:omc-setup모든 프로젝트에 공통 적용되는 설정을 만듭니다. 기존 전역 CLAUDE.md에 영향을 줄 수 있습니다.
진단/oh-my-claudecode:omc-doctor설치·설정 상태를 점검하고 문제가 있으면 알려줍니다. 문제 해결의 첫 단계입니다.
프로젝트 문서화/oh-my-claudecode:deepinit [path]프로젝트 구조를 분석해 AI가 이해하기 쉬운 문서(AGENTS.md)로 정리합니다.
요구사항 명확화/deep-interview <idea>모호한 아이디어에 질문을 던져 구체적인 요구사항으로 다듬습니다.
자율 구현/oh-my-claudecode:autopilot <task>요구사항을 받아 구현부터 검증까지 알아서 진행합니다.
끝까지 수행/oh-my-claudecode:ralph <task>완료 조건을 만족할 때까지 멈추지 않고 반복 수행합니다.
최대 병렬/oh-my-claudecode:ultrawork <task> 또는 ulw서로 독립적인 여러 작업을 동시에 처리해 속도를 높입니다.
팀 실행/oh-my-claudecode:team <N>:<agent> <task>지정한 수(N)의 에이전트에게 역할(agent)을 맡겨 작업을 분담시킵니다.
업데이트/plugin marketplace update omc → /oh-my-claudecode:omc-setup마켓플레이스를 최신으로 동기화한 뒤 설정을 다시 적용합니다.
계획 / 합의/oh-my-claudecode:plan · /oh-my-claudecode:ralplan작업 전에 실행 계획을 세웁니다. ralplan은 합의 기반으로 더 신중하게 검토합니다. (omc-plan은 plan의 호환 별칭)
취소/oh-my-claudecode:cancel 또는 stopomc / cancelomc진행 중인 OMC 작업을 중단합니다.
패턴 추출/oh-my-claudecode:skillify한 세션에서 효과적이었던 작업 패턴을 재사용 가능한 스킬로 추출합니다. (learner는 deprecated 별칭)
HUD 설정/oh-my-claudecode:hud setup작업 진행 상태를 보여주는 화면 표시(HUD)를 설정합니다.
읽는 법 <task>, <idea>, <N> 처럼 꺾쇠로 묶인 부분은 실제 값으로 바꿔 넣는 자리입니다. 예를 들어 <task> 자리에는 "로그인 API 구현"처럼 수행할 작업을 적습니다. [path] 처럼 대괄호로 묶인 부분은 생략 가능한 선택 항목입니다.

빠른 참조 카드

자주 쓰는 명령을 상황별로 묶은 치트시트입니다. 작업 중 빠르게 찾아 쓰기 좋습니다.
