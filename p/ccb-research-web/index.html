실습 — 조사·디자인·논문 정리

웹에서 조사한 내용을 파일로 저장하고, 그 파일로 사이트를 만들어 다듬습니다.

Claude Code에는 여러 도구가 기본 내장되어 있습니다. 그중 웹 검색(WebSearch)·웹 가져오기(WebFetch) 도구를 이용하면, 시키는 작업을 웹에서 조사해 가져올 수 있습니다. 조사 → 파일 저장 → 웹사이트 생성까지 한 흐름으로 해 봅니다.

1) 조사해서 파일로 저장

미토스(Mythos) 모델을 조사하고 관련된 내용을 파일로 저장해줘.

Claude Code가 웹 검색으로 자료를 수집하고, 출처 링크를 포함해 파일로 정리합니다. (CLAUDE.md 지침이 있으면 한글로 작성되고 파일명에 _new 가 붙습니다.)

2) 조사 내용으로 웹사이트 생성

지금 조사된 내용을 토대로 세련되고 모던한 웹사이트를 만들어줘.
애니메이션 효과가 극대화된 배경, 인터랙티브한 요소를 추가해줘.

텍스트 파일 하나만 주면 Claude Code가 의도를 파악해 사이트를 완성합니다. 완성 후 "브라우저에서 열어줘" 라고 하면 바로 띄워 줍니다.

3) 디자인 수정 · 브랜딩

만들어진 사이트는 계속 고칠 수 있습니다.

# 테마 변경
화이트 테마로 바꿔줘.
# 브랜드 이름을 주면 더 나은 디자인이 나온다
화이트 컬러의 애플 사이트 스타일로 수정해줘.

"애플 사이트 스타일"처럼 익숙한 브랜드를 언급하면 더 완성도 높은 디자인을 만들어 주는 경향이 있습니다.

작업 중에 알아두면 좋은 조작

  • ESC — 진행 중인 작업을 언제든 취소.
  • 작업 중에 무언가를 타이핑하면 다음 작업으로 큐에 쌓여, AI가 처리 가능한 시점에 수행합니다.
  • 에러가 나도 "계속 진행" 또는 그냥 기다리면 Claude Code가 스스로 해결하는 경우가 많습니다.
토큰 주의 웹사이트 생성처럼 큰 작업은 토큰(사용량)을 빠르게 소모할 수 있습니다. 실습 중 요금제 한도에 도달할 수 있으니, 무거운 작업은 필요할 때만 돌리세요. (사용량 관리는 뒤의 "사용량·컨텍스트·세션 관리" 참고)

디자인 시스템 추출

웹서비스를 개발할 때는 보통 디자이너가 만든 디자인 시스템을 받아, 그것을 토대로 개발자가 화면을 만듭니다. Claude Code로는 이 과정을 거꾸로 — 이미 만들어진 사이트에서 디자인 요소만 뽑아 디자인 시스템을 만들 수 있습니다.

추출 요청

완성된 이 사이트의 디자인 요소를 추출해서
별도의 디자인 시스템을 만들어줘.

무엇이 정리되나

현재 사이트의 디자인 요소만 뽑아 하나의 문서로 정의합니다.

  • 컬러 팔레트
  • 텍스트(타이포그래피) 스타일
  • 컴포넌트 — 버튼 스타일, 배치(레이아웃) 스타일
  • 애니메이션 효과

왜 만드나

디자인 시스템을 한 번 만들어 두면, 앞으로 만들 사이트들을 계속 같은 디자인으로 찍어낼 수 있습니다. 사내 시스템을 개발하거나 2차·3차 사이트를 만들 때 동일한 톤을 유지할 수 있고, 동료에게 넘겨 공유하기도 좋습니다.

다음 단계 이렇게 만든 디자인 시스템은 그대로 재사용해도 되지만, "앞으로도 계속 쓰겠다"면 스킬(Skill) 로 만들어 두는 것이 더 편리합니다. (확장 편에서 다룹니다.)

웹 자료 정리 — 허깅페이스 논문

URL 하나만 주면 Claude Code가 그 페이지의 내용을 가져와 정리해 줍니다. 실습에서는 허깅페이스 데일리 페이퍼(그날 추천을 많이 받은 논문 목록)를 정리합니다.

요청 방법

# huggingface.co 의 데일리 페이퍼 URL을 붙여넣고
https://huggingface.co/papers
# 이어서
오늘자 논문들을 정리해줘.

목록 페이지만으로 끝나지 않는다

목록에서 각 논문 페이지를 열어 초록을 모으고, 분류해 한 파일로 정리합니다.

데일리 페이퍼 목록 페이지에는 각 논문의 상세 내용이 담겨 있지 않습니다. 그래서 Claude Code는

  • 목록에서 각 논문의 개별 페이지를 탐색(WebFetch) 하고,
  • 각 페이지의 초록(abstract) 을 가져와,
  • 전체를 분류별로 정리해 파일로 저장합니다.

실습 당시 총 16건의 논문이 분류별로, 각 논문 내용과 함께 하나의 파일로 정리되었습니다.

활용 논문을 하나씩 열어 보는 대신, 관련 논문을 통째로 가져와 AI에게 1차 분석을 시킨 뒤 그 결과로 훑어보면 훨씬 빠릅니다. 이 정리 파일은 이후 "논문 소개 사이트"와 "논문 분석 에이전트"의 입력으로 이어집니다.

실습에서 만든 디자인 시스템과 논문 정리는 다음 편 확장의 재료가 됩니다 — 스킬로 굳히고, 플러그인을 붙이고, 에이전트에게 맡깁니다.
