Claude Code vs Gemini(Antigravity)

AI 도구는 엎치락뒤치락 발전합니다. 현재는 Claude Code가 가장 좋지만, 강사는 Antigravity CLI(agy 명령)도 병행합니다.

항목Claude CodeAntigravity (Gemini 3.5 Flash)
생성 속도초당 약 50~60 토큰약 4배 빠름
이미지 생성모델 자체는 불가(codex-image 스킬로 가능)가능(나노바나나)
결과 퀄리티강사 소감상 더 예쁘게 나옴빠르지만 다듬음 필요

모델별 성능·속도·가격은 Artificial Analysis 사이트에서 비교할 수 있습니다. (Opus·GPT 5.5는 가격이 비싼 편)

수치 참고 표의 "약 4배 빠름"은 공개 벤치마크가 아니라 강사의 경험치입니다. 참고로 병렬 에이전트 구성의 속도 향상은 작업의 독립성에 따라 약 2배에서 최대 10배까지 보고됩니다(Anthropic은 복잡한 쿼리에서 소요 시간 90% 단축을 보고).

Codex CLI로 2차 검증

단일 모델 검증은 편향될 수 있어, Codex CLI(GPT 5.5) 를 연결하는 스킬로 QA 에이전트에 2차 검증을 붙일 수 있습니다.

# 구성 변경이 필요할 때 /harness 로 지시
/harness QA 에이전트는 Codex CLI를 이용해 검증하도록 수정
  • QA 에이전트가 이중 검증 프로토콜로 업데이트 — Claude로 1차, Codex CLI로 2차, 두 의견을 통합.
  • 워크플로우를 알아야 하므로 오케스트레이터도 함께 갱신됩니다.
  • 이런 하네스 구성 변경 이력은 CLAUDE.md 에 기록됩니다.

에이전트 1:1 (원온원)

특정 에이전트와 커피챗하듯 대화하며 재설계할 수 있는 기능도 있습니다. 에이전트 목록에서 상대를 고르면 그 에이전트가 자기 역할·원칙을 설명하고 "어떤 부분을 수정할까요?"라고 물어봅니다.

마무리 — 사람이 집중할 것

에이전트가 많은 일을 대신하는 초입에서, 사람은 다음에 집중해야 합니다: 목표 설정, 맥락적 판단, 품질 기준, 책임·윤리, 좋은 질문, 시스템적 사고, 도메인 전문성, 평가·피드백, AI 협업.

Q&A 요점 · 에이전트가 /agents 에 안 뜨면 리스트만 안 보일 뿐 재시작하면 로딩됨(동적 로딩 실패 시 일반 서브에이전트로 뜨기도).
· 오토 모드 — Shift+Tab 으로 auto/accept/plan 모드 전환. 오토 모드는 권한을 매번 묻지 않아 더 자율적으로 동작(중간에 언제든 전환 가능). 안 보이면 클로드 코드 업데이트 필요(native 설치는 자동 업데이트, npm 설치는 수동).
· 2026-08-14부터 오토 모드가 기본값(Pro·Max·Team 신규 세션). 묻지 않는 대신 하드 디나이 규칙과 프롬프트 인젝션 스크리닝이 판정하고, 되돌릴 수 없거나 파괴적인 행동만 사람에게 올라옵니다 — 상세는 묻지 않는 기본값.
· 에이전트·스킬은 프로젝트별 .claude 에 생기므로 Git으로 공유; 플러그인은 환경(PC)마다 각각 설치.
· 실무에서는 데모와 달리 상세 요구사항과 데이터를 함께 주면(길면 마크다운으로) 의도 전달이 확실해집니다.
