하네스 실행하기 (실습)

의도만 전하면 팀이 꾸려지고, 사람이 리뷰·승인한 뒤 실행은 손을 떠납니다.

설치한 /harness 로 실제 일을 시켜 봅니다. 핵심 차이는 "의도만 전달" 한다는 점입니다.

"작성해줘"가 아니라 "작성하고자 합니다"

보통 AI에는 "보고서를 작성해줘"라고 지시합니다. 하지만 하네스에는 의도만 말합니다. 그러면 그 의도를 해결해 줄 에이전트 팀을 구성해 줍니다.

/harness 2026년 국가 과학기술 전 분야 전략기술 예산 배분 및
포스트 PBS 대응 전략에 대해 조사하고 보고서를 작성하고자 합니다.
  • /harness 입력 후 Tab 으로 자동완성한 뒤 요청을 이어 붙입니다.
  • 실행하면 도메인 분석 → 팀 구성을 진행합니다.
  • 중간에 "하네스 풀 구축 / 하네스만 구축" 같은 선택을 물어봅니다.
  • 내 데이터가 있으면 함께 주며 물어볼 수 있습니다. (예: 1000페이지 넘는 PDF 분석도 잘 처리)

구성 완료 → 리뷰 → 실행

하네스 구성이 완료되면 잠시 멈춥니다. 만들어진 에이전트들을 리뷰한 뒤, 문제없으면 실행합니다.

# 리뷰 후 그냥 진행 지시
진행시켜

이 순간 작업은 사람의 손을 떠나, 에이전트 팀이 리서치 → 보고서 작성 → QA를 오케스트레이터가 계획한 순서대로 끝까지 진행합니다.

병렬로 여러 작업

  • 한 작업을 돌려놓고 다른 터미널 창을 띄워 또 다른 일을 시킬 수 있습니다. (예: "코스피가 만까지 갈 수 있을까?" 조사)
  • 실무 개발자 자리에는 이렇게 터미널이 여러 개 떠서 서로 다른 일을 동시에 합니다.
  • Shift + 방향키 로 현재 스폰된 에이전트들이 무슨 일을 하는지 살펴볼 수 있습니다. (색이 들어간 에이전트가 작업 중)
무엇에 쓰나 데이터 분석, 리서치, 보고서 작성, 시뮬레이션 등 — 무엇이든 의도를 주면 그 일을 할 에이전트 팀을 구성해 줍니다.
