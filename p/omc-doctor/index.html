설치 진단

설치 후 문제가 생기면 진단 명령으로 먼저 상태를 확인합니다.

플러그인 환경에서는 아래 명령을 우선 사용합니다.

# 설치·설정 상태를 점검하고 문제를 알려줌 (문제 해결의 첫 단계)
/oh-my-claudecode:omc-doctor

CLI 런타임 경로를 별도로 쓰는 경우에는 다음 진단도 가능합니다.

# CLI 런타임 경로에서 진단
omc doctor
# 플러그인 설치 폴더를 직접 지정해 진단
omc doctor --plugin-dir /path/to/oh-my-claudecode
