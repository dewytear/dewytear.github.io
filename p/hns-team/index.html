에이전트 팀과 컨텍스트 관리

여러 에이전트를 어떻게 협업시키느냐, 그리고 컨텍스트를 어떻게 관리하느냐가 하네스 품질을 좌우합니다.

격리형 서브에이전트 → 커뮤니케이션하는 팀

격리 서브에이전트는 결과만 리턴하지만, 에이전트 팀은 서로를 다시 깨워 협업합니다.
  • 기존 방식 — 서브에이전트들이 격리된 환경에서 각자 일하고 결과만 리턴(병렬). 서로 대화하는 방법이 없었습니다.
  • 에이전트 팀 — 에이전트들이 커뮤니케이션하며 일해서 더 스마트하게 동작합니다.

예를 들어, 리서치 에이전트가 조사를 끝내고 종료된 뒤 분석 에이전트가 스폰됐는데, 분석 중 리서치가 부족한 부분을 발견하면 — 자기가 리서치하는 게 아니라 리서치 에이전트를 다시 깨워 추가 조사를 요청합니다.

에이전트 팀 활성화

이 기능은 실험 버전이라 기본 비활성 상태입니다. 사용자 폴더의 ~/.claude/settings.json 에 환경 변수를 켭니다.

# ~/.claude/settings.json 의 env
"CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  • 이 값을 켜야 에이전트들이 서로 대화하며 팀으로 동작합니다.
  • 에이전트가 동적 로딩에 성공하면 팀 모드가 잘 켜지고, 실패하면 격리된 일반 서브에이전트로 뜨는 경우가 많습니다. (실험 버전의 버그)
  • 참고로 Gemini의 Antigravity CLI 에도 에이전트 간 커뮤니케이션 기능이 추가됐습니다.

컨텍스트 = 주방의 작업대

컨텍스트는 요리를 만드는 작업대와 같습니다. 그 요리와 관련된 것만 올라와 있으면 깔끔하지만, 관련 없는 것이 섞이면 실수할 여지가 생깁니다(소금통에 설탕이 든 격). 실제로 대화가 길어지면 앞뒤 생각이 모순되기도 하는데, 그 상태로 일을 시키면 AI가 "A가 맞나 B가 맞나" 혼란스러워합니다. 그래서 컨텍스트 관리가 중요합니다.
