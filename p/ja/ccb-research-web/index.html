実習: ウェブ調査 → ファイル → ウェブサイト

ウェブで調べた内容をファイルに保存し、そのファイルからサイトを作って整えます。

Claude Code にはいくつものツールが標準で組み込まれています。その中のウェブ検索（WebSearch）・ウェブ取得（WebFetch）ツールを使えば、頼んだ作業をウェブで調べて持ってこられます。調査 → ファイル保存 → ウェブサイト生成までをひと続きでやってみます。

1）調べてファイルに保存

Mythos（ミトス）モデルを調べて、関連する内容をファイルに保存して。

Claude Code がウェブ検索で資料を集め、出典リンクを含めてファイルに整理します。（CLAUDE.md の方針があれば日本語で書かれ、ファイル名に _new が付きます。）

2）調べた内容からウェブサイトを生成

いま調べた内容をもとに、洗練されたモダンなウェブサイトを作って。
アニメーション効果を最大化した背景と、インタラクティブな要素を追加して。

テキストファイルをひとつ渡すだけで、Claude Code が意図を汲んでサイトを仕上げます。完成後に「ブラウザで開いて」と言えば、そのまま表示してくれます。

3）デザイン修正・ブランディング

できあがったサイトは、いくらでも直せます。

# テーマの変更
ホワイトテーマに変えて。
# ブランド名を挙げるとより良いデザインが出る
ホワイトカラーの Apple のサイト風に直して。

「Apple のサイト風」のように見慣れたブランドに言及すると、完成度の高いデザインを作ってくれる傾向があります。

作業中に知っておくとよい操作

  • ESC — 進行中の作業をいつでもキャンセル。
  • 作業中に何かをタイプすると次の作業としてキューに積まれ、AI が処理できる時点で実行されます。
  • エラーが出ても「続けて」と言うか、ただ待つだけで Claude Code が自分で解決することがよくあります。
トークン注意 ウェブサイト生成のような大きな作業は、トークン（使用量）を速く消費します。実習中に料金プランの上限に達することがあるので、重い作業は必要なときだけ回してください。（使用量の管理はあとの「使用量・コンテキスト・セッション管理」を参照）
