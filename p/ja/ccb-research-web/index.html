実習 — 調査・デザイン・論文整理

ウェブで調べた内容をファイルに保存し、そのファイルからサイトを作って整えます。

Claude Code にはいくつものツールが標準で組み込まれています。その中のウェブ検索（WebSearch）・ウェブ取得（WebFetch）ツールを使えば、頼んだ作業をウェブで調べて持ってこられます。調査 → ファイル保存 → ウェブサイト生成までをひと続きでやってみます。

1）調べてファイルに保存

Mythos（ミトス）モデルを調べて、関連する内容をファイルに保存して。

Claude Code がウェブ検索で資料を集め、出典リンクを含めてファイルに整理します。（CLAUDE.md の方針があれば日本語で書かれ、ファイル名に _new が付きます。）

2）調べた内容からウェブサイトを生成

いま調べた内容をもとに、洗練されたモダンなウェブサイトを作って。
アニメーション効果を最大化した背景と、インタラクティブな要素を追加して。

テキストファイルをひとつ渡すだけで、Claude Code が意図を汲んでサイトを仕上げます。完成後に「ブラウザで開いて」と言えば、そのまま表示してくれます。

3）デザイン修正・ブランディング

できあがったサイトは、いくらでも直せます。

# テーマの変更
ホワイトテーマに変えて。
# ブランド名を挙げるとより良いデザインが出る
ホワイトカラーの Apple のサイト風に直して。

「Apple のサイト風」のように見慣れたブランドに言及すると、完成度の高いデザインを作ってくれる傾向があります。

作業中に知っておくとよい操作

  • ESC — 進行中の作業をいつでもキャンセル。
  • 作業中に何かをタイプすると次の作業としてキューに積まれ、AI が処理できる時点で実行されます。
  • エラーが出ても「続けて」と言うか、ただ待つだけで Claude Code が自分で解決することがよくあります。
トークン注意 ウェブサイト生成のような大きな作業は、トークン（使用量）を速く消費します。実習中に料金プランの上限に達することがあるので、重い作業は必要なときだけ回してください。（使用量の管理はあとの「使用量・コンテキスト・セッション管理」を参照）

デザインシステムの抽出

ウェブサービスを開発するときは、ふつうデザイナーが作ったデザインシステムを受け取り、それをもとに開発者が画面を作ります。Claude Code ではこの流れを逆に — すでに出来上がったサイトからデザイン要素だけを抜き出してデザインシステムを作れます。

抽出の依頼

完成したこのサイトのデザイン要素を抽出して、
別のデザインシステムを作って。

何が整理されるのか

いまのサイトのデザイン要素だけを抜き出し、ひとつの文書として定義します。

  • カラーパレット
  • テキスト（タイポグラフィ）のスタイル
  • コンポーネント — ボタンのスタイル、配置（レイアウト）のスタイル
  • アニメーション効果

なぜ作るのか

デザインシステムをいちど作っておけば、これから作るサイトを同じデザインでいくらでも量産できます。社内システムを開発するときや、2 番目・3 番目のサイトを作るときに同じトーンを保てますし、同僚に渡して共有するのにも向いています。

次のステップ こうして作ったデザインシステムはそのまま再利用してもよいのですが、「これからもずっと使う」ならスキル（Skill）にしておくほうが便利です。（拡張の章で扱います。）

ウェブ資料の整理 — Hugging Face の論文

URL をひとつ渡すだけで、Claude Code がそのページの内容を取ってきて整理してくれます。実習では Hugging Face のデイリーペーパー（その日に多く推薦された論文の一覧）を整理します。

頼み方

# huggingface.co のデイリーペーパーの URL を貼り付けて
https://huggingface.co/papers
# 続けて
今日の論文を整理して。

一覧ページだけで終わらない

一覧から各論文のページを開いて要旨を集め、分類してひとつのファイルに整理します。

デイリーペーパーの一覧ページには、各論文の詳しい内容までは載っていません。そこで Claude Code は

  • 一覧から各論文の個別ページを探索（WebFetch）し、
  • それぞれのページの要旨（abstract）を取ってきて、
  • 全体を分類ごとに整理してファイルに保存します。

実習の時点では、計 16 本の論文が分類ごとに、それぞれの内容とともにひとつのファイルへ整理されました。

使いどころ 論文をひとつずつ開いて見る代わりに、関連する論文をまるごと取ってきて AI に一次分析をさせ、その結果でざっと眺めるほうがずっと速いです。この整理ファイルは、このあとの「論文紹介サイト」と「論文分析エージェント」の入力へつながります。

実習で作ったデザインシステムと論文整理は、次の章拡張の材料になります — スキルとして固め、プラグインを付け、エージェントに任せます。
