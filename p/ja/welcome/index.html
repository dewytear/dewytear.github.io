はじめに

Claude Code は Anthropic がつくった Claude 公式の CLI（コマンドラインインターフェース）です。ターミナルの中で動くエージェンティックなコーディングツールで、あなたのコードベースを理解し、定型作業の実行・複雑なコードの説明・git ワークフローの処理を代行します — すべて自然言語の指示だけで。 チャット画面とエディタのあいだでコードをコピー＆ペーストする代わりに、プロジェクトディレクトリで Claude Code に直接話しかけます。ファイルを読んで修正し、シェルコマンドを実行し、コードベースを検索し、テストを走らせ、コミットまで代行します — 危険な操作は実行前に許可を求めます。 Claude Code はターミナル CLI、デスクトップアプリ（Mac/Windows）、ウェブアプリ（claude.ai/code）、IDE 拡張（VS Code、JetBrains）で使え、Opus・Sonnet・Haiku といった最新の Claude モデルで動きます。

インストールと開始

いちばん速い始め方はネイティブインストーラーです — 依存関係なしにコマンド一行で済み、Claude Code を自動で最新の状態に保ってくれます。

  • macOS / Linux / WSL: curl -fsSL https://claude.ai/install.sh | bash
  • Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
  • プロジェクトへ移動: cd your-project
  • 実行: claude
Homebrew（brew install --cask claude-code）と WinGet にも対応しています。npm でのインストール（npm install -g @anthropic-ai/claude-code、Node.js 22 以上が必要）も引き続き動作し、同じネイティブバイナリを入れます。 初回起動すると Claude Code が認証の手順を案内します — Claude アカウント（Pro/Max プラン）でログインするか、Anthropic API キーを使えます。そのあとは、やりたいことを普通の言葉で説明するだけです。例: 「認証フローを説明して」、「ダークモードのトグルを追加してテストを走らせて」。 知っておくと便利な起動フラグをいくつか:
  • claude — 対話セッションを開始
  • claude "プロンプト" — 一度きりの作業を実行
  • claude -c — 直近の会話を再開
  • claude --help — 全オプションを表示

日々の使い方

インストールと認証が済んだら、ほとんどの場合、やりたいことを自然言語で書くだけで Claude Code は動きます — ファイルを読み、コードを直し、コマンドを実行し、危険な操作の前には許可を求めながら。普通のプロンプトに加えて、セッションを扱う組み込みのスラッシュコマンドもあります:

  • /help — 使えるコマンドを表示
  • /clear — 新しい会話を開始（コンテキストを初期化）
  • /init — プロジェクトを説明する CLAUDE.md ファイルを生成
  • /review — PR または作業中の変更をレビュー
  • /config — 設定を開く（テーマ・モデルなど）
  • /model — 使用する Claude モデルを切り替え
大きな差を生む二つのコツ:
  • CLAUDE.md — プロジェクトのルール・コマンド・コンテキストを書いておくリポジトリ内のファイル。Claude Code が自動で読むので、同じことを繰り返し言う必要がありません。
  • Plan mode — 修正の前にまず計画を立てさせるモード。大きな作業ほど、コードが変わる前にアプローチを先に承認できます。
ここまでが基本です。Claude Code の本当の力は拡張から生まれます。その通り道がスキル・MCP サーバー・フックの三つ — 続きは拡張機能で。
