Welcome

Claude Code は Anthropic がつくった Claude 公式の CLI（コマンドラインインターフェース）です。ターミナルの中で動くエージェンティックなコーディングツールで、あなたのコードベースを理解し、定型作業の実行・複雑なコードの説明・git ワークフローの処理を代行します — すべて自然言語の指示だけで。 チャット画面とエディタのあいだでコードをコピー＆ペーストする代わりに、プロジェクトディレクトリで Claude Code に直接話しかけます。ファイルを読んで修正し、シェルコマンドを実行し、コードベースを検索し、テストを走らせ、コミットまで代行します — 危険な操作は実行前に許可を求めます。 Claude Code はターミナル CLI、デスクトップアプリ（Mac/Windows）、ウェブアプリ（claude.ai/code）、IDE 拡張（VS Code、JetBrains）で使え、Opus・Sonnet・Haiku といった最新の Claude モデルで動きます。 左のリストから、Claude Code のインストール方法、日々の使い方、そしてスキル・MCP サーバー・フックによる拡張の方法を順に学んでください。
