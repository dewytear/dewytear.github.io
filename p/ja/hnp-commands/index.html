コマンド・クイックリファレンス

ハーネスを使っていてよく探すことになるコマンド・操作・設定を一か所にまとめました。

主なコマンド

コマンドやること
/plugin marketplace add <repo>ハーネスのマーケットプレイスを登録（例: lev-factory/harness）
/plugin install harnessハーネスプラグインをインストール
/reload入れたプラグインを現在のセッションに反映
/harness <意図>意図を渡してハーネスを実行（チーム編成の開始）
進めて提案されたチームを検討したうえで実行を承認
/agents生成されたエージェントの一覧を確認
/exitセッションの終了（エージェントが見えないときの入り直し用）

操作・ショートカット

操作やること
Tab/harness を入力したあとの補完
Shift + 方向キー実行中の各エージェントの作業をのぞく
Shift + Tabモードの切り替え（auto / accept / plan）
新しいターミナル窓別のハーネスを同時に実行（並列の作業）

設定・成果物の場所

項目内容
エージェントチームを有効化~/.claude/settings.json の env に "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
成果物のフォルダ_workspace — 分析・設計・実装・QA レポート・根拠の出典
エージェント・スキルの定義.claude の下（Git で共有できます）
構成の変更履歴CLAUDE.md

場面別のチートシート

場面こうする
はじめてのインストール/plugin marketplace add … → /plugin install harness → /reload → /harness で確認
はじめての実行/harness + 「〜したいと思っています」という意図 → チームを検討 → 進めて
進行の観察Shift + 方向キーでエージェントを確認
検証の強化/harness QA エージェントは Codex CLI で交差検証するように修正
チームの修正/harness <エージェント> は <条件> も検証/処理するように修正
エージェントが見えない/exit して入り直す → /agents で確認
意図の文のテンプレート（コピーして使う） /harness ERP の <モジュール> で <何を> する顧客向けカスタマイズを進めたいと思っています。標準ソースの影響範囲の分析と回帰テストまで含めてください。
いろいろなシナリオで、このテンプレートの<モジュール>・<何を>だけを入れ替えれば大丈夫です。
