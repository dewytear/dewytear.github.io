LLM Wiki — 概要

この資料は「LLM Wiki（LLM ウィキ）/ ク・ヨハン」の講演を、順に段落ごとに整理したものです。人工知能の時代には、自分の資料をどこにどう整理しておくかがとても重要になります。私たちはすでに Claude Code の CLAUDE.md・memory.md のようなマークダウンで AI へ文脈を広げてきましたが、Obsidian はそのすべてをひとつの体系として文脈づけてくれるシステムです。

重い RAG も再コンパイルもなしに、ボルトの地図（道しるべ）をたどって AI がライブで知識を探しに行きます。

LLM Wiki とは

Karpathy（カルパシー）が 2026 年 4 月の X の投稿（「LLM Knowledge Bases」）と 'llm-wiki' の gist を通じて提案した考え方で、ベクトル DB やグラフ DB を作る重い RAG も、継続的なコンパイルもなしに、ライブで埋め込んで人工知能が知識を参照できるようにするシステムです。Obsidian のボルトに知識ベースを築けば、AI が地図・ナビゲーション（道しるべ）を見て知識を探しに行きます。

この文書セットで扱うこと

  • ボルト（Vault）の体系 — メインのボルト vs ウィキのボルト
  • 何を入れるのか（知識のキャプチャ）とノートのメタデータ
  • ノートのつながり（links）と、ウィキカードの種類
  • システムファイルと rules、オンボーディングの実習
  • 三つの中心的な動作 — Ingest · Query · Lint
  • ウェブクリッパーとインボックス、そして活用の哲学
