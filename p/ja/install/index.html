インストールと開始

いちばん速い始め方はネイティブインストーラーです — 依存関係なしにコマンド一行で済み、Claude Code を自動で最新の状態に保ってくれます。

  • macOS / Linux / WSL: curl -fsSL https://claude.ai/install.sh | bash
  • Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
  • プロジェクトへ移動: cd your-project
  • 実行: claude
Homebrew（brew install --cask claude-code）と WinGet にも対応しています。npm でのインストール（npm install -g @anthropic-ai/claude-code、Node.js 22 以上が必要）も引き続き動作し、同じネイティブバイナリを入れます。 初回起動すると Claude Code が認証の手順を案内します — Claude アカウント（Pro/Max プラン）でログインするか、Anthropic API キーを使えます。そのあとは、やりたいことを普通の言葉で説明するだけです。例: 「認証フローを説明して」、「ダークモードのトグルを追加してテストを走らせて」。 知っておくと便利な起動フラグをいくつか:
  • claude — 対話セッションを開始
  • claude "プロンプト" — 一度きりの作業を実行
  • claude -c — 直近の会話を再開
  • claude --help — 全オプションを表示
