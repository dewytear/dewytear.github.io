Claude Code とは何か

Claude Code は自分のローカル環境（自分の PC）で動く AI エージェントだと考えてください。ウェブのチャットと違い、自分のコンピュータのファイルを直接読んで修正し、コマンドを実行して仕事を片づけます。作業はプロジェクトごとにフォルダをひとつ作り、そのフォルダの中で進めます。Windows では通常 PowerShell のターミナルで実行します。

既存のサービスとの違い

形態特徴自由度
ウェブブラウザ（Claude・ChatGPT・Gemini）ブラウザ内の制約された環境で AI を使う。ファイルをいちいちアップロードする必要があるもっとも制限的
Claude デスクトップアプリローカルで動くが、ターミナルに比べると制約がある中間
Claude Code（ターミナル）実行したフォルダのファイルに直接アクセス。思いどおりに自由に作業できるもっとも自由

ターミナル環境に少し慣れるだけで、普段 AI チャットを使うようにずっと自由に使えるようになります。

実演 — 議事録 3 つをひとつのレポートに

ファイル一覧を教えなくても、自分で探索・読み込み・分析してレポートを作ります。

議事録ファイル 3 つが入ったフォルダで Claude Code を実行し、こう頼みます。

この議事録 3 つをまとめて 1 つのレポートに要約して。日本語で。

ここで肝心なのはどんなファイルがあるかを教えていないという点です。ウェブのチャットならファイルを自分でアップロードする必要がありますが、Claude Code は

  • いまのフォルダにどんなファイルがあるかをまず探索（search）し、
  • そのファイルを一つずつ読み込み、
  • 内容を分析したうえで結果（レポート）を作ってくれます。

つまり「実行した場所のフォルダ」がそのまま作業空間になり、その中のファイルを自分で扱います。

覚えておくこと Claude Code は claude を実行したそのフォルダ全体にアクセスします。だからプロジェクトごとにフォルダを分け、作業するフォルダの中で実行する習慣が大切です。
