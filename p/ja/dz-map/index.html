Knowledge Map — Douzone

このページは DOUZONE World（業務・組織の知識）を集計した知識の地図です。ウィキの知識は World → Domain → System → Document の 4 階層で構成され、この地図はそのうち DOUZONE World を扱います。会社の知識の文書がどの System に属し、互いにどうつながっているかを示します。文書ごとの要約・中心の概念・関連する文書は、AI が作った構造的な知識のインデックス（knowledge-index.json）から出てきており、この関連は Knowledge Graph で 3 種類の 3D と 6 種類の 2D の表現として見られます。講義や学習の知識は AI Knowledge Map が同じ構造で集計します。

ふたつの World — 学習の知識（AI）と業務の知識（DOUZONE）が、同じインデックスの上でつながります。

System をひと目で

“ハブの文書”は、ほかの文書からいちばん多く関連として指された、その筋の入口の文書です。表の数値は knowledge-index.json から実時間で集計され、新しい System は文書が登録されると自動で現れます。

System の詳細 — 何が入っていて、どの順に読むか

AI開発ナレッジプラットフォーム — GitLab をもとにした自動の知識化の提案（4 編）

GitLab に積み上がる開発の成果を AI が分析して組織の知識へ自動で変換し蓄積する Read-Only Engineering Knowledge Platform の提案のシリーズです。下の順に読めば、問題の定義から実行の計画までがひと続きにつながります。

  • 提案概要 — なぜ今、何を — 一文の要約と好循環の構造、業界統計に根拠づけた問題定義。シリーズの入口。
  • 提案の中核とアーキテクチャ — 開発フローはそのまま、知識化は AI が。Event Stream（GitLab）と Knowledge State（Wiki）の分離、7 層構成・トリガー・SHA 増分分析・整合性ゲート。
  • 知識管理体系 — 価値判定 · 知識の原子構造 · 二重のリンク（related · relations）· Identifier 検索 · 出所追跡 · FACT/INFERRED/DECISION の信頼等級 · supersedes のライフサイクル。
  • セキュリティ・付加価値・ロードマップ — Reference Wiki エンジンの再利用と PUBLIC~RESTRICTED の等級・アクセス分離、API 仕様書の自動更新などの対象別シナリオ、4 フェーズの推進と第 1 次 PoC・検証 KPI。

AI通知の送信エンジン — Kafka をもとにした送信エンジンの実装の要請（1 編）

AI 通知が送信要求の生成まで終えたあとの、実際の送信・タイミング・再処理・状況を、プラットフォームのチームが Kafka をもとにした共用の送信エンジンとして実装してくれるよう要請する提案のシリーズです。概念を主に整理しており、具体の設計は協議で確定します。

  • 送信エンジン実装依頼 — 概要・依頼事項・インターフェース — 送信依頼の生成までが AI 通知、その先の送信・タイミング・再処理・現況がエンジンの責任という境界の定義から、チャネル送信・冪等・配達保証・DLQ などの依頼事項、インターフェースの事前確定・協議・期待効果までを一編に。

予定の System — 場所だけ用意されたところ

下の三つの System は、ナビゲーションにフォルダだけ用意された状態です。そのフォルダに文書が加わり知識のインデックスに登録されると、上の表と Knowledge Graph に自動で現れます。

  • Architecture — OmniEsol ERP・SCM の領域のシステムの構造、階層の設計、モジュール間の連携といったアーキテクチャの知識が積まれる場所です。
  • Development Guide — 開発の標準、共通のパターン、コードレビューの基準など、チームが共有する開発のガイドが集まる場所です。
  • Project — 個々のプロジェクトの業務の Rule、意思決定、障害の経験といったプロジェクト単位の知識が記録される場所です。

おすすめの読む順

  • 提案書をはじめて読むなら — 提案概要 — なぜ今、何を → 提案の中核とアーキテクチャ。ここまでが「何を、なぜ」です。
  • 技術の検討が目的なら — 中核とアーキテクチャ → 知識の管理の体系 → セキュリティ・付加価値・ロードマップ。「どうやって」を扱います。
  • 実行の判断が目的なら — セキュリティ・付加価値・ロードマップで Phase・PoC・KPI を確かめ、背景が要るなら概要へ戻ります。

知識をつなぐ橋 — ブリッジの概念

いくつもの System に同時に現れる概念は、筋をまたぐ“橋”になります。DOUZONE World のふたつの System（提案のシリーズ）は、まだ共有する中心の概念がないので、集計されたブリッジがありません — 概念が 3 つ以上の System にまたがると、この場所に自動で現れます。いまはナレッジプラットフォーム · AI キュレーター · 知識の管理のような概念が AI World（Second Brain・LLM Wiki の System）と主題でつながっており、World をまたぐ橋の候補です。

ハブの文書 — いちばん多くつながる入口

ほかの文書たちが関連する文書としていちばんよく指した文書です。いまの入口は 提案の概要（5 回のつながり）であり、共通のハブの基準（6 回以上）に届くと、この場所に自動で集計されます。
