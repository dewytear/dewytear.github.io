使用量・コンテキスト・セッションの管理

Claude Code をうまく使うには、使用量（トークン）とコンテキスト、そしてセッション（文脈）を管理できる必要があります。トークンがとても重要な時代になりました。

使用量 — /usage

  • /usage — いまのセッションと今週の使用量を表示します。
  • セッションの上限: 最初に実行した時点から5 時間単位で計算されます。5 時間のうちに 100% 使い切ると、その 5 時間が終わるまで待つことになります。
  • 週次のリミットもあります。開発者がいちばん苦しむ上限なので、やりくり上手に使うのが肝心です。

コンテキスト — /context

/context は、いま Claude Code に何が載って運ばれているのかを可視化して見せてくれます。コンテキストウィンドウの大きさはモデルによって違います — 基本はたいてい 20 万（200K）トークンで、最新のモデル（Fable 5・Sonnet 5・Sonnet 4.6、Opus 4.6 以降）は100 万（1M）トークンに対応します。Max・Team・Enterprise のプランでは Opus が自動で 1M コンテキストにアップグレードされ、/model opus[1m] のように [1m] の接尾辞を付けて自分で選ぶこともできます。

  • システムプロンプトやツールの定義などが一部を占め、仕事を頼むたびに少しずつ埋まっていきます。
  • ある程度埋まるとコンパクト（compact）が起きて、内容が圧縮・縮小されます。
  • コンパクトが起きると一部のデータが失われ、性能が少し落ちることがあります。
  • だから満杯になるまで待たず、適当な時点で /compact による手動の圧縮が勧められます。

エージェントを活用すれば、メインのコンテキストを節約しながら品質を保てます。

セッション（文脈）の管理

ウェブのチャットと違い、Claude Code は /exit で出ると文脈が切れます。もう一度つなぐには次のコマンドを使います。

コマンドやること
claude --continue直近のセッションをそのまま続けて開始
claude --resume過去のセッション一覧から選んで、その文脈へ復帰
/clear出ずに文脈だけ空にして新しいセッションを開始

セッションの記録はユーザーフォルダ配下の ~/.claude/projects/ に、プロジェクトごと・セッションごとに保存されます。つまり、ずっと前の作業も --resume でよみがえらせられます。ただしこの記録はローカルにだけ保存されるので、別の PC にはありません。

キャッシュに注意 AI にはキャッシュがあり、続けて頼めば新しい依頼の分だけが課金されます。ただしキャッシュには有効時間があるので、時間が経ってから --resume でまた頼むと、積み上げた内容を全部もう一度載せて送ることになり、キャッシュの恩恵を受けられません。そんなときは新しいセッションを開くほうが有利なこともあります。
