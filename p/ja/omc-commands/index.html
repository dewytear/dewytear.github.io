コマンド集

よく使うコマンドをひと目で整理し、それぞれが実際に何をするのかの説明も添えました。スラッシュコマンドはできるかぎりネームスペース（/oh-my-claudecode:）の形式で表記します。

区分コマンドやること
インストール/plugin marketplace add <repo> → /plugin install oh-my-claudecodeプラグインのリポジトリを登録してから OMC を入れます。2 行を順に実行します。
プロジェクト設定/oh-my-claudecode:omc-setup --localいまのプロジェクトにだけ適用される OMC の設定を作ります。グローバルな設定には触れません。
グローバル設定/oh-my-claudecode:omc-setupすべてのプロジェクトに共通で適用される設定を作ります。既存のグローバルな CLAUDE.md に影響することがあります。
診断/oh-my-claudecode:omc-doctorインストール・設定の状態を点検し、問題があれば知らせます。問題解決の第一歩です。
プロジェクトの文書化/oh-my-claudecode:deepinit [path]プロジェクトの構造を分析し、AI が理解しやすい文書（AGENTS.md）に整理します。
要件の明確化/deep-interview <idea>あいまいなアイデアに質問を投げて、具体的な要件へ磨き上げます。
自律実装/oh-my-claudecode:autopilot <task>要件を受け取り、実装から検証まで自分で進めます。
最後までやり切る/oh-my-claudecode:ralph <task>完了の条件を満たすまで止まらずくり返し実行します。
最大の並列/oh-my-claudecode:ultrawork <task> または ulw互いに独立した複数の作業を同時に処理して速度を上げます。
チーム実行/oh-my-claudecode:team <N>:<agent> <task>指定した数（N）のエージェントに役割（agent）を割り当てて作業を分担させます。
アップデート/plugin marketplace update omc → /oh-my-claudecode:omc-setupマーケットプレイスを最新に同期してから設定を再適用します。
計画 / 合意/oh-my-claudecode:plan · /oh-my-claudecode:ralplan作業の前に実行の計画を立てます。ralplan は合意にもとづき、より慎重に検討します。（omc-plan は plan の互換エイリアス）
キャンセル/oh-my-claudecode:cancel または stopomc / cancelomc進行中の OMC の作業を中断します。
パターンの抽出/oh-my-claudecode:skillifyひとつのセッションで効果的だった作業のパターンを、再利用できるスキルとして抜き出します。（learner は deprecated のエイリアス）
HUD の設定/oh-my-claudecode:hud setup作業の進行状況を見せる画面表示（HUD）を設定します。
読み方 <task>、<idea>、<N> のように山かっこでくくられた部分は、実際の値に置き換えて入れる場所です。たとえば <task> の場所には「ログイン API の実装」のように、やってほしい作業を書きます。[path] のように角かっこでくくられた部分は省略できる任意の項目です。
