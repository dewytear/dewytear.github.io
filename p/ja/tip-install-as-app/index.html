アーティファクトをアプリとしてインストールする — Install as app の使い方と三段階の権限

Claude に「会議の準備ページを作って」と頼むと、会話の横に小さな Web 画面ができます。このように Claude が作ってくれる実行できる成果物をアーティファクト(artifact)と呼びます。これまでアーティファクトは Claude のウィンドウの中でしか開けませんでした。毎日使う道具なのに、使うたびに Claude を開いてその会話を探す必要がありました。

2026年11月24日にベータで出た Install as app は、このアーティファクトを Mac と Windows にアプリとしてインストールできるようにします。インストールしたアプリは自分のアイコンと自分のウィンドウを持ち、許可すれば通知を送ったり、メニューバーに常駐したり、ファイルを扱ったりします。このページでは、作るところからインストール、権限の設定、組織の管理者設定までを使う順に整理しました。

このページについて(出典) · 根拠: Anthropic の発表記事 Turn artifacts into Mac and Windows apps、Claude ヘルプ Install an artifact as an app・Artifacts admin guide(2026-11-25 時点)。ベータなのでメニュー名や既定値は変わることがあります

ひと目で: 言葉で作り、押してインストールする

パッケージ化もコード署名も要りません。アプリは自分の Claude アカウントで動くので、API キーも別のログインもありません。流れは四段階です。

インストールしたアプリはアーティファクトの複製ではありません。同じアーティファクトを別のウィンドウで見せているので、自分やほかの編集者がアーティファクトを直すとアプリも変わります。アーティファクトと同じように Claude を呼び、自分のコネクタ(Claude につないだメールやカレンダーなどの外部サービス)も使います。

① 作る — 欲しいアプリを言葉で説明する

チャットに作りたいアプリを書きます。ヘルプが挙げる例はこういうものです。

メニューバーに常駐するポモドーロタイマーを作って
1時間ごとにストレッチを促す小さな Mac アプリを作って
フォルダ内の写真の名前を日付順に変える Windows アプリを作って

三つの例は必要な権限が違います。タイマーはメニューバー項目と通知を、ストレッチのリマインダーは通知を使い、写真の名前変更は自分のファイルに触れるので、いちばん高い段階であるフルアクセスが要ります。それぞれの意味は下の「三段階の権限」の節で扱います。

Anthropic は社員がこの機能で作ったアプリも公開しました。レイヤー対応の画像エディタ、映画の小道具のように仕立てたファイルマネージャ、フォルダのルールを決めておくと Claude がファイルを整理するアプリ、Claude が横で説明してくれるターミナル、コンピュータの性能をメニューバーで見るアプリです。発表記事は日々の仕事の例として、カレンダーとメールを定期的に読み込む会議準備ページと、その日に出荷する注文のトラッカーを挙げています。

② インストールする

  1. Claude Desktop のメインウィンドウでアーティファクトを開きます。
  2. アーティファクトのタイトルメニューを開くか、アーティファクトを右クリックします。
  3. Install as app を選びます。共有(Share)メニューにも同じ項目があります。
  4. Install を押して確定します。

アーティファクトの中にインストールボタンを付けてほしいと Claude に頼むこともできます。どの道から入っても、Claude はインストールの前に確認を求めます。

メニューに Install as app が見えないときは、まず Claude Desktop を更新してください。6.28899.0 以降が必要です。macOS は Claude > Check for Updates、Windows はメニューボタン(☰)の下の Help > Check for Updates です。Team・Enterprise プランなら、組織のオーナーが機能を有効にしているか確認します。

ブラウザの「Dock に追加」「ショートカットを追加」「ホーム画面に追加」は別の機能です。ショートカットを作るだけで、ここで説明する通知やファイルへのアクセスはできません。

③ 開く・終了する

場所開き方
macOSホームフォルダのアプリケーションフォルダにある Claude Apps フォルダ。Spotlight やアプリランチャーからも見つかり、Dock アイコンを右クリックして オプション > Dock に追加を選ぶと固定できる
Windowsスタートメニューの Claude Apps フォルダ、またはデスクトップのショートカット
Claude Desktopアーティファクトの「Open installed app」、または File > Apps でアプリを選んで「Open」

メニューバー項目やシステムトレイのアイコンを持つアプリは、ウィンドウを閉じても動き続けます。完全に止めるには、macOS では Dock から終了するか、アプリがアクティブなときに Cmd+Q を押します。Windows ではトレイアイコンのメニューで「Exit」を選びます。

三段階の権限 — 何を許すかでアプリが変わる

この機能でいちばん丁寧に見ておきたい部分です。インストールしただけでは、アプリは自分のコンピュータに手を出せません。できることは、自分が許した分だけ増えます。

アプリは下の機能を使う前に必ず尋ねなければならず、依頼ごとに「Allow」か「Don't allow」で答えます。

権限アプリにできること
通知ほかのアプリを使っている間も通知を出す
キーボードショートカットほかのアプリを使っている間も、決めたキーの組み合わせに反応する
ほかのウィンドウの上に表示ほかのウィンドウの上に内容を描き、画面上のマウスカーソルの位置を読む
メニューバー項目(macOS)・システムトレイのアイコン(Windows)アプリが開いている間、そこに項目を表示する
このコンピュータへのフルアクセスプログラムを実行し、ファイルを読み、変更し、削除する。毎回は尋ねない。上の権限も含む

許可にはいくつか決まりが付いています。

  • 許可はアプリの一つのバージョンにだけ有効です。アプリが更新されると Claude がもう一度尋ねます。自分で直した場合も同じです。逆に「Don't allow」は自分で変えるまで残ります。
  • 外から読み込むコードは、尋ねられないまま変わることがあります。アプリがほかのサイトのコードを読み込んでいる場合、その部分は新しい依頼なしに変わりえます。フルアクセスを与えたアプリでは特に気をつけたい点です。
  • 出どころがはっきりしないと警告が付きます。組織の外から来たアプリや、誰が作ったか Claude に分からないアプリは、権限の依頼画面に警告が出ます。
  • フルアクセスは信頼できる作者にだけ開きます。組織外の人が一部でも書いたアプリ、作者を確認できないアプリは、基本的にフルアクセスを求めることもできません。個人プラン(Free・Pro・Max・Ultra)では「組織外」は自分以外のすべてのユーザーを指します。つまり個人ユーザーは、実質的に自分で作ったアプリにしかフルアクセスを与えられません。

Anthropic はインストール前のアプリを審査しません。フルアクセスを持つアプリはどんなプログラムでも実行でき、ファイルを消すこともできるので、そのアプリを書いた全員を信頼できるときだけ許可してください。

行動を危険の度合いで枠に分け、いちばん危険な枠は誰でも開けられないようにする作りは、このウィキが Claude Duet を一望するで見た三段の承認ゲートと同じ設計です。Duet はその枠をエージェントの行動に引き、Install as app はアプリの権限に引きました。

権限の変更とアプリの削除

与えた権限はいつでも取り消せます。

  • macOS: アプリを開いた状態でメニューバーのアプリ名をクリックし、「Permissions」を選びます。
  • Windows: アプリのタイトルバーを右クリックするか Alt+Space を押し、「Permissions」を選びます。
  • Claude Desktop: アプリが開いている間に File > Apps でアプリを選び、「Permissions」を押します。

フルアクセスを切るとアプリが再読み込みされたり閉じたりすることがあるので、先に作業を保存してください。アプリが起動したプログラムは止まりますが、アプリから自分で切り離れたプログラムは残ることがあります。アプリがすでに変えたファイルは元に戻りません。

アプリを消すには File > Apps でアプリを選び、「Uninstall」を押します。macOS ではアプリがゴミ箱に移り、Windows ではショートカットが消えます。消すと許可した権限もなくなりますが、アーティファクト自体は残ります。

プランと組織の設定

ベータはすべてのプランに順次開かれています。ただし既定値はプランごとに違います。

対象アプリのインストールアプリ権限フルアクセス
Free・Pro・Max・Ultra利用可利用可自分で作ったアプリだけ
Team既定でオン既定でオン既定でオフ(管理者がオンにする)
Enterprise既定でオフ既定でオフ既定でオフ
顧客管理の暗号鍵(CMEK)・組織全体の ZDR三つともオフの状態で始まる
HIPAA 対応構成・ハイブリッド展開オンにできない
K-12 の教育組織組織によってはオフの状態で始まるオンにできない

ZDR はゼロデータ保持(zero data retention)の略で、サービス側に会話の内容を残さないという契約条件です。インストールしたアプリは ZDR の対象になりません。管理者はこの点を押さえておく必要があります。

Team・Enterprise の管理者は Organization settings > Artifacts で三つの設定(Install as app、App permissions、Full access to the computer)を別々に切り替えます。変更が行き渡るまで1時間ほどかかります。設定を切ると開いていたアプリは閉じ、アプリが起動したプログラムも止まります。インストール済みのアプリとユーザーが与えた権限は残り、設定を戻すとまた動きます。

会社のコンピュータで個人アカウントまで止めたいときは、デバイスポリシー(MDM、会社が社員の端末設定を遠隔で管理する仕組み)を使います。キーは三つあり、機能を切ることしかできません。組織の設定とデバイスポリシーが食い違うときは、厳しいほうが適用されます。

isArtifactAppsEnabled             # false でインストールしたアプリ全体を切る
isArtifactAppPermissionsEnabled   # false でアプリ権限とフルアクセスを切る
isArtifactAppFullAccessEnabled    # false でフルアクセスだけを切る

# macOS: com.anthropic.claudefordesktop ドメインのコンピュータレベルのプロファイル
# Windows: HKLM\SOFTWARE\Policies\Claude に DWORD 0

監査の記録には穴があります。アプリを開いたこととアクセス確認は Compliance API にアーティファクトの閲覧として残りますが、インストール、権限の依頼への答え、アプリがコンピュータ上でしたこと、三つの設定の変更は記録されません。フルアクセスを組織に開く前に検討しておきたい点です。

使う前に知っておくこと

  • Mac と Windows だけです。Linux、Web、モバイルではアプリを使えません。
  • オフラインでは開けません。オンラインで Claude Desktop にログインしている必要があります。
  • 利用上限を使います。アプリを作ることも、アプリが Claude に送るリクエストも、自分のプランの上限から引かれます。定期的に Claude を呼ぶアプリをいくつも動かせば、その分だけ上限が減ります。
  • インストールできないアーティファクトがあります。Docs・Slides・Sheets のようにテンプレートから作ったアーティファクト、旧形式のアーティファクト、Claude Cowork のライブアーティファクトは対象外です。
  • 共有が切れるとアプリも止まります。オーナーが共有をやめると、アプリが起動したプログラムも止まります。これには20分ほどかかることがあり、オフラインやログアウト中はもっとかかります。
  • コンピュータ操作機能とは半分だけかみ合います。macOS で Claude がコンピュータを操作するとき、インストールしたアプリを見ることはできますが、クリックや入力はできません。

はじめてなら、この順で

  1. すでに毎日開いているアーティファクトを一つ選んでインストールします。権限を何も与えない既定の状態で数日使ってみてください。
  2. 通知が欲しくなったら、そのとき通知だけを許可します。アプリ権限は機能ごとに尋ねられるので、必要なものだけ開ければ足ります。
  3. フルアクセスは、自分で作ったアプリで、ファイルを扱うことがそのアプリの目的であるときだけ与えます。与える前に、アプリが外部サイトのコードを読み込んでいないか Claude に聞いてみてください。
