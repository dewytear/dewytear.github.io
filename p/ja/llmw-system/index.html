システムファイルと rules

ボルトにはノートだけでなく、AI の動きを定めるシステムファイルも一緒に入ります。講師が念入りに削り出したこれらのファイルは、いちど通読してみる価値があります。

著者とモデルの明示

  • メインボルトの主な著者は人（自分）です。
  • LLM ウィキには自分の名前とともに、どのモデルが書いたのかも明示します。例:「Opus 4.8 · effort X-high」「Fable」「Codex Fugu · Ultra」など。
  • どのモデルが作ったウィキかを記録して品質を比較・最適化します。インジェストはトークンと時間を多く使うので、本当に重要な資料だけを集めるのがよいです。

メインボルトのシステムファイル

Claude が読む文書、ほかのエージェントが読む文書、CMDS（コンテキスト）に関する内容、ボルトのルール、執筆・フォーマットのルール、研究の主題、ペルソナ（brain dump）などが入ります。

LLM ウィキの core-context

LLM ウィキはどんな目的でウィキを使おうとしているのかを収めるコンテキストのファイルを使います。オンボーディングを始めると core-context.md を直しながら、名前・所属・部署・趣味・好みなどを埋めます。ここでもすべてを 1 ファイルに書かず、「好みは 好み.md、専門のペルソナはここ」のように住所を明示してコンテキストを最適化します。

.claude/rules — 憲法のように読まれるルール .claude フォルダの中の rules フォルダのマークダウンファイルは、Claude Code がセッション開始のすぐに先に読みます（憲法のように厳密に守る）。一方 CLAUDE.md はガイドとして参考にします。だから編集のルール・好み・重要な強制のルールは rules に入れておくとよいです。
