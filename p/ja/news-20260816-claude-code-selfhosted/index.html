自分のサーバーで動く Claude Code — セルフホスティング公開ベータと8月のリリース

三行要約

  • Claude Code のセルフホスト環境（エージェントセッションを Anthropic のクラウドではなく自組織のインフラで動かす機能）が2026年8月6日に公開ベータになった。Team・Enterprise プラン対象、コマンド一つ（claude self-hosted-runner）で自分のマシンが実行層になる。
  • 同じ週に GitLab マージリクエスト対応（--worktree が MR URL を受け付ける）と auto-continue（使用量上限で止まったセッションを、ウィンドウのリセット時に自動再開 — 8月14日）が続いた。
  • 三つの向きは同じだ — 実行場所・対象プラットフォーム・時間のコントロールをまとめて組織の側へ渡す。承認の判定を規則に移したauto モード既定値の次の一手である。

セッションが組織の境界の内側に入った

これまで Claude Code のリモートセッションは、Anthropic が管理する隔離コンテナで動いていた。コードはセッション開始時に新しくクローンされ、終わればコンテナは回収される — 便利ではあるが、データが組織の外のコンピューターを通るという事実そのものが、金融・医療・防衛のようにデータレジデンシー（データを特定の場所の外に出さない要件）やネットワーク分離の規制を持つ組織には導入不可の理由だった。

8月6日に公開ベータとなったセルフホスト環境は、この境界を動かす。Claude Code v2.1.224（8月7日）に入った claude self-hosted-runner という一つのコマンドで、自分のマシンやコンテナがセッションの実行層になり、エージェントは内部ネットワークのサービス・ツールチェーン・セキュリティ統制のすぐ隣で働く。ランナーの運用は二つのモードがある。

  • 固定（fixed） — ランナーを決まった数だけ常時立てておき、セッションを振り分ける。
  • オンデマンド（on-demand） — 待機中のセッションを監視し、仕事が来たらランナーを立ち上げ、終われば畳む。

既定値はオフで、組織の管理者が設定で有効化する必要がある。ZDR（Zero Data Retention — データを一切保存しない契約オプション）を使う組織はまだ使えない。要するに「誰でもオンにする機能」ではなく、コンプライアンス要件のせいで導入が塞がれていた組織のための通路だ。

同じ週の残り — GitLab MR・auto-continue・Compliance API

GitLab マージリクエスト対応。 claude --worktree が GitHub PR だけでなく GitLab MR URL を受け付けるようになり、エージェント一覧画面で MR が !N と表示される。プラットフォームの判別は git remote と API 探索で行うため、GitLab.com だけでなくセルフホストの GitLab インスタンスも捕まえる — 社内 GitLab を使う組織（この Wiki の AI 開発ナレッジプラットフォーム提案が前提とするまさにその環境）に直接届く変化だ。

auto-continue。 8月14日にデスクトップアプリへ入ったチェックボックス一つ。使用量上限にかかって止まったセッションを、上限ウィンドウがリセットされた瞬間に自動で再開する。上限そのもの（5時間ウィンドウ・週間上限）は変わらない — 変わったのは、リセット後に人が戻ってきて再指示していた作業が自動になった点だけだ。長い自律作業を夜通し走らせる使い方では体感が大きい。

Compliance API の拡張。 セキュリティチームが監査・eDiscovery（電子証拠開示）用にセッション内容とメタデータを一括照会する API が、Cowork と Claude Code のデスクトップ・ウェブ・モバイル・CLI 全表面に広がった（Enterprise ベータ）。

なぜ一つの流れなのか

今週のリリースは一見雑多だが、方向は一つだ。auto モード既定値が「何を許すか」の判定を毎回尋ねる対話からあらかじめ書いた規則に移したとすれば、今週は「どこで動くか」（セルフホスティング）、「何を対象に」（セルフホスト GitLab）、「いつまで」（上限ウィンドウと自動再開）を組織が決める値に移した。エージェントが強くなるほど、コントロールの拠点は対話ではなく環境と規則へ移る — この Wiki が Tip 上級編で権限編集と検証の分離を扱う理由と同じ筋だ。

事実検証ノート

セルフホスティング公開ベータ（8/6）・プラン範囲・ランナー2モード・既定オフ・ZDR 除外は Anthropic 公式ブログ（Run Claude Code sessions on your own compute）と公式ドキュメント（Self-hosted environments）に基づく。v2.1.224 での claude self-hosted-runner 導入（8/7）は nextdev のリリース分析と Classmethod の EC2 実践記で相互確認。auto-continue（8/14）は Anthropic 開発者チャンネルの告知に基づき、上限自体は不変という解釈は explainx の整理と一致する。GitLab MR 対応の詳細（--worktree・!N 表記・セルフホスト判別）は公開リリースノート要約に基づくもので、バージョン単位の確定は上記公式ドキュメントを優先する。
