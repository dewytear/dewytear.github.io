インストールと準備

ハーネスは Claude Code のプラグインとして配布されています。マーケットプレイスを一度登録してインストールすれば、/harness コマンドが使えるようになります。

先に必要なもの Claude Code が入っている必要があります（Install & Start を参照）。ターミナルで作業するプロジェクトのフォルダへ移動し、claude を実行した状態で下のスラッシュコマンドを入力します。

インストールの 3 ステップ

方法 1 — コマンド 2 行（おすすめ）

# 1) ハーネスのマーケットプレイスを追加
/plugin marketplace add lev-factory/harness
# 2) ハーネスプラグインをインストール
/plugin install harness

インストールの画面が出たら User スコープで入れます（自分のアカウント全体で使える）。特定のプロジェクトだけで使いたいときはプロジェクトスコープを選びます。

方法 2 — /plugin の画面から

  1. /plugin と入力 → 方向キーの右で Marketplace タブへ移動。
  2. Add Marketplace に lev-factory/harness を入力 → Enter。
  3. 一覧から harness を選択 → インストール画面で Enter → User スコープで導入。

インストール後 — リロードして確認

# プラグインを現在のセッションに反映
/reload
# 下が補完・実行できればインストール成功
/harness

/harness と入力して補完が出れば準備完了です。ここからはじめてのハーネス実行へ進みます。

注意 — マーケットプレイスのアドレスを確認 上の lev-factory/harness は講義で言及された例の値です。実際に入れるときは配布者の GitHub リポジトリのパスを確認して入れてください（検索語:「ハーネス 100」）。インストールできないときはコマンドの方法 ↔ /plugin 画面の方法を交互に試してみてください。
社内環境でのコツ 社内ネットワークやプロキシの環境では GitHub へのアクセスが制限されることがあります。マーケットプレイスの追加が失敗したら、ネットワーク／プロキシのポリシーと Git のアクセス権限をまず確認してください。プラグインはマシンごとに個別インストールが必要です（エージェントの定義は Git で共有できますが、プラグイン自体は各自でインストール）。
