グラフを読む 9 つの眼 — ビューごとに違う問いに答える

同じ知識グラフでも、何が知りたいかによって合う可視化は変わります。Knowledge Graph 画面のドックは、まず 3D・2D を選び、その中のビューを選ぶ 2 段構えで（既定は 3D）、全部で 9 つのビューがあります。それぞれ、異なる問いひとつに答えるように選ばれています。この文書は「このビューで何を見ればよいか」を整理します。

9 つの眼 — すべて同じインデックスから描かれるので、どのビューでもデータはひとつです。

ビュー別「この問いにはこのビュー」

ビュー答える問い読み方
Constellation（星座・3D）知識の全体はどんな形か？丸い球の上で色 = World/System。同じ色のパッチがひとつの主題クラスターで、パッチを横切る線が主題どうしの橋です。設定で丸み（0〜100）を調節できます。
Orbits（軌道系・3D）ひとつの System にどんな文書がつながれているか？World が恒星、System がそのまわりを回る惑星、文書が惑星を回る衛星です。軌道面が互いに傾いているので所属がひと目で分かれ、実際に公転するので静止画より系譜が読みやすくなります。文書を押すと、その文書の隣だけを残してカードが開きます。
Strata（ストラタ・3D）4 階層は実際にどうつながっているか？World → Domain → System → Document を四枚のガラス板として積み、系譜線を上下に貫かせます。このウィキの階層モデルそのものを目で確かめるビューで、いちばん下の文書層には概念エッジが低い弧として敷かれます。
Bundlingどの文書どうしが引き合っているか？円周に文書が System 順に並び、概念のつながりが中心へ曲がって束になります。太い束 = 強く絡んだ主題の組。
ChordSystem どうしはどれだけ結合しているか？弧の長さ = その System の対外的なつながりの量、リボンの太さ = ふたつの System のあいだのつながりの数。いちばん太いリボンが知識の実質的な隣人関係です。
Packingどこに知識が多く積まれているか？World の円のなかに System の円、そのなかに文書の点。円の大きさ = 文書数 — 成長の偏りがひと目で見えます。
Concepts概念どうしはどうつるんでいるか？ノードが文書ではなく概念である唯一のビュー。いっしょに登場する概念どうしがつながり、語彙レベルの知識の地形（例: 「スキル」のまわりに何が集まるか）を見せます。
Arcつながりは隣の中か、遠くへ行くのか？文書を一列に並べ、つながりを弧で描きます。低い弧 = 同じ主題の中、高い弧 = 主題を飛び越える橋。
Matrixどのブロックが密集で、どこが空白か？文書×文書の格子につながりを点で。System 順に並ぶので対角ブロック = 内部の結束、ブロック外の点 = 交差するつながり、空いた領域 = まだつないでいない知識。

広げて触れるグラフ — グラフスタジオ

上の9つのビューが“焼き込んで見せる”表現なら、グラフスタジオは同じデータを物理で広げて直接触る画面です。力指向レイアウトで文書と共有概念が群れをなし、ノードをつかんで引くと水滴のように揺れ、隣接が引っ張られてきます。ノードを押すと隣接だけが目覚め（フォーカス＋コンテキスト）、説明と関係がカードで出ます。検索で特定ノードにスポットライトを当て、設定パネルで反発・バネ・概念ノードの範囲などを直接調整できます。

作成モードはarrows.app風の教育用です — 白紙に自分の知識グラフを描き、ダブルクリックでノード、ノードの縁からドラッグで関係を結び、その際このウィキの関係5種（前提知識・実装・事例・根拠・置き換え）の語彙をそのまま使います。探索画面の文書カードの“作成モードへコピー”で実際のグラフの一部を切り出して始めることもできます。描いたものはブラウザに自動保存され、JSONで書き出せます。

ハブとブリッジ — グラフの中心を見つける方法

ビューが何であれ、分析の入り口はふたつです:

  • ハブ（hub） — ほかの文書からいちばん多く参照される文書。現在の同率 1 位はLLM Wiki とナレッジコンテキスト・拡張機能（各被参照 9 回）で、ハーネスの構成と効果が 8 回で続きます。ある主題を初めてつかむときは、そのクラスターのハブから読むのがいちばん速い方法です。
  • ブリッジ（bridge） — 複数の System にまたがって登場する概念。「スキル」は 7 つの System にまたがる最大のブリッジで、「スラッシュコマンド」・「サブエージェント」がそれぞれ 5 つの System をつなぎます。ブリッジの概念をたどると、主題と主題が実際に出会う地点が見えてきます。

ハブ・ブリッジ・System 別の集計は知識マップが表で見せてくれ、文書が追加されるたびにライブで再計算されます。要するに — 知識マップは「まとめられた表」、9 つのビューは「同じデータの可視化」であり、この文書シリーズはそのデータが作られる原理（前編）と消費されるかたち（次編）を説明します。
