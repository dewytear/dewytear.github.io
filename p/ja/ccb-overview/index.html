講義の概要と目標

この資料は「Claude Code 基礎 / ファン・ミンホ」の実習講義を映像の順に整理したものです。開発者ではない方にとってターミナルは不慣れな環境ですが、たったひとつの山 — 「フォルダを作り、その場所で claude を実行すること」さえ越えれば、そこから先は AI がほとんどの仕事を代わりにやってくれます。今日の目標はターミナルと仲よくなることです。

この講義でできるようになること

  • ターミナルでフォルダを作り、Claude Code を実行する。
  • CLAUDE.md で自分だけの作業方針を与える。
  • ウェブ調査 → ファイル保存 → ウェブサイト生成までを一度に任せる。
  • 繰り返し作業をスキル（Skill）に、専門的な作業をエージェント（Agent）にして再利用する。
  • プラグインを入れて PDF・PPT・エクセルの文書を扱う。
  • 使用量・コンテキスト・セッションを管理して品質とコストを調節する。

もう一歩 — ハーネス（Harness）

数行のプロンプトで、チーム編成から執筆・挿絵・変換・ウェブサイトまで約 1 時間で仕上がります。

基礎の山を越えると、その次にハーネス（Harness）が待っています。ハーネスを使えば、数行のプロンプトだけで 200〜300 ページを超える本を一冊つくり出せます。講義で見せられた例はこう動きます。

  • 本を書くエージェントを複数（例: 5 つ）作る。
  • リサーチのエージェントが本の素材を用意する。
  • エージェントたちが並列で執筆し、完了を報告する。
  • 必要な挿絵の画像まで生成し、正確な位置に挿入する。
  • 成果物をマークダウン・PDF に変換し、ページをめくって見るウェブサイトまで作る。 — 所要は合計およそ 1 時間。

つまり「Claude Code を始める人のための自分だけの本」も自分で作れます。ハーネス自体はこのあと別のセッションで扱います。
