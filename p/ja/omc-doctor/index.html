インストールの診断

インストール後に問題が起きたら、まず診断のコマンドで状態を確認します。

プラグインの環境では下のコマンドを優先して使います。

# インストール・設定の状態を点検し、問題を知らせてくれる（問題解決の第一歩）
/oh-my-claudecode:omc-doctor

CLI ランタイムの経路を別に使っている場合は、次の診断もできます。

# CLI ランタイムの経路で診断
omc doctor
# プラグインのインストール先を直接指定して診断
omc doctor --plugin-dir /path/to/oh-my-claudecode
