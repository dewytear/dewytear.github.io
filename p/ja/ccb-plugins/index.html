プラグイン・マーケットプレイス

複数のスキルをまとめてプラグインの形で配布できます。論文はたいてい PDF なので、PDF をうまく読むスキルの入った公式のドキュメントスキル（document-skills）プラグインを入れてみます。

1）マーケットプレイスの追加

Claude Code で /plugin と入力して Enter を押すと、プラグインの画面が出ます。矢印キーでマーケットプレイスを選び → Add Marketplace で Anthropic 公式のマーケットプレイスを追加します。

# GitHub への接続が塞がれていたり UI が難しいときは、コマンドで直接実行
/plugin marketplace add anthropics/skills

2）document-skills のインストール

追加したマーケットプレイス（Anthropic 公式）にはプラグインがいくつかありますが、そのうち document-skills だけを入れます。一覧で Space で選び、Enter でインストールします。コマンドでもできます。

/plugin install document-skills

このスキルは PDF・PPT（pptx）・エクセルといった文書を Claude Code で読めるようにしてくれます。

3）再起動して確認

インストール後にうまく反映されないときは、/exit で Claude Code を出てから再起動します。そのうえで /pdf または /pptx と入力してコマンドが出ればインストール成功です。出なければマーケットプレイスの追加とインストールをやり直します。

インストールで詰まったとき（GitHub のエラーなど） Google で 「anthropic skills github」と検索して公式リポジトリに入ると、README の途中にインストールのコマンドがあります。plugin marketplace add ... の一行と plugin install document-skills の一行をそれぞれコピーして Claude Code に貼り付けて実行すれば大丈夫です。
