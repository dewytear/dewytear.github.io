ツールの拡張とまとめ

Claude Code vs Gemini（Antigravity）

AI ツールは抜きつ抜かれつで進化します。いまは Claude Code がいちばん良いのですが、講師は Antigravity CLI（agy コマンド）も併用しています。

項目Claude CodeAntigravity (Gemini 3.5 Flash)
生成の速度毎秒およそ 50〜60 トークン約 4 倍速い
画像の生成モデル自体は不可（codex-image スキルで可能）可能（ナノバナナ）
結果の品質講師の所感ではよりきれいに出る速いが手直しが要る

モデルごとの性能・速度・価格は Artificial Analysis のサイトで比べられます。（Opus・GPT 5.5 は価格が高めです）

数値についての注記 表の「約 4 倍速い」は公開ベンチマークではなく講師の経験値です。参考までに、並列エージェント構成による速度向上は作業の独立性に応じて約 2 倍から最大 10 倍まで報告されています（Anthropic は複雑なクエリで所要時間 90% 短縮を報告）。

Codex CLI による二次検証

単一のモデルによる検証は偏りうるので、Codex CLI（GPT 5.5）をつなぐスキルで、QA エージェントに二次検証を足せます。

# 構成の変更が必要なときは /harness で指示
/harness QA エージェントは Codex CLI を使って検証するように修正
  • QA エージェントが二重検証のプロトコルに更新 — Claude で一次、Codex CLI で二次、ふたつの意見を統合。
  • ワークフローを知っている必要があるので、オーケストレーターも一緒に更新されます。
  • こうしたハーネス構成の変更履歴は CLAUDE.md に記録されます。

エージェントと 1 対 1（ワンオンワン）

特定のエージェントとコーヒーチャットのように会話しながら再設計できる機能もあります。エージェントの一覧から相手を選ぶと、そのエージェントが自分の役割・原則を説明し、「どの部分を直しましょうか？」と尋ねてきます。

まとめ — 人が集中すべきこと

エージェントが多くの仕事を代わりにやる入口に立ったいま、人は次のことに集中すべきです: 目標の設定、文脈をふまえた判断、品質の基準、責任と倫理、良い問い、システム的な思考、ドメインの専門性、評価とフィードバック、AI との協業。

Q&A の要点 · エージェントが /agents に出ないのはリストに見えないだけで、再起動すればロードされる（動的ロードに失敗すると通常のサブエージェントとして立ち上がることも）。
· オートモード — Shift+Tab で auto/accept/plan のモードを切り替え。オートモードは権限を毎回たずねないのでより自律的に動く（途中でいつでも切り替え可）。見えなければ Claude Code の更新が必要（native インストールは自動更新、npm インストールは手動）。
· エージェント・スキルはプロジェクトごとの .claude にできるので Git で共有できる。プラグインは環境（PC）ごとに個別インストール。
· 実務ではデモと違い、詳しい要件とデータを一緒に渡すと（長ければマークダウンで）意図が確実に伝わります。
