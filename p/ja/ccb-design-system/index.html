デザインシステムの抽出

ウェブサービスを開発するときは、ふつうデザイナーが作ったデザインシステムを受け取り、それをもとに開発者が画面を作ります。Claude Code ではこの流れを逆に — すでに出来上がったサイトからデザイン要素だけを抜き出してデザインシステムを作れます。

抽出の依頼

完成したこのサイトのデザイン要素を抽出して、
別のデザインシステムを作って。

何が整理されるのか

いまのサイトのデザイン要素だけを抜き出し、ひとつの文書として定義します。

  • カラーパレット
  • テキスト（タイポグラフィ）のスタイル
  • コンポーネント — ボタンのスタイル、配置（レイアウト）のスタイル
  • アニメーション効果

なぜ作るのか

デザインシステムをいちど作っておけば、これから作るサイトを同じデザインでいくらでも量産できます。社内システムを開発するときや、2 番目・3 番目のサイトを作るときに同じトーンを保てますし、同僚に渡して共有するのにも向いています。

次のステップ こうして作ったデザインシステムはそのまま再利用してもよいのですが、「これからもずっと使う」ならスキル（Skill）にしておくほうが便利です。（次の文書で扱います。）
