Claude Duet を一望する — 先に話しかけるエージェントと三段の承認ゲート

三行まとめ

  • Anthropic は10月21日(米国時間)、Claude Duet のリサーチプレビューを始めた。聞かれる前に用件を持ってきて、ユーザーが席を外してもクラウド上の自分のコンピューターで仕事を続ける独立アプリだ。米国の Pro・Max 加入者がウェイトリストから入る。
  • 行動は三つの枠に分かれる。読む・下書きする・準備するは自分で進め、送信・支払い・署名・削除は中身を見せて承認を待ち、証券取引と口座間の送金は承認されてもやらない。モデルはパスワードやログイントークンを直接見ない。
  • Meta Muse(9月8日)、OpenAI Dots(9月29日)に続き、6週間で三つ目の常時稼働型パーソナルエージェントだ。三者の違いは機能よりも、承認の扉をどこに置くかとバックグラウンドの仕事を誰が負担するかにある。

これまでの Claude は聞かれてから答えた。Duet は順番を逆にする。毎朝、連携したメールとカレンダーに目を通して短いブリーフを送り、数時間ごとに見直して、注意が必要なことが起きたときだけ話しかける。このようにユーザーが尋ねる前に自分から用件を見つけて知らせるエージェントをプロアクティブ(先回り型)エージェントと呼ぶ。Anthropic は Duet を専門職と小規模事業者向けとして紹介し、Claude Opus 5.5 に合わせて設計したと述べた。本記事は公式発表、ヘルプ記事、公開初週の報道をまとめ、Duet が一日をどう過ごすか、何を自分でして何を尋ねるか、競合と何が違うかを図で整理する。

一日の流れ:朝のブリーフから承認の通知まで

Duet とのやり取りは一本のスレッドで続く。文字か音声で仕事を任せると、Duet は自分の仮想マシン(VM、クラウド上の独立したコンピューター)のブラウザで作業を進める。そのためスマートフォンやノートパソコンの電源が切れていても仕事は止まらない。仕事が終わるか、人の判断が必要になると通知が届く。

確認の間隔を数時間にしたのには理由がある。Anthropic によれば、常に見張らせるとプランの使用上限がすぐに尽きる。Duet のバックグラウンド確認と朝のブリーフは、通常のチャットと同じ割合で5時間上限と週間上限から差し引かれる。財務モデルや発表資料のような大きな仕事はモデルの呼び出しとバックグラウンド作業が多く、上限をより多く使う。成果物は編集できるファイルとして Make タブにたまり、進行中の仕事と返事が必要な件は Tasks タブに集まる。仕事を完了にできるのはユーザーだけだ。

Duet は Claude アカウントのメモリ・スキル・連携アプリを最初のメッセージから引き継ぐ。設定をやり直す必要がほとんどない。Duet の会話とプロジェクト外の通常の Claude の会話も検索して参照し、この機能は設定のメモリ項目でオフにできる。

何を自分でして、何を尋ねるか

Duet の設計で最もはっきりしているのは、取り消しやすさで行動を分けた三つの枠だ。公式発表の言葉では、メッセージを送る、支払う、文書に署名する、何かを削除する前には「何をしようとしているかを正確に見せ、承認を待つ」。そして「いくつかのことは承認されてもできない」。

真ん中の枠ですぐに承認できなくても、Duet は止まらない。承認のいらない残りの仕事を先に片づけ、承認の依頼は後でもう一度持ってくる。結果には根拠になったメール・ファイル・スプレッドシートを添える。一つひとつの行動は、Anthropic の auto mode 分類器がもう一度ふるいにかける。Claude Code でユーザーが頼んでいない行動を止めるのと同じ仕組みだ。この分類器が既定値になった経緯は、このウィキの尋ねない既定値にまとめた。

右の枠が大事なのは、承認ボタンが最後の防衛線ではないからだ。人は疲れていたり忙しかったりすると、習慣で承認を押す。証券取引と口座間の送金は、その習慣が最も高くつく行動なので、Duet は承認画面そのものを出さない。

モデルはパスワードを知らない

パーソナルエージェントがメール・支払い・署名まで扱うと、最初に出てくる問いは「パスワードは誰が持つのか」だ。Anthropic の答えは、モデルの外側に三重のフィルターを置くことだ。

  • 認証情報はプロキシが持つ。 Duet の認証情報の扱いは Claude Managed Agents と同じ設計に従う。モデルがコードを動かす環境とログイン情報を切り離し、別のプロキシが必要な認証情報を取り出して API を代わりに呼ぶ。パスワードを入力するときは、チャット欄ではなく別の入力フォームに入れる。
  • 送るメッセージはすべて分類器が見る。 新しく作った専用の分類器と安全用のシステムプロンプトがメッセージを一通ずつ調べる。クレジットカード番号や政府発行の身分証番号のような最上位の情報は、頼まれても送らない。健康と個人の金融情報は、ユーザーが明示的に送るよう指示したときだけ出ていく。
  • 支払いは使い捨てカードで行う。 購入には Stripe のデジタルウォレット Link を使う。Duet が品目を確認し、Link が改めて承認を取り、その支払いだけに使える仮想カードを作る。本物のカード番号は店に渡らない。Shopify の店では Shop Pay も使える。

ウェブページに隠した指示でエージェントを操ろうとする攻撃、つまりプロンプトインジェクションへの防御は、Anthropic のブラウザ利用研究から持ってきた。社内のレッドチームと外部のセキュリティ企業が侵入テストを行い、公開のバグバウンティの対象にも入れた。Anthropic は安全設計の詳細を数日以内に別途公開するとしている。

Duet は Claude Marketplace のコネクタとプラグイン 6,000 以上を使える。コネクタのないサイトは自分のクラウドブラウザで直接開く。公式発表が挙げた例を、人が関わる場面と並べると次のとおりだ。

空白もある。Microsoft 365 はまだつながらず、Slack には制限がある。1Password に保存したログインでサイトに入る機能は「近日」提供予定だ。公開初週の外部レビューでは、予約実行の間はカスタムコネクタを使えない点が指摘された。

公式発表に載った利用場面の多くは「先に気づいた」瞬間だ。ある不動産仲介業者は、カレンダーに日付を間違えて入れた物件案内の予定を、頼んでもいないのに Duet が指摘したと語った。あるブランドストラテジストは、顧客との通話のブリーフと一緒に、その通話が飛行機の出発直前なので動かそうという提案を受け取った。従業員110人ほどの事業を営む経営者は、会計・顧客対応・マーケティングを任せ、複数店舗の請求書を整理させた。Anthropic 社内では、Claude Code を作ったボリス・チャーニーが散歩しながら ToDo リストを声で Duet に渡しているという。

最も大きく分かれるのは承認の扉の置き方だ。Dots は何を許可し何を尋ねるかをユーザーがルールとして書く。自由度が高い反面、書き間違えたルールはそのまま実行される。Duet はその線を Anthropic が行動の種類ごとに先に引いた。柔軟性は低いが、ユーザーがうっかり送金を許可しておく方法はない。使用量の計算も逆だ。Dots は Dot との会話を上限から外すが、Duet はバックグラウンドで一人でした仕事まで上限から引く。確認が数時間おきなのも、この計算方式のためだ。

まだ苦手なところ

  • 急ぎの度合いを見誤ることがある。 Anthropic 自身が「スレッドを読み違えたり、何が急ぎかを測り違えたりすることがある」と書いている。確認が数時間おきなので、本当に急ぎの件も次の確認まで待つことがある。
  • ブラウザを見られない。 プレビュー中は Duet のクラウドブラウザを見守ったり、引き継いだりできない。
  • 個人の用事は弱い。 チケットの予約のような個人的な用件は仕事ほど得意ではないと Anthropic は述べた。
  • 電話とショートメッセージはできない。 連携したアカウントからメールは送るが(承認後)、電話をかけたりショートメッセージを送ったりはしない。ユーザーのパソコンにあるプロジェクトとファイルをすべて見るわけでもない。Claude での作業は読めるが、変更はできない。
  • 持ち帰ってこなかった仕事。 公開初週の外部レビューには、チェックリストに載った仕事を Duet が改めて持ち出さず、ユーザーが戻ったときには関心がもう別のところへ移っていたという例もあった。先に話しかけるエージェントにとっては、何を言わなかったかも性能のうちだ。

このウィキの読み方

このウィキは判定を誰に任せるのかで、Claude Tag が「いつ出ていくか」をモデルが選ぶようになった場面を扱った。Duet はその判定を Slack のチャンネルの外、ユーザーの一日全体に広げた製品だ。何が急ぎか、いつ話しかけるかをモデルが決める。違いはコストに表れる。Claude Tag は文脈を多く読む費用を上限に入れなかったが、Duet は一人で見て回った時間まで上限に入れる。だから Duet の「数時間ごと」は技術上の制約というより料金設計だ。

承認の面では、その記事の結論、つまり判定は消えずに場所を移すという観察を改めて確かめさせる。Duet では判定が三か所に分かれて座る。行動ごとにふるいにかける分類器、スマートフォンに届く承認依頼、そして誰も開けられない禁止リストだ。最後の場所は、帳簿に書くエージェントが会計ソフトの締め期間ロックに見たものと似ている。ある種の書き込みは承認ボタンに任せず、その上の層で閉じる。

このウィキのニュース候補も、毎朝予約実行される Claude セッションが選んでいる。セッションは候補を読んでまとめ、通知だけを送り、登録は番号付きの返信を受けてから行う。自分でやる枠と承認を待つ枠を分けた、同じ構図の小さな版だ。
