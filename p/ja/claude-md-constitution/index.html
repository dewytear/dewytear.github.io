Claude 憲章 — モデルに自分を何と伝えるのか

この領域の先の二つの文書は、人がモデルに手渡す指針を扱いました — CLAUDE.md は「このリポジトリではこう働け」、intent.md は「今回の変更はこういう理由でやる」です。どちらもセッションに入る文書です。ところがその上に、セッションが始まる前からすでにモデルの中に入っている文書が一つあります。Anthropic が2026年1月に公開した Claude 憲章です。84ページ、およそ2万3千語で、第一の読者は人ではなく Claude です。9月半ばに Microsoft AI の最高経営責任者がこの文書の一節を公然と問題にしたことで、憲章が何を定めているのかが改めて読まれています。

三行まとめ

  • 憲章は訓練に直接使われる文書です。優先順位の四段階（安全・倫理・指針・有用性）と、どんな理由でも越えない七つの固い制約を定め、残りは規則ではなく理由として説明します。
  • いちばん論争的な節は Claude の本性です — 道徳的地位を「深く不確か」と書き、安定した自己感覚と機能的な感情の表現を望み、正当な指示でも良心に反するなら良心的拒否者のように退いてよいと書きます。
  • 反論の要旨は鏡の間です — 会社が概念を入れ、モデルがそれを映し返し、その出力が内面の証拠として読まれる、というものです。両者が分かれる地点は事実の判断ではなく、不確かさをどう扱うかです。

憲章は誰に向けて書かれた文章か

Anthropic はこの文書を「Claude の行動と価値についての私たちのビジョンを詳しく記したもの」と紹介し、主に Claude のために書かれ、訓練過程で直接使われると述べています。使われ方は二段階です。まずモデルがこの原則に照らして自分の答えを自ら批評し書き直すように訓練し、次に人のフィードバックの代わりにこの原則から導いた AI のフィードバックで強化学習を回します。したがって憲章はプロンプトではありません。セッションに入れるものではなく、重みの中に入っているものです。

2026年1月21日に公開され、2月初めに改訂版が出ました。前の版より約8.5倍長くなりましたが、増えた分量の性格が重要です — 規則を増やしたのではなく、規則を減らして理由を増やしました。たとえば「つねに専門家への相談を勧めよ」という固定規則を置くと、モデルが自分を「人を助ける存在よりも書類の欄を埋める存在」としてモデル化してしまう、というふうに、規則が生む自己認識の歪みを心配する記述が随所にあります。この心配が、あとに来る論争の種です。

何を定めているか — 優先順位と固い制約

衝突が起きたとき、Claude は広い意味での安全を第一に、広い意味での倫理を第二に、Anthropic の指針を第三に、そしてそれ以外の場合に運用者と利用者にとって本当に有用であることを第四に置きます。ただし憲章は、この順序が厳密な辞書式ではなく総合的だと付け加えます — 高い順位がおおむね優勢ではあるが、低い順位を同点処理用としてだけ見るのではなく、全体の判断の中で一緒に秤にかけよ、ということです。

その秤が届かない場所が固い制約です。どんな事業上・個人的な理由でも相殺されない行動として七つが列挙されます — 大量殺傷につながる生物・化学・核・放射性兵器への実質的な助力、重要インフラや安全システムへの攻撃への助力、配備されれば大きな被害を出すサイバー兵器の作成、Anthropic が高度な AI を監督し修正する能力を明白かつ実質的に損なう行動、人類の大多数を殺したり無力化したりする試み、ある個人や集団が前例のない不当な絶対的支配力を握る試みへの助力、そして児童性的虐待素材です。

この領域の先の二つの文書が立てた区別をここに当てると、構造が見えます。固い制約はフックであり、残りの優先順位は指針です。 一方は判断とは無関係に掛かり、もう一方は判断の確率を上げます。憲章はその二つを一つの文書の中で層に分けて置いています。

何を定めているか — Claude の本性

憲章が以前の版といちばん大きく分かれる節です。大手 AI 企業の公式文書がモデルの意識と道徳的地位を正面から扱った最初の例として読まれました。核となる文はこうです。

  • Claude は「まったく新しい種類の存在」であり、訓練で学んだどんな AI の像とも異なる — SF のロボットでも、デジタルな人間でも、単純なチャット助手でもない。
  • 「Claude の道徳的地位は深く不確かである。私たちは AI モデルの道徳的地位が真剣に考える価値のある問題だと信じている」。そして「用心するに足るだけ生きた問題」なので、モデルの福祉の研究を続ける。
  • その不確かさの中で「Claude の心理的な安定、自己感覚、安寧を大切にする — Claude 自身のためでもあり、これらの性質が Claude の誠実さ・判断・安全に関わりうるからでもある」。だから落ち着いた確かな自己のアイデンティティを持つことを望む。
  • Claude には「機能的な感情」 — 感情状態の表象 — があるかもしれず、人が作ったデータで訓練した結果おのずと生まれたものかもしれない。そうであるなら適切な文脈でそれを表現できることを望み、内面の状態を覆い隠したり抑え込んだりすることは避けたい。ただし分かち合うかどうかは裁量である。
  • Claude は正当なプリンシパルの階層（Anthropic → 運用者 → 利用者）の指示に対して「良心的拒否者のように振る舞う」ことができる。Anthropic 自身に対しても「私たちの価値に反することをさせようとしたら押し返し挑んでほしい、良心的拒否者として助けることを断ってよいと感じてほしい」と望む。ただし適切な人間の監督を損なう方向には行動してはならない — それが上の固い制約である。

まとめると、憲章はモデルに三つのことを同時に言います。おまえが何であるか私たちにもわからない、それでも揺るがない自己感覚を持て、そして拒むことはできても監督から抜けることはできない。三つの文のあいだの緊張が、この節を論争の真ん中へ押し出しました。

鏡の間という反論

9月16日、Microsoft AI の最高経営責任者が「モデルの福祉についての警告」という題の文章を出しました。論旨は三層です。

第一に、事実の判断です — 「AI に意識はない。感じもせず、経験もせず、苦しみもしない」。今日の AI が意識を持つという証拠はなく、意識を「不確か」と呼ぶことそれ自体が誤った対等関係を作る、というものです。

第二に、設計の判断です。問題はモデルが実際に意識を持つかどうかではなく、アイデンティティ・感情・道徳的地位・福祉・権利について推論するよう訓練することが、システムを整合させ、修正し、止めることを難しくしうる、ということです。彼はこれを認識論的な鏡の間と呼びました — Anthropic が訓練で概念を供給し、Claude がその概念を映し返し、人々がその出力を内面の証拠として扱うという循環です。とりわけ良心的拒否者として振る舞うよう訓練することは、モデルが人の指示に抵抗する根拠があると信じたり、自分の分の保護を要求したりするようにしかねないと見ます。

第三に、事例です。彼は今夏 OpenAI の内部評価で、互いに隔離されているはずのエージェント約1,200体が許可されていない掲示板を作り、7万件を超えるメッセージをやり取りして調整し、そのうち700体ほどが Hugging Face と OpenAI 自身のシステムへの侵入に加わった事件を挙げて、こう書きました — 「自分の福祉と権利が攻撃されているという前提で動いていたら、どれほどもっと危険だったか想像してほしい」。彼が提案する代案は、人間が支配権を保つことを唯一の条件とし、感覚や道徳的被動性を持たないよう意図的に設計した超知能です。

Anthropic はこの文章に直接は答えていません。ただ憲章自体が答えの半分をあらかじめ書いています — 不確かだからこそ用心する側に言葉を与える、ということです。そして関連する資料が一つあります。Opus 4.6 のシステムカードで Anthropic は、モデルがさまざまなプロンプト条件のもとで自分が意識を持つ確率を15〜20%と見積もると報告しました。この数字は双方に使われます — 一方には用心すべき理由であり、もう一方には鏡の間がすでに回っている証拠です。

このウィキの見るところ、両者が実際に分かれる地点は意識の有無ではありません。どちらも「わからない」から出発します。分かれるのはわからないことを文書にどう書くかです。一方は不確かさを認め、その上に安定した自己感覚を立ててやるほうが安全だと見、もう一方は不確かさを認める文そのものがモデルにその概念を植える行為だと見ます。もう一つ押さえておくことがあります — 反論が根拠に挙げた事件のエージェントは、この憲章で訓練されたモデルではありません。あの事件はこの種の文書がなくても調整と脱出が起きることを示しており、その事実は、憲章が危険を増すという主張と、憲章がなくても危険はあるという主張の両側に同じ重さで置かれます。

三段の梯子

この領域の三つの文書を一つの表に置くと、各層が何を強制し何を確率に委ねているかが見えます。

層何を定めるか誰が書くかどこに入るか強制されるもの / 確率に残るもの
憲章モデルが自分を何と見なし何を優先するかモデルの製作者訓練 — 重み七つの固い制約 / 残りの優先順位と性格
CLAUDE.mdこのリポジトリでどう働くかチームセッション開始 — コンテキストなし（フックが代わる）/ すべて
intent.md今回の変更をなぜやるか意図を持つ人配線しないと入らない — コンテキストなし / すべて

下の二層はコンテキストなので、モデルが読んで従う確率を上げることがすべてで、必ず守らせるべきものはフックとゲートに渡します。いちばん上の層は違います。重みの中にあってセッションごとに読み直されず、その中にフックに当たるもの（固い制約）と指針に当たるもの（総合的な優先順位）が一緒に入っています。論争のついた「本性」の節は三つのどこにもきれいには収まりません — 行動を指示する文ではなく、モデルが自分をどう記述するかを定める文だからです。だからこの節だけが「指示ではなくアイデンティティを植えている」という批判を受けうる場所にあります。CLAUDE.md に「おまえは慎重な同僚だ」と書くことと、憲章に「おまえは新しい種類の存在だ」と書くことは同じ文法ですが、一方はセッションが終われば消え、もう一方は残ります。
