用語のポイント

OMC の文書には次の用語がよく出てきます。先に理解しておくと、以降の内容がぐっと読みやすくなります。

  • スラッシュコマンド — Claude Code の入力欄で / から始める特別なコマンドです。普通の会話ではなく、決められた機能をすぐ実行します。例: /plugin install ...
  • ネームスペース — コマンドの前にプラグイン名が付く形式です。ほかのプラグインと名前がぶつからないようにしてくれます。例: /oh-my-claudecode:autopilot
  • エージェント（Agent） — 特定の役割を負った AI の作業者です。探索・実装・検証のように役割が分かれているので、大きな作業を分担させられます。例: explore、executor、qa-tester
  • スキル（Skill） — ひとつの作業をこなす機能の単位です。自律実行やくり返し実行といった動作がスキルとして提供されます。例: autopilot、ralph、skillify
  • Hook（フック） — 決められた時点（例: ファイル修正の前後）に自動で割り込んで実行される動作です。キーワードの検知や完了の検証などに使われます。例: PreToolUse、PostToolUse
  • プロジェクトメモリ — AI がプロジェクトの構造を覚えていられるように整理しておいた文書です。毎回ゼロから探索するコストを減らします。例: deepinit、AGENTS.md
