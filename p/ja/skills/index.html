Skills

スキル（Skill）は、特定の作業のための専門知識とワークフローを Claude Code に与える、再利用可能なパッケージ形式の能力です。指示文（必要ならスクリプトやリソースまで）をひとまとめにしておくと、依頼がそのスキルの用途に合ったときに Claude が必要な分だけ読み込んで使います。 スキルは通常のスラッシュコマンドと同じく / のあとにスキル名を打って直接呼び出せますし、Claude Code が作業を見分けて関連スキルを自動的に発動することもあります。スキルにできることの例:

  • 現在の diff に対する構造化されたコードレビューの実行
  • 複数の情報源をあたる深いリサーチと、出典つきレポートの作成
  • フック・キーバインド・設定の設計と構成
  • 一貫したデザインシステムに従うデータ可視化の作成
細かなノウハウが毎回打つメッセージではなくスキルの中に住むので、プロンプトは短くなり、結果は一貫します。Claude Code に標準搭載されたスキルを使うことも、プラグインとして入れることも、自分でつくることもできます。
