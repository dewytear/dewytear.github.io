高度なツール

OMC は、コードをより正確に扱うためのツール群を用意しています。テキスト検索より精密な分析が必要なときに役立ちます。

ツール群代表的な機能使いどころ注意点
LSPlsp_hover、lsp_goto_definition、lsp_find_references、lsp_diagnostics正確なシンボルの探索、型エラーの確認、参照の検索typescript-language-server、pyright、rust-analyzer など言語ごとのサーバーが必要
AST Grepast_grep_search、ast_grep_replace構文の構造にもとづく検索・置換テキストの grep より精密だが、パターンを書く力が要る
Python REPLpandas、numpy、matplotlib による分析CSV・ログ・統計の分析データファイルへのアクセス権限とパッケージの有無の確認が必要
Ask / Team CLIomc ask、omc team、omc session search外部の CLI ワーカーとセッションの検索プラグインのインストールの流れと CLI/runtime の経路の区別が必要
LSP の補足 LSP（Language Server Protocol）は、コードエディタが「この変数の定義はどこ？」「ここに型エラーはある？」を正確に突き止められるようにする標準です。ただし、その言語のランゲージサーバーが入っていないと正常に動きません。
