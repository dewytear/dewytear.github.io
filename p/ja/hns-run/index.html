ハーネスを実行する（実習）

意図を渡すだけでチームが組まれ、人がレビュー・承認したあとの実行は手を離れます。

入れた /harness で実際に仕事をさせてみます。核心的な違いは「意図だけを渡す」という点です。

「作成して」ではなく「作成したいと思っています」

ふつう AI には「レポートを作成して」と指示します。しかしハーネスには意図だけを言います。すると、その意図を解決してくれるエージェントチームを組んでくれます。

/harness 2026 年の国家科学技術の全分野にわたる戦略技術の予算配分と、
ポスト PBS への対応戦略について調査し、レポートを作成したいと思っています。
  • /harness と入力して Tab で補完したあと、依頼を続けて書きます。
  • 実行するとドメイン分析 → チーム編成が進みます。
  • 途中で「ハーネスをフル構築 / ハーネスだけ構築」のような選択を尋ねてきます。
  • 自分のデータがあれば一緒に渡して尋ねられます。（例: 1000 ページを超える PDF の分析もきちんと処理）

構成の完了 → レビュー → 実行

ハーネスの構成が完了すると、いったん止まります。作られたエージェントたちをレビューし、問題がなければ実行します。

# レビューのあと、そのまま進行の指示
進めて

この瞬間、作業は人の手を離れ、エージェントチームがリサーチ → レポート作成 → QA をオーケストレーターの立てた順序どおりに最後まで進めます。

並列でいくつもの作業

  • ひとつの作業を回しておいて、別のターミナル窓を開いてまた別の仕事をさせられます。（例:「KOSPI は 1 万まで行けるか？」の調査）
  • 実務の開発者の席では、こうしてターミナルがいくつも開いていて、別々の仕事を同時にしています。
  • Shift + 方向キーで、いまスポーンされているエージェントが何をしているかを見られます。（色の付いたエージェントが作業中）
何に使うのか データ分析、リサーチ、レポート作成、シミュレーションなど — 何であれ意図を渡せば、その仕事をするエージェントチームを組んでくれます。
