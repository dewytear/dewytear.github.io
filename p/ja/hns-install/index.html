メタハーネススキルのインストール（実習）

ハーネスを毎回手で組む（エージェントやスキルをいちいち用意する）のは面倒です。そこで講師は目標を渡すだけでハーネスを代わりに組んでくれる「メタハーネス」スキルを開発して GitHub に公開し、多くの使用レポートとスターを集めました。今日の実習は、このスキルを入れるところから始めます。

方法 1 — コマンド 2 行

# 1) ハーネスのマーケットプレイスを追加
/plugin marketplace add lev-factory/harness
# 2) ハーネスプラグインをインストール
/plugin install harness

方法 2 — /plugin の UI

  1. /plugin と入力 → 方向キーの右で移動して Marketplace タブを選ぶ。
  2. Add Marketplace で lev-factory/harness を入力 → Enter（GitHub からダウンロード）。
  3. プラグインのインストール画面で Enter → User スコープで入れると、どのプロジェクトでも使えます。

インストール後 — リロードして確認

インストールが終わると「リロードせよ」という案内が出ます。/reload（プラグインのリロード）のあと /harness が出れば、正常にインストールされています。

/reload
# 下が補完・実行できればインストール成功
/harness
マーケットプレイスのパスを確認 マーケットプレイスのハンドル（lev-factory/harness）は発表で言及された値を写したものなので、実際に入れるときは講師の GitHub（例:「ハーネス 100」で検索）で正確なリポジトリのパスを確認してください。プラグインのインストールがうまくいかないときは、UI の方法とコマンドの方法を交互に試します。
