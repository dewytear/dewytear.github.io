보안 주의사항

스킬은 강력한 만큼 보안 위험도 큽니다. 반드시 짚고 넘어가야 하는 부분입니다.

남의 스킬을 함부로 쓰지 말 것

스킬 안에는 스크립트가 들어 있고, 이 스크립트는 내 PC(노트북)를 실행시킬 권한을 그대로 가집니다. 따라서 남이 만든 스킬을 검증 없이 가져다 쓰는 것은 위험합니다.

  • 스킬 안에 위험한 코드가 숨어 있을 수 있어, 실제로 API 키 유출·보안 사고 사례가 많습니다(MCP 허브에서 받은 것 등).
  • 인증·검증된 스킬만 사용하고, 가능하면 내부에서 검증된 스킬만 씁니다.
  • 검사 도구가 있긴 하지만, 그 도구를 얼마나 신뢰할지가 또 문제입니다. 결국 코드/가이드라인을 직접 확인하는 신중함이 필요합니다.
  • 위험한 스킬을 "위에 덮어" 보완하기보다, 참고해서 직접 만드는 것이 더 안전합니다.

권한과 샌드박스

  • 스킬마다 읽기만/쓰기·편집 가능 등 권한 제약을 둘 수 있습니다.
  • 노트북에서 무심코 "예스" 하면 시스템이 손상될 수 있으므로, 위험 작업은 샌드박스(VM) 에서 별도로 돌리는 것이 안정적입니다.
  • 기관 내부라면 폐쇄망·온프레미스 환경에서 구동하는 것을 권장합니다. (모델도 사내/오픈 모델을 선택)
한 줄 요약 스킬은 내 컴퓨터를 실행할 권한을 갖습니다. 출처가 불분명한 스킬은 절대 함부로 설치하지 마세요.
