시작하기

Claude Code는 Anthropic이 만든 Claude 공식 CLI(명령줄 인터페이스)입니다. 터미널 안에서 살아가는 에이전틱 코딩 도구로, 여러분의 코드베이스를 이해하고 반복 작업 실행·복잡한 코드 설명·git 워크플로 처리를 대신해 줍니다 — 모두 자연어 명령만으로요. 채팅 창과 에디터 사이에서 코드를 복사해 붙여 넣는 대신, 프로젝트 디렉터리에서 Claude Code에게 직접 말을 겁니다. 파일을 읽고 수정하고, 셸 명령을 실행하고, 코드베이스를 검색하고, 테스트를 돌리고, 커밋까지 대신해 주며 — 위험한 일은 진행 전에 허락을 구합니다. Claude Code는 터미널 CLI, 데스크톱 앱(Mac/Windows), 웹 앱(claude.ai/code), IDE 확장(VS Code, JetBrains)으로 쓸 수 있고, Opus·Sonnet·Haiku 같은 최신 Claude 모델로 구동됩니다.

설치와 시작

가장 빠른 시작 방법은 네이티브 인스톨러입니다 — 의존성 없이 명령 한 줄이면 되고, Claude Code를 자동으로 최신 상태로 유지해 줍니다.

  • macOS / Linux / WSL: curl -fsSL https://claude.ai/install.sh | bash
  • Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
  • 프로젝트로 이동: cd your-project
  • 실행: claude
Homebrew(brew install --cask claude-code)와 WinGet도 지원합니다. npm 설치(npm install -g @anthropic-ai/claude-code, Node.js 22 이상 필요)도 여전히 동작하며 같은 네이티브 바이너리를 설치합니다. 처음 실행하면 Claude Code가 인증 과정을 안내합니다 — Claude 계정(Pro/Max 플랜)으로 로그인하거나 Anthropic API 키를 쓸 수 있습니다. 그다음부터는 원하는 것을 평범한 말로 설명하면 됩니다. 예: "인증 흐름을 설명해줘", "다크 모드 토글을 추가하고 테스트를 돌려줘". 알아 두면 좋은 시작 플래그 몇 가지:
  • claude — 대화형 세션 시작
  • claude "프롬프트" — 일회성 작업 실행
  • claude -c — 가장 최근 대화 이어가기
  • claude --help — 전체 옵션 보기

일상 사용

설치와 인증이 끝났다면, 대부분의 경우 원하는 것을 자연어로 적기만 하면 Claude Code가 알아서 일합니다 — 파일을 읽고, 코드를 고치고, 명령을 실행하고, 위험한 일 앞에서는 허락을 구하면서요. 평범한 프롬프트와 함께, 세션을 다루는 내장 슬래시 명령어도 있습니다:

  • /help — 사용 가능한 명령 보기
  • /clear — 새 대화 시작(컨텍스트 초기화)
  • /init — 프로젝트를 설명하는 CLAUDE.md 파일 생성
  • /review — PR 또는 작업 중인 변경사항 리뷰
  • /config — 설정 열기(테마·모델 등)
  • /model — 사용할 Claude 모델 전환
큰 차이를 만드는 두 가지 팁:
  • CLAUDE.md — 프로젝트의 규칙·명령·컨텍스트를 적어 두는 저장소 안의 파일. Claude Code가 자동으로 읽으므로 같은 말을 반복할 필요가 없습니다.
  • Plan mode — 수정 전에 계획부터 세우게 하는 모드. 큰 작업일수록 코드가 바뀌기 전에 접근 방식을 먼저 승인할 수 있습니다.
여기까지가 기본기입니다. Claude Code의 진짜 힘은 확장에서 나오는데, 스킬·MCP 서버·훅 세 갈래가 그 통로입니다 — 확장 기능 편에서 이어집니다.
