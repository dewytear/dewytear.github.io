Installation Diagnosis

If a problem comes up after installing, first check the state with the diagnosis command.

In a plugin environment, use the command below first.

# Checks the installation and configuration state and tells you about problems (the first step in troubleshooting)
/oh-my-claudecode:omc-doctor

If you separately use the CLI runtime path, the following diagnosis is also possible.

# Diagnose from the CLI runtime path
omc doctor
# Diagnose by pointing directly at the plugin installation folder
omc doctor --plugin-dir /path/to/oh-my-claudecode
