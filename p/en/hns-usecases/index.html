Use Cases — From Content to Research

The harness has such a wide range of uses that it would be a waste to use it only for development. These are cases the instructor built himself.

Novel — "The Age of Agents"

When he said "let's write an SF novel", the agents and skills for writing a novel got created.

  • Character design agent — creating and developing the characters.
  • Worldbuilding agent — building the technology system and social structure of the setting (e.g. 2028–2032).
  • Science advisor agent — identifying and strengthening scientific errors · unrealistic elements in the manuscript.
  • Brainstorming, science verification and the like were made into skills and injected into the agents.

Flow: a one-line logline → the whole plot outline (a plan for tension and paying off foreshadowing chapter by chapter) → pre-generating the character · worldbuilding material → since the content of each chapter is already fixed, writing in parallel → science verification (e.g. correcting a random string into a string that is actually interpretable by a real algorithm and reflecting it).

Webtoon

When a webtoon was made from that same novel, a webtoon artist agent appeared, and a quality verification agent (checking character consistency · speech bubbles · errors) that catches odd panels was added. A loop was created to draw again when verification fails, so it ran through with a single "draw chapters 2 through 12".

Other cases

  • Onboarding guide — researching and organizing what has happened since ChatGPT in December 2022.
  • Markdown viewer (mdview.kr) — first deployment in 40 minutes to an hour with a harness. Supports HWP import, and documents are stored only in the browser without being sent to a server.
  • Survey of the national AI data center — organizing the numbers and the timeline, plus critical/positive press analysis and the problems (business viability · GPU supply · power · data sovereignty). Because it is source-based, hallucination dropped sharply.
  • Organizing things in newspaper style, planning research for an exam question service, and generating several UI templates to compare (planning with visible deliverables).
What they have in common Rather than "just write it", the agents · skills · workflow for doing that work are created first, and the result comes out on top of pre-planned material and a verification loop.
