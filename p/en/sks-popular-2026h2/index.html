Popular Skills of H2 2026 — The Top Seven by Installs, and How to Use Them

In three lines

  • As of October 22, 2026, the most-installed skill on skills.sh is find-skills (about 3.98 million). In the official Claude plugin directory, frontend-design (about 1.13 million) and Superpowers (about 1.01 million) are first and second.
  • The top of the list falls into five kinds: a skill that finds skills, a skill that interrogates your plan, skills that give the agent hands (a browser, video), skills that plant taste and rules, and a skill that bundles a whole development method.
  • Install counts are not quality scores. Each counter uses a different unit, and skills.sh counts per repository, so a repo with many skills fills several rows at once.

A skill is a single markdown file (SKILL.md) plus its folder that an agent reads when it needs it. The description in the frontmatter at the top decides when the skill is pulled in. The mechanics are covered in What Skills Are and Structure & Mechanics. This article picks the most-installed skills of the second half of 2026, reads each skill's original SKILL.md directly, and sets out what it does, how to use it, and where it pays off.

Where the rankings come from

"The most popular skill" is hard to state as one number. Several places count skills, and each uses its own unit. Even frontend-design gets a different number depending on who counts.

skills.sh is the skill directory run by Vercel, and it counts installs made with the npx skills command. There is a catch. Installs are counted per repository, so when one repo holds several skills, the skills installed together rise side by side. That is why five of the top ten below come from mattpocock/skills and two from heygen-com/hyperframes. An open dataset that merges several rankings and publishes them daily (LinklyAI best-skills, CC BY 4.0) states this limitation itself.

1. find-skills — the skill that finds skills

What it does. The skill wakes up when a user asks things like "how do I do X?" or "is there a skill for X?". The agent first checks the skills.sh leaderboard for an established skill, and if there is none it searches with npx skills find. It does not recommend right away. It checks three things: whether installs are above 1,000, whether the source is reputable (official sources such as vercel-labs, anthropics, microsoft), and whether the source repository has more than 100 GitHub stars. Only what passes is shown, with name, purpose, install count and install command, and it installs the skill if the user wants.

npx skills add vercel-labs/skills --skill find-skills   # install
# later, in conversation
"Is there a skill that helps with PR reviews?"  → npx skills find pr review
                                               → vet candidates → show install command
npx skills add <owner/repo@skill> -g -y                 # user-level install

Where it pays off. It is the front door to the skills ecosystem, which is also why it is first. People bringing in skills for the first time install it before anything else, and later skills arrive through it. It is worth noting that the vetting criteria are written into the skill itself. Those criteria are still installs and stars, though, so as this article concludes, judgment beyond the numbers stays with a human.

2. grill-me — an interview that interrogates your plan to the end

What it does. grill-me's SKILL.md is seven lines. The body is a single line, "call the grilling skill", and the actual rules live in the repo's grilling skill. The frontmatter's disable-model-invocation: true means the model should not pull it in on its own; it runs only when the user calls /grill-me. A small skill calling another skill shows well how "a reusable unit made of one markdown file" works in practice.

grilling treats a plan as a decision tree. Each decision has the decisions that hang off it attached like branches. In each round the agent asks every question whose prerequisites are already settled, so it can be asked now (the frontier). Each question is numbered and comes with a recommended answer, worded so that answering "yes" accepts the recommendation.

npx skills add mattpocock/skills --skill grill-me
# or the whole repo as a Claude Code plugin
claude plugin install mattpocock-skills@claude-plugins-official

/grill-me   ← paste a plan or design and call it
❓ Q1 - Storage location: …   ➡️ recommended answer
❓ Q2 - Behavior on failure: … ➡️ recommended answer
(answer, and the next round follows)

Where it pays off. Before any code is written, it surfaces the assumptions hiding in a plan. The agent looks up facts itself through subagents and asks the user only for decisions, which keeps the questions from piling up. grill-with-docs (about 1.21 million), also near the top, runs the same interview while using the domain-modeling skill to write a glossary (GLOSSARY.md) and decision records (ADRs) on the spot. It proposes an ADR only when three conditions all hold: the decision is hard to reverse, surprising without context, and the result of a real trade-off. grill-me also topped social mentions over the last seven days.

3. agent-browser — a browser for the agent

What it does. A browser automation CLI written in Rust. It drives Chrome directly over the Chrome DevTools Protocol and does not depend on Playwright or Puppeteer. The key is that it does not read pages as raw HTML. It takes a snapshot of the accessibility tree, gives each button and input a short reference such as @e1 or @e2, and the agent clicks and types through those references. The original docs say this lets the agent read 200–400 tokens instead of HTML. The SKILL.md itself is a signpost; the real usage guide is loaded from the installed version with agent-browser skills get core, so the instructions never go stale.

npm i -g agent-browser && agent-browser install   # CLI and Chrome
npx skills add vercel-labs/agent-browser           # the skill

agent-browser open https://example.com
agent-browser snapshot -i          # interactive elements only
agent-browser click @e3
agent-browser skills get electron  # sub-skill for Electron apps such as Slack, VS Code

Where it pays off. Anything where the agent has to handle real web pages: testing web apps, filling forms, capturing screens, extracting data. Sub-skills extend it to Electron apps (VS Code, Slack, Figma), exploratory QA, recording a site's requests to derive an API client, and cloud browsers. It overlaps with the Playwright MCP, sixth in the official directory. The difference is that it moves through short CLI commands instead of MCP tools, and Playwright's own docs note that CLI plus skills uses fewer tokens for coding agents.

4. hyperframes — video made from HTML

What it does. An open-source framework published by HeyGen that renders scenes written in HTML and CSS into video. It seeks a paused timeline one frame at a time, so the same files render the same video every time. index.html holds the whole video and each file under compositions/ holds one scene. The skill carries the render contract, the work loop and what each kind of video needs (sound, captions, aspect ratio). When a website is the subject, the site is captured directly as material.

npx hyperframes skills update        # core skill set (recommended for agents)
npx skills add heygen-com/hyperframes   # or pick interactively

npx hyperframes init my-video
npx hyperframes capture https://example.com --json   # a site as material
npx hyperframes check --json                         # contract violations
npx hyperframes render --quality looks --output out.mp4

Where it pays off. Product launch films, explainers, chart animations, vertical clips: videos you revise again and again. Because it is code rather than a video editor, the agent can change and re-render easily. It had the highest seven-day growth (+13.3%), and seven of the repo's skills sit in the top 40 together.

5. frontend-design — how to avoid generic AI design

What it does. A design-judgment skill made by Anthropic. It gives the agent the role of "the design lead at a studio known for giving every client a distinct identity that is not mistaken for anyone else's". First it settles what the screen is about, who sees it and what it has to do, then picks color and type from that subject's world (its industry, materials and vocabulary). It also bans the common tells of a generated page by name: accenting a single word in a headline, all-caps labels, 01·02·03 numbering on content that is not a sequence, the same fade-in on every section. The process is plan, check against the brief, build, critique.

/plugin install frontend-design@claude-plugins-official
# or
npx skills add anthropics/skills --skill frontend-design

"Build a booking page for my neighborhood bakery"   ← wakes up on its own for UI work

Where it pays off. Building UI from scratch: landing pages, dashboards, app screens. It is first by installs in the official directory (1,134,112) and third in the composite score. In the same dataset's seven-day growth ranking, another UI-taste skill (ui-taste) sits second, so "a screen that looks AI-made" is a problem many people are running into right now.

6. Superpowers — a development method, bundled

What it does. A development method built from 15 skills. Its entry point, using-superpowers, wakes up at the start of every conversation and insists: if there is even a 1% chance a skill applies, invoke it first. The seven-stage skills below then fire in order on their own. Plans are cut fine enough (2–5 minutes per task) that an enthusiastic junior engineer with no context could follow them, and implementation is TDD, writing the failing test first.

/plugin install superpowers@claude-plugins-official

"I want to add recurring events to my to-do app"
→ brainstorming wakes first, asks the purpose, shows the design in short chunks
→ once approved: workspace, plan, implementation and review follow in turn

Where it pays off. Handing an agent hours of work. According to the original description, once the plan is approved it is common for the agent to work alone for a couple of hours without drifting from it. It is second by installs in the official directory (1,009,371) and ships install instructions for many harnesses beyond Claude Code, including Codex, Cursor and Gemini CLI. On the other hand it starts with brainstorming even for short questions, so it can feel heavy for people who mostly do light tasks.

7. vercel-react-best-practices — 70 rules in priority order

What it does. Vercel Engineering's 70 React and Next.js performance rules, sorted into 8 categories and ranked by impact. At the top are eliminating waterfalls (requests waiting on each other in sequence) and cutting bundle size, both CRITICAL, followed by server-side performance, client-side data fetching and re-renders. The agent applies them in that order when writing or reviewing React code. web-design-guidelines from the same repo (ninth in the composite score) fetches the latest guidelines from a URL at every review and reports violations in file:line form.

npx skills add vercel-labs/agent-skills --skill vercel-react-best-practices
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a claude-code

"Why is this page slow?"   ← wakes up on its own for React or Next.js work
"Review my UI"             ← web-design-guidelines

Where it pays off. It is a model for planting a team's code rules directly in the agent instead of in a document. The rules are organized by priority and prefix (async-, bundle-), so it is worth copying when you write an in-house rules skill.

What to check when choosing

  • Install counts measure popularity. Compare only within one counter and allow for the per-repository counting effect. The composite score uses official-publisher status as its trust signal, and the data provider says it does no security scanning yet.
  • Skills run with the agent's permissions. Read the SKILL.md and its scripts before installing. How to check what it runs and where it connects is covered in Install · Security · Creating.
  • Check whether it fires on its own. Self-triggering skills like frontend-design and Superpowers are convenient but also step in when you do not want them. Some, like grill-me, use disable-model-invocation so they run only when called.
  • Plugins have their own ranking. The top plugins in the official directory and what they are made of are in Popular Plugins of H2 2026.
