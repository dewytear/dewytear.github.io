Harness Engineering — Overview and Recap

This material organizes the "Harness Engineering / Minho Hwang" hands-on course part by part in the order of the video. Following the previous Claude Code Basics course, this topic is Harness Engineering.

The human gives only the intent, and the agent team the harness assembles works on its own for a long time to produce a verified result.
First, keep this in mind Because a harness is a structure that does a lot of work over a long time without human intervention, it may not feel like a hands-on exercise. Instead, it becomes a chance to see for yourself that "I asked once and the AI worked for a long time and made a good result."

Recap of the previous basics course

  • AI tools come not only as the web but also as a desktop app and a terminal (Claude Code).
  • Terminal basics — pwd · cd · mkdir, and running claude in a folder.
  • Research → file → building a website, and applying design with the design system skill.
  • Creating an agent to analyze papers, and parallel processing with multiple agents.
  • The importance of context when working with AI, and managing token usage.

About the instructor — FDE

The instructor belongs to Kakao's FDE (Forward Deployed Engineer) organization. FDE is a role that started with Palantir and is now widely hired at OpenAI · Anthropic as well; FDEs are deployed on site at a client (or an internal organization), rapidly build the systems needed with AI, and help with AX (AI transformation) training and adoption.
