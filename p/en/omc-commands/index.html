Command Collection

We have gathered the commands you use often at a glance, with a note on what each one actually does. Slash commands are written in the namespaced (/oh-my-claudecode:) form wherever possible.

CategoryCommandWhat it does
Install/plugin marketplace add <repo> → /plugin install oh-my-claudecodeRegisters the plugin repository, then installs OMC. Run the two lines in order.
Project setup/oh-my-claudecode:omc-setup --localCreates OMC settings that apply only to the current project. It does not touch the global settings.
Global setup/oh-my-claudecode:omc-setupCreates settings that apply commonly to every project. It may affect your existing global CLAUDE.md.
Diagnosis/oh-my-claudecode:omc-doctorChecks the install and configuration state and tells you if something is wrong. The first step in troubleshooting.
Project documentation/oh-my-claudecode:deepinit [path]Analyzes the project structure and organizes it into a document (AGENTS.md) that is easy for AI to understand.
Requirement clarification/deep-interview <idea>Throws questions at a vague idea to refine it into concrete requirements.
Autonomous implementation/oh-my-claudecode:autopilot <task>Takes the requirements and proceeds on its own from implementation through verification.
Carry through to the end/oh-my-claudecode:ralph <task>Repeats without stopping until the completion condition is satisfied.
Maximum parallelism/oh-my-claudecode:ultrawork <task> or ulwHandles several mutually independent tasks at the same time to increase speed.
Team execution/oh-my-claudecode:team <N>:<agent> <task>Assigns the role (agent) to the specified number (N) of agents and divides the work among them.
Update/plugin marketplace update omc → /oh-my-claudecode:omc-setupSyncs the marketplace to the latest, then applies the settings again.
Plan / consensus/oh-my-claudecode:plan · /oh-my-claudecode:ralplanLays out an execution plan before the work. ralplan reviews more carefully, on a consensus basis. (omc-plan is a compatibility alias for plan)
Cancel/oh-my-claudecode:cancel or stopomc / cancelomcStops the OMC work in progress.
Pattern extraction/oh-my-claudecode:skillifyExtracts a work pattern that was effective in a session into a reusable skill. (learner is a deprecated alias)
HUD setup/oh-my-claudecode:hud setupSets up the on-screen display (HUD) that shows the progress of the work.
How to read this The parts wrapped in angle brackets, like <task>, <idea>, and <N>, are slots you replace with actual values. For example, in the <task> slot you write the work to be done, such as "implement the login API". Parts wrapped in square brackets, like [path], are optional items you may omit.
