Everyday Use

Most of the time you simply type what you want in natural language and Claude Code does the work — reading files, editing code, running commands, and asking for permission before anything risky. Alongside plain prompts, there are built-in slash commands that control the session:

  • /help — show available commands
  • /clear — start a fresh conversation and reset context
  • /init — generate a CLAUDE.md file documenting your project
  • /review — review a pull request or your working changes
  • /config — open settings (theme, model, and more)
  • /model — switch the Claude model in use
Two tips that make a big difference:
  • CLAUDE.md — a file in your repo where you record project conventions, commands, and context. Claude Code reads it automatically so you don't have to repeat yourself.
  • Plan mode — ask Claude to plan before it edits, so you can approve the approach on larger tasks before any code changes.
