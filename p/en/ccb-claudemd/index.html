CLAUDE.md — The Instruction File

Claude Code uses a Markdown file called CLAUDE.md as the file it always refers to. Think of it as a file that is always included with whatever command you give the AI. That is why it should hold the important content clearly, without getting too long.

The four layers

The same CLAUDE.md has a different scope depending on where it sits, and lower layers take precedence.

The same CLAUDE.md has a different scope depending on where you put it.

  • Enterprise (managed) — applies to every member inside the company.
  • User global — always applies on my PC, whatever project I'm working on.
  • Project — applies only in that project (shared with teammates).
  • Project local — instructions inside the project that are not shared, just for my own PC.

Practice — creating instructions

Run claude in a new folder, then ask for this to create a CLAUDE.md.

Create a CLAUDE.md file in this folder.
Instructions: always write answers in Korean,
and always append _new to the names of new files you create.

Once the file is created, the instructions you just gave ("write in Korean", "append _new to new files") are recorded inside it. Every later task always follows these instructions underneath this folder. For example, if you say "save a short poem as a text file", the result is written in Korean and the filename carries _new.

What is worth putting in

  • Rules that keep original files from being modified
  • Rules to follow when writing code (Python, for example)
  • Output format · how files are saved
  • Tone · language of what gets written
Tip You can have the AI create CLAUDE.md, or open and edit it yourself. On Windows, line breaks in a prompt may not work well, but writing it all on one line without breaks is perfectly fine.
