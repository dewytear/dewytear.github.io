Extending the Tools and Wrap-up

Claude Code vs Gemini (Antigravity)

AI tools advance by leapfrogging each other. Right now Claude Code is the best, but the instructor also uses Antigravity CLI (the agy command) alongside it.

ItemClaude CodeAntigravity (Gemini 3.5 Flash)
Generation speedAbout 50–60 tokens per secondAbout 4 times faster
Image generationNot possible with the model itself (possible via the codex-image skill)Possible (Nano Banana)
Output qualityComes out prettier in the instructor's impressionFast, but needs polishing

You can compare performance · speed · price by model on the Artificial Analysis site. (Opus and GPT 5.5 are on the expensive side.)

About the numbers The "about 4 times faster" in the table is not a public benchmark but the instructor's own experience. For reference, the speedup of a parallel agent configuration is reported as anywhere from about 2 times up to 10 times depending on how independent the tasks are (Anthropic reported a 90% cut in elapsed time on complex queries).

Second-pass verification with Codex CLI

Since verification by a single model can be biased, you can attach second-pass verification to the QA agent with a skill that connects Codex CLI (GPT 5.5).

# when the composition needs to change, instruct with /harness
/harness Modify the QA agent so that it verifies using Codex CLI
  • The QA agent is updated to a double verification protocol — a first pass with Claude, a second pass with Codex CLI, and the two opinions combined.
  • Since it has to know the workflow, the orchestrator is updated along with it.
  • This kind of harness composition change history is recorded in CLAUDE.md.

Agent 1:1 (one-on-one)

There is also a feature that lets you talk with a specific agent as if having a coffee chat and redesign it. When you pick a counterpart from the agent list, that agent explains its own role and principles and asks "which part shall we modify?".

Wrap-up — what people should focus on

At the entrance to an era where agents do much of the work for us, people should focus on the following: setting goals, contextual judgment, quality standards, responsibility · ethics, good questions, systems thinking, domain expertise, evaluation · feedback, and AI collaboration.

Q&A points · If an agent does not show up in /agents, only the list is missing; restarting loads it (when dynamic loading fails it sometimes shows up as an ordinary subagent).
· Auto mode — switch between auto/accept/plan modes with Shift+Tab. Auto mode does not ask for permission every time, so it operates more autonomously (you can switch at any point in the middle). If you do not see it, Claude Code needs to be updated (a native install updates automatically, an npm install manually).
· Since 2026-08-14 auto mode is the default (new sessions on Pro, Max, and Team). Instead of asking, hard deny rules and prompt-injection screening make the call, and only irreversible or destructive actions come back to you — details in Defaults That Stop Asking.
· Agents · skills are created in the per-project .claude, so share them with Git; plugins are installed separately on each environment (PC).
· In real work, unlike in a demo, giving detailed requirements and data together (in markdown if long) makes the intent land reliably.
