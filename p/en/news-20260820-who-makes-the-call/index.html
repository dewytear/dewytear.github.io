Who Gets to Make the Call — Four Scenes from August

Three-line summary

  • In the second week of August, four announcements from different companies touched the same question — in the agent era, who makes the judgment call. Claude Tag handed "when to step in" to the model's reading of context; Grok Bot handed "how far to execute" to approval escalation.
  • Cursor Origin let the weighty call about code custody slip through as a default with no terms, and GPT-5.6-Cyber moved the call on dangerous capability from the model's refusals to a human vetting program.
  • Judgment does not disappear; it relocates — the third observation in this wiki's series, after the auto-mode default (conversation → rules) and self-hosting (execution location → the organization).

Claude Tag — the model picks when to step in

Claude Tag, the Claude that works when you mention @Claude in Slack, reads the whole channel's context as of August 13. It used to judge from the single mentioned message; now it reads the channel's flow, its accumulated memory, and standing instructions together to decide whether to step in on its own — Anthropic says this call got roughly 30% more accurate.

Its moves split four ways. If the answer is short and verifiable, it replies inline; if the message deserves real time, it starts deeper work in a thread; if it overlaps work already in flight, it routes there; and if nothing calls for it, it stays silent. The billing detail is the interesting part — reading more context raises usage, but the extra context does not count toward limits on any plan. Making the "when to speak" call well is itself treated as the product's value.

Grok Bot — people keep only the approvals

Grok Bot, which xAI opened in beta on August 11, is the design at the opposite end. Bots live on a cloud computer, sign into the apps you already use, grind through multi-step work around the clock, and come back to a person only when a call needs human judgment. Demonstrate a task once and the bot saves the flow as a routine to repeat on schedule; the beta opened to SuperGrok Heavy ($300/month) and Cursor Ultra/Teams Premium subscribers.

The default of judgment is inverted here — execution is the default and the person becomes the exception handler. Which is why credentials (login information) immediately became the issue: the official introduction says each bot gets its own cloud computer, while security analysis reports that one account's bots share a single computer and every login. The very fact that the descriptions diverge tells you how wide the delegation runs beyond what the approval prompt shows.

Cursor Origin — the default nobody ruled on

As soon as SpaceX's acquisition of Cursor closed (agreed in June, completed August 14 as a $60B all-stock deal — the combined entity presents itself as SpaceXAI), Cursor opened Origin, a code-hosting service, in early beta on August 17. It is a repository built for AI agents, with pull requests, code review and GitHub sync, and it landed while GitHub outages were running error rates around 20% — hence the "attacking GitHub's moat" framing.

The problem was how it opened. It switched on as opt-out (enrolled by default, leave if you want) for every paid plan, and at launch no data-retention or training-use terms were published. Paying customers' code began shipping to the platform before anyone had ruled on what policy governs it — unlike the other three scenes, which argue over whether the call belongs to a model or a person, here the call was simply left empty.

GPT-5.6-Cyber — vetting instead of refusing

GPT-5.6-Cyber, announced by OpenAI on August 10, branches off GPT-5.6 Sol and is trained for finding zero-days (undisclosed vulnerabilities that have no patch yet) and building exploit chains. On OpenAI's internal Advanced Cybersecurity Completion Rate it answers 95.0% of advanced security requests where standard Sol answers 1.5%, and in the wild it found two previously unknown vulnerabilities in Chrome's V8 engine (patched as CVE-2026-15903) plus a privilege-escalation chain in a mobile OS.

How that capability is handled is what ties it to this piece — instead of the model refusing requests, it exists only behind Daybreak Red, a vetted defender program requiring identity verification, account-security requirements, monitoring, approved-use restrictions, and legal attestations. The risk class is "High" under OpenAI's Preparedness framework. The call moved from the model's response stage to the program's front door.

Why this is one current

The auto-mode default moved approval calls from a prompt asked every time into pre-written rules, and self-hosting handed control of the execution location to the organization. These four scenes show how far that migration goes. The call moved into the model's context reading (Claude Tag), into approval escalation (Grok Bot), into a program's admissions (GPT-5.6-Cyber) — and, as Origin shows, if you don't decide where the call lives, the default decides for you. It is the same reason this wiki's advanced tips spend pages on deny-rule editing and self-approval bias: the more work you hand to agents, the thing you actually have to design is not the work but the seat of judgment.
