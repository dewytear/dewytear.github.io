Getting Started

Claude Code is Anthropic's official CLI (command-line interface) for Claude. It is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows — all through natural language commands. Instead of copying and pasting code between a chat window and your editor, you talk to Claude Code directly in the project directory. It can read and edit files, run shell commands, search the codebase, run tests, and commit changes on your behalf, asking for permission along the way. Claude Code is available as a terminal CLI, a desktop app (Mac/Windows), a web app (claude.ai/code), and IDE extensions (VS Code, JetBrains). It is powered by the latest Claude models, such as Opus, Sonnet, and Haiku.

Install & Start

The fastest way to get started is the native installer — a single command with no dependencies, and it keeps Claude Code updated automatically.

  • macOS / Linux / WSL: curl -fsSL https://claude.ai/install.sh | bash
  • Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
  • Go to your project: cd your-project
  • Launch it: claude
Homebrew (brew install --cask claude-code) and WinGet are also supported. Installing with npm (npm install -g @anthropic-ai/claude-code, requires Node.js 22 or newer) still works and installs the same native binary. On first launch, Claude Code walks you through authentication — you can log in with a Claude account (Pro/Max plan) or an Anthropic API key. After that, just describe what you want in plain language, for example: "explain the auth flow" or "add a dark mode toggle and run the tests". A few handy startup flags:
  • claude — start an interactive session
  • claude "your prompt" — run a one-off task
  • claude -c — continue the most recent conversation
  • claude --help — list all options

Everyday Use

Once installed and authenticated, most of the time you simply type what you want in natural language and Claude Code does the work — reading files, editing code, running commands, and asking for permission before anything risky. Alongside plain prompts, there are built-in slash commands that control the session:

  • /help — show available commands
  • /clear — start a fresh conversation and reset context
  • /init — generate a CLAUDE.md file documenting your project
  • /review — review a pull request or your working changes
  • /config — open settings (theme, model, and more)
  • /model — switch the Claude model in use
Two tips that make a big difference:
  • CLAUDE.md — a file in your repo where you record project conventions, commands, and context. Claude Code reads it automatically so you don't have to repeat yourself.
  • Plan mode — ask Claude to plan before it edits, so you can approve the approach on larger tasks before any code changes.
That covers the basics. Claude Code's real power comes from extending it, and there are three ways in: skills, MCP servers, and hooks — the story continues in Extending Claude Code.
