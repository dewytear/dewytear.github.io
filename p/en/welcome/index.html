Welcome

Claude Code is Anthropic's official CLI (command-line interface) for Claude. It is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows — all through natural language commands. Instead of copying and pasting code between a chat window and your editor, you talk to Claude Code directly in the project directory. It can read and edit files, run shell commands, search the codebase, run tests, and commit changes on your behalf, asking for permission along the way. Claude Code is available as a terminal CLI, a desktop app (Mac/Windows), a web app (claude.ai/code), and IDE extensions (VS Code, JetBrains). It is powered by the latest Claude models, such as Opus, Sonnet, and Haiku. Use the navigation on the left to learn how to install Claude Code, run everyday commands, and extend it with skills, MCP servers, and hooks.
