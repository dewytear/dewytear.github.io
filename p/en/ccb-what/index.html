What Is Claude Code

Think of Claude Code as an AI agent that runs in your local environment (your own PC). Unlike web chat, it reads and edits the files on your computer directly and runs commands to get work done. You work by creating one folder per project and staying inside that folder. On Windows you normally run it from the PowerShell terminal.

How it differs from existing services

FormCharacteristicsFreedom
Web browser (Claude · ChatGPT · Gemini)Using AI inside the browser's constrained environment. You have to upload files one by oneMost limited
Claude desktop appRuns locally, but has constraints compared to the terminalMedium
Claude Code (terminal)Direct access to the files in the folder you launched it from. Work as freely as you likeMost free

Get just a little comfortable with the terminal environment and you can use it far more freely, much as you would use ordinary AI chat.

Demo — Three Meeting Notes into One Report

Without being told the file list, it explores, reads, and analyzes on its own to produce the report.

Run Claude Code in a folder holding three meeting-note files and ask for this.

Combine these three meeting notes and summarize them into a single report. In Korean.

The key point here is that you never told it which files exist. With web chat you would have to upload the files yourself, but Claude Code

  • first explores (searches) which files are in the current folder,
  • reads those files one by one,
  • and after analyzing the content, produces the result (the report).

In other words, "the folder you launched it from" becomes the workspace, and it handles the files inside on its own.

Worth remembering Claude Code has access to the entire folder in which you ran claude. That is why it matters to split folders per project and make a habit of launching inside the folder you want to work in.
