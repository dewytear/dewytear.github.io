SKILL.md Structure and the Description

The center of a skill folder is the SKILL.md file, and alongside it sit bundled files such as reference, examples, and scripts.

Front matter (metadata)

Within a single file the front matter is always loaded, while the body is loaded when the skill is invoked.

At the very top of SKILL.md there is YAML front matter. For a PDF skill, for example:

# SKILL.md front matter (the part that is always loaded)
name: pdf
description: Toolkit for extracting text/tables from PDFs, merging, splitting, and so on

On the first load only this front matter comes in, and the actual manual (the body) is loaded when the skill is invoked.

Writing the description matters

A skill can be invoked explicitly with /skill-name, and it can also fire automatically on the basis of its front matter when you say something like "extract the text from this PDF." That is why the description has to be written well.

  • When it does not get invoked — for example, if it has a PDF editing capability but the description only says "used for reading," it may not be invoked when you ask for an edit.
  • When it gets invoked unnecessarily — it suddenly fires on something that has nothing to do with PDFs.

So test whether it gets invoked when it should and whether it fires when it should not, and when you build one yourself write the description with care.

Referencing files from the instructions

Inside the body (markdown) instructions you can write references to other files, such as "in this case, look at this file." Unlike the JSON tool specs we saw earlier, this amounts to writing something like "how to run the command" in natural language, as if you were telling a person.

Why read/execute alone is enough Coding agents come with file read, write, edit, and search tools built in, so they handle the file system freely. That is why the agent loads a file on its own even when the instructions only say "read this file." It is easier to grasp if you picture how a skill's content and the coding agent's tools interact as it reads.
