Links and Cross-Vault References

Obsidian's greatest strength is links between notes. For example, a "BM25" note has all sorts of notes linked to it — an MOC (Map of Content, a knowledge map), harness engineering, logs, and more. These links are the heart of it.

One address reads the linked knowledge along with it

Hand artificial intelligence just the address of the "BM25" note, and it reads the rest of the notes linked to it, strung together like sausages. That automatic linking, however, only works within the same vault.

A small knowledge graph of notes joined by links — the blue (accent) lines are links that cross vaults.

Cross-vault links — markdown links

The wikilinks ([[...]]) used inside a vault cannot point to notes outside it, so links to an external vault have to use the markdown link form ([text](address)). The speaker has set up the system files so that these cross-vault links get written automatically too.

  • During onboarding it asks, "What is your main vault?"
  • Give it the address of the main vault and it parses that URI value and builds the links to those addresses along the way.
Example — mobile command center When building a "mobile command center" wiki card about putting Starlink and a battery system in a vehicle, the artificial intelligence found and linked not only the related concepts inside the wiki vault (Related) but also the related notes organized in the main vault (main vault Related). Connecting your entire knowledge system this way goes beyond the innate limitation of Obsidian vaults (links only within a vault).
