Skills

Skills are reusable, packaged capabilities that give Claude Code specialized knowledge and workflows for a specific task. A skill bundles instructions (and optionally scripts and resources) that Claude loads on demand when your request matches what the skill is for. You invoke a skill the same way you run any slash command — by typing / followed by the skill name — or Claude Code can trigger a relevant skill automatically when it recognizes the task. Examples of what skills can do:

  • Run a structured code review of the current diff.
  • Perform deep, multi-source research and produce a cited report.
  • Design and configure hooks, keybindings, or settings.
  • Build data visualizations that follow a consistent design system.
Skills keep your prompts short and your results consistent, because the detailed know-how lives in the skill rather than in every message you type. You can use the skills that ship with Claude Code, install skills from plugins, or author your own.
