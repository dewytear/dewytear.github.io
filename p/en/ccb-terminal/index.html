Basic Terminal Commands

It's fine if the terminal feels unfamiliar. Our goal reaches only as far as "create a new folder, go to that location, and run claude". The AI does everything after that. On Windows, launching PowerShell usually starts you in your user folder.

Remember just these four

CommandMeaningWhat it does
pwdprint working directoryShows which folder you are in right now
cd <folder>change directoryMove to another folder (e.g. cd Downloads)
mkdir <name>make directoryCreate a new folder (e.g. mkdir kist-test)
claude—Run Claude Code in the current folder

Practice sequence

Creating a new folder, moving there, and running claude is today's gateway.
# 1. Check where you are now
pwd
# 2. Move to the Downloads folder
cd Downloads
# 3. Create a new folder
mkdir kist-test
# 4. Move into the folder you created
cd kist-test
# 5. Run Claude Code in that folder
claude

Once you run claude in the folder you just created, Claude Code now does all its work inside that folder.

Today's gateway "Create a folder → move there → run claude" — get this far and you can rely on the AI from then on. If you get stuck, don't hesitate to ask for help.
