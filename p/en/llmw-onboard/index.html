Onboarding (Hands-on)

The starter kit contains an onboarding skill, so a single /onboard (or "onboard me") kicks off a personalized setup.

From getting the release to the moment you open the vault in graph view — a personalized setup with one /onboard.

Preparation — getting the release

  • Download the latest release file (1.7.0, for example) from the LLM Wiki page (GitHub repository) given in the course.
  • Unzipping it produces a single folder (= the wiki vault, soon to be an Obsidian vault).
  • Place this folder first at the path you will actually use (My Documents, Desktop, and so on).

Running onboarding

# Copy the folder path — Windows: Ctrl+Shift+C / Mac: Cmd+Option+C
# Then run Claude Code in that folder
/onboard        # or "onboard me"

A set of questions follows — what purpose are you using it for, what should it call you, whether to connect it to your main vault, and so on. The more context you give, the smarter it gets, so answer sincerely. (Takes about 5 minutes.)

  • Connect it if you have a main vault — the AI then references the notes I have written when it builds the wiki.
  • If you do not have one, starting standalone is fine.

Opening the vault in Obsidian

  1. Bottom left of Obsidian → Manage vaults → Open folder as vault, and open that folder.
  2. Check that your folder name is correct at the bottom left.
  3. Press Ctrl/Cmd + G to open the graph view and you can see the embedded relationships between notes.
To start clean If you want to start without the sample data, just delete the sample files in the concept, entity, and article folders. Files for Codex are prepared too, but using it in Claude Code is more advantageous.
