Advanced Tools

OMC provides a family of tools for handling code more precisely. They are useful when you need analysis more precise than a text search.

Tool familyRepresentative featuresWhat it is used forCautions
LSPlsp_hover, lsp_goto_definition, lsp_find_references, lsp_diagnosticsAccurate symbol navigation, checking type errors, searching referencesRequires a per-language server such as typescript-language-server, pyright, or rust-analyzer
AST Grepast_grep_search, ast_grep_replaceSearch · replace based on syntactic structureMore precise than a text grep, but you need the skill to write the patterns
Python REPLAnalysis based on pandas, numpy, matplotlibCSV · log · statistical analysisYou need to check access permissions for the data files and package availability
Ask / Team CLIomc ask, omc team, omc session searchExternal CLI workers and session searchYou need to distinguish the plugin installation flow from the CLI/runtime path
A note on LSP LSP (Language Server Protocol) is a standard that helps a code editor accurately work out "where is this variable defined?" and "is there a type error here?". Note, though, that the language server for the language in question must be installed for it to work properly.
