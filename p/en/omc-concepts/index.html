Core Terminology

The following terms show up often in the OMC documents. Understanding them up front makes everything that follows much easier to read.

  • Slash command — a special command starting with / in the Claude Code input box. Instead of ordinary conversation, it directly runs a set feature. e.g. /plugin install ...
  • Namespace — the form where the plugin name is prefixed to a command. It keeps names from colliding with other plugins. e.g. /oh-my-claudecode:autopilot
  • Agent — an AI worker taking on a specific role. Roles are divided up like exploration, implementation, and verification, so you can split a large task among them. e.g. explore, executor, qa-tester
  • Skill — a unit of functionality that performs one task. Behaviors such as autonomous execution or repeated runs are provided as skills. e.g. autopilot, ralph, skillify
  • Hook — an action that automatically steps in and runs at a set point (e.g. before or after a file edit). It is used for things like keyword detection and completion verification. e.g. PreToolUse, PostToolUse
  • Project memory — a document organized so that the AI remembers the project structure. It reduces the cost of exploring from scratch every time. e.g. deepinit, AGENTS.md
