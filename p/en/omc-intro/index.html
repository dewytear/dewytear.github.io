OMC — Introduction and Install

oh-my-claudecode (hereafter OMC) is a plugin that adds autonomous execution, multi-agent collaboration, and automatic verification to Claude Code.

OMC adds autonomous execution, multi-agent work, and automatic verification to Claude Code with a single command.

Three concepts

  • What Claude Code is — a CLI tool that lets you hand coding work to Claude from a terminal or an IDE. It reads and edits files, runs commands, and helps you develop.
  • What a plugin is — an extension pack that adds new features to Claude Code. Install it once and dedicated commands and behaviors are added.
  • What OMC adds — it lets you use advanced ways of working such as "implement it all the way through on its own", "several workers split the job", and "verify automatically after the work" with a single command.

This document is a summary written by installing it directly in a local environment for partial verification and by cross-checking the official documentation, release notes, and plugin documentation. Some commands and behaviors may differ depending on Windows PowerShell, WSL2, macOS, or Linux, so environment-dependent items are marked separately. The reference version is v4.15.2 (checked 2026-07-05). Since releases are fairly frequent at 3–5 per month, the details may differ from the latest release notes at the time you read this.

Core Terminology

The following terms show up often in the OMC documents. Understanding them up front makes everything that follows much easier to read.

  • Slash command — a special command starting with / in the Claude Code input box. Instead of ordinary conversation, it directly runs a set feature. e.g. /plugin install ...
  • Namespace — the form where the plugin name is prefixed to a command. It keeps names from colliding with other plugins. e.g. /oh-my-claudecode:autopilot
  • Agent — an AI worker taking on a specific role. Roles are divided up like exploration, implementation, and verification, so you can split a large task among them. e.g. explore, executor, qa-tester
  • Skill — a unit of functionality that performs one task. Behaviors such as autonomous execution or repeated runs are provided as skills. e.g. autopilot, ralph, skillify
  • Hook — an action that automatically steps in and runs at a set point (e.g. before or after a file edit). It is used for things like keyword detection and completion verification. e.g. PreToolUse, PostToolUse
  • Project memory — a document organized so that the AI remembers the project structure. It reduces the cost of exploring from scratch every time. e.g. deepinit, AGENTS.md

Installation

The install paths split three ways. Ordinary users should apply the plugin marketplace approach first.

From "How to install?" it splits three ways into the plugin marketplace (recommended) · --local · npm CLI.

1) Recommended — the plugin marketplace

Add the marketplace inside Claude Code, then install the OMC plugin. Run the two lines below one after another in the input box. Pasting both lines at once fails, so you must run them one line at a time (stated in the official README).

# Step 1: register the plugin repository (marketplace)
/plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode
# Step 2: install the OMC plugin from the registered repository
/plugin install oh-my-claudecode

2) Project configuration (--local recommended)

After installing, per-project configuration is recommended. Adding --local is safe because it does not overwrite your existing global CLAUDE.md.

# Apply the OMC configuration only to the current project — the global configuration is preserved as is
/oh-my-claudecode:omc-setup --local

Use the command below only when you really need a global configuration. However, you should check in advance whether it affects your existing ~/.claude/CLAUDE.md.

# Applied commonly to all projects — you need to check whether it affects the existing global CLAUDE.md
/oh-my-claudecode:omc-setup
Recommendation for company dev PCs · shared projects Project-local configuration (--local) is recommended over global configuration. It prevents the global CLAUDE.md from getting mixed in when rules differ per project.

3) npm installation — the official alternative path for CLI/runtime use

The plugin approach above is enough for ordinary users, but npm installation is a separate, officially supported path as well. Its purpose is different, though. The plugin installation is for using slash commands (/autopilot and so on) inside a Claude Code session, while the npm installation is for using the omc CLI commands (omc doctor, omc team, omc ask, and so on) in a terminal.

# Only when you need the terminal CLI (the omc command) — the npm package name is oh-my-claude-sisyphus
npm i -g oh-my-claude-sisyphus@latest

The thing to watch out for is that the npm package name differs from the repository name. The project brand is oh-my-claudecode, but the package name published on npm is oh-my-claude-sisyphus. Installing it registers both the oh-my-claudecode and omc commands together. You may see a deprecated prebuild-install warning during installation, but it is a known warning originating from an upstream dependency and does not mean the installation failed. Installation via a curl script is not in the official documentation, so do not use it.

Installation · updates When using the plugin approach, handle installation and updates through Claude Code's plugin management features. If marketplace auto-update is off, first sync the latest version with /plugin marketplace update omc, then run /oh-my-claudecode:omc-setup again to apply the latest configuration.

Installation Diagnosis

If a problem comes up after installing, first check the state with the diagnosis command.

In a plugin environment, use the command below first.

# Checks the installation and configuration state and tells you about problems (the first step in troubleshooting)
/oh-my-claudecode:omc-doctor

If you separately use the CLI runtime path, the following diagnosis is also possible.

# Diagnose from the CLI runtime path
omc doctor
# Diagnose by pointing directly at the plugin installation folder
omc doctor --plugin-dir /path/to/oh-my-claudecode
