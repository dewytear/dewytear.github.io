One Step Further — the Harness

A few lines of prompt take it from forming the team through writing, art, conversion, and the website in about an hour.

Once you are past the basic hurdle, the Harness is waiting next. With a harness, a few lines of prompt can produce an entire book of more than 200–300 pages. The example shown in the course works like this.

  • Create several agents (say, five) to write the book.
  • A research agent prepares the book's sources.
  • The agents write in parallel and report when they're done.
  • It even generates the illustrations needed and inserts them at exactly the right places.
  • It converts the result into Markdown and PDF, and builds a page-turning website too. — about an hour in total.

In other words, you can build "my own book for people starting out with Claude Code" yourself. The harness itself is covered in a separate later session.

What Is Claude Code

Think of Claude Code as an AI agent that runs in your local environment (your own PC). Unlike web chat, it reads and edits the files on your computer directly and runs commands to get work done. You work by creating one folder per project and staying inside that folder. On Windows you normally run it from the PowerShell terminal.

How it differs from existing services

FormCharacteristicsFreedom
Web browser (Claude · ChatGPT · Gemini)Using AI inside the browser's constrained environment. You have to upload files one by oneMost limited
Claude desktop appRuns locally, but has constraints compared to the terminalMedium
Claude Code (terminal)Direct access to the files in the folder you launched it from. Work as freely as you likeMost free

Get just a little comfortable with the terminal environment and you can use it far more freely, much as you would use ordinary AI chat.

Demo — Three Meeting Notes into One Report

Without being told the file list, it explores, reads, and analyzes on its own to produce the report.

Run Claude Code in a folder holding three meeting-note files and ask for this.

Combine these three meeting notes and summarize them into a single report. In Korean.

The key point here is that you never told it which files exist. With web chat you would have to upload the files yourself, but Claude Code

  • first explores (searches) which files are in the current folder,
  • reads those files one by one,
  • and after analyzing the content, produces the result (the report).

In other words, "the folder you launched it from" becomes the workspace, and it handles the files inside on its own.

Worth remembering Claude Code has access to the entire folder in which you ran claude. That is why it matters to split folders per project and make a habit of launching inside the folder you want to work in.

Basic Terminal Commands

It's fine if the terminal feels unfamiliar. Our goal reaches only as far as "create a new folder, go to that location, and run claude". The AI does everything after that. On Windows, launching PowerShell usually starts you in your user folder.

Remember just these four

CommandMeaningWhat it does
pwdprint working directoryShows which folder you are in right now
cd <folder>change directoryMove to another folder (e.g. cd Downloads)
mkdir <name>make directoryCreate a new folder (e.g. mkdir kist-test)
claude—Run Claude Code in the current folder

Practice sequence

Creating a new folder, moving there, and running claude is today's gateway.
# 1. Check where you are now
pwd
# 2. Move to the Downloads folder
cd Downloads
# 3. Create a new folder
mkdir kist-test
# 4. Move into the folder you created
cd kist-test
# 5. Run Claude Code in that folder
claude

Once you run claude in the folder you just created, Claude Code now does all its work inside that folder.

Today's gateway "Create a folder → move there → run claude" — get this far and you can rely on the AI from then on. If you get stuck, don't hesitate to ask for help.

CLAUDE.md — The Instruction File

Claude Code uses a Markdown file called CLAUDE.md as the file it always refers to. Think of it as a file that is always included with whatever command you give the AI. That is why it should hold the important content clearly, without getting too long.

The four layers

The same CLAUDE.md has a different scope depending on where it sits, and lower layers take precedence.

The same CLAUDE.md has a different scope depending on where you put it.

  • Enterprise (managed) — applies to every member inside the company.
  • User global — always applies on my PC, whatever project I'm working on.
  • Project — applies only in that project (shared with teammates).
  • Project local — instructions inside the project that are not shared, just for my own PC.

Practice — creating instructions

Run claude in a new folder, then ask for this to create a CLAUDE.md.

Create a CLAUDE.md file in this folder.
Instructions: always write answers in Korean,
and always append _new to the names of new files you create.

Once the file is created, the instructions you just gave ("write in Korean", "append _new to new files") are recorded inside it. Every later task always follows these instructions underneath this folder. For example, if you say "save a short poem as a text file", the result is written in Korean and the filename carries _new.

What is worth putting in

  • Rules that keep original files from being modified
  • Rules to follow when writing code (Python, for example)
  • Output format · how files are saved
  • Tone · language of what gets written
Tip You can have the AI create CLAUDE.md, or open and edit it yourself. On Windows, line breaks in a prompt may not work well, but writing it all on one line without breaks is perfectly fine.
