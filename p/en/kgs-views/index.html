Nine Ways to Read the Graph — Each View Answers a Different Question

Even for the same knowledge graph, the right visualization depends on what you are curious about. The dock on the Knowledge Graph screen is two-stage — you first pick 3D · 2D and then a view inside it (3D is the default) — and there are nine views in total. Each was chosen to answer one distinct question. This document lays out "what to look for in each view".

Nine ways of seeing — all drawn from the same index, so whichever view you pick, the data is one.

"For this question, this view"

ViewQuestion it answersHow to read it
Constellation (3D)What shape does the knowledge as a whole have?On a rounded sphere, color = World/System. A patch of one color is a topic cluster, and lines crossing patches are bridges between topics. You can adjust the roundness (0–100) in settings.
Orbits (3D)Which documents are bound to one System?A World is a star, a System is a planet circling it, and a document is a moon circling the planet. The orbital planes are tilted against each other so membership separates at a glance, and because they actually revolve, lineage reads better than in a still image. Tap a document and a card opens, leaving only that document's neighbors.
Strata (3D)How do the four tiers actually connect?World → Domain → System → Document are stacked as four sheets of glass, with lineage lines running through them vertically. This is the view for seeing this wiki's own hierarchy model with your eyes, and on the bottom document layer the concept edges are laid out as low arcs.
BundlingWhich documents pull on each other?Documents are placed around a circle in System order, and concept connections curve toward the center to form bundles. A thick bundle = a strongly entangled pair of topics.
ChordHow tightly are Systems coupled?Arc length = that System's outward connection volume; ribbon thickness = the number of connections between two Systems. The thickest ribbon is the substantive neighbor relation in the knowledge.
PackingWhere has knowledge piled up most?System circles inside World circles, with document dots inside those. Circle size = number of documents — growth imbalance is visible at a glance.
ConceptsHow do concepts stick together?The only view whose nodes are concepts rather than documents. Concepts that appear together are linked, showing the knowledge terrain at the vocabulary level (e.g. what gathers around 'skills').
ArcDo connections stay among neighbors, or reach far?Documents are placed in a single row and connections drawn as arcs. A low arc = within the same topic, a high arc = a bridge that jumps across topics.
MatrixWhich blocks are dense and where are the gaps?Connections as dots on a document × document grid. Sorted in System order, so diagonal blocks = internal cohesion, dots outside the blocks = cross connections, and empty areas = knowledge not yet connected.

The graph you can spread out and touch — Graph Studio

Where the nine views above "bake" a representation, Graph Studio spreads the same data out with physics so you can handle it directly. A force-directed layout clusters documents and shared concepts; grab a node and it wobbles like a water drop, pulling its neighbours along. Click a node and only its neighbours wake (focus + context) while a card shows its summary and relations. Search spotlights a node, and a settings panel exposes parameters — repulsion, springs, which concept nodes to show — for you to tune.

Create mode is an arrows.app-style teaching surface: sketch your own knowledge graph on a blank canvas — double-click for a node, drag from a node's rim to draw a relation, reusing this wiki's five relation types (prerequisite · implements · example-of · evidence-for · supersedes). A "copy to Create mode" button on any explore card lets you tear off a piece of the real graph to start from. What you draw is auto-saved in the browser and can be exported as JSON.

Hubs and Bridges — How to Find the Center of the Graph

Whatever the view, there are two entry points for analysis:

  • Hub — the document other documents refer to most. The current number one is Anatomy and Effects of a Harness (referenced 11 times), followed by LLM Wiki Overview and the vault system at 8 each. When getting to grips with a topic for the first time, reading that cluster's hub first is the fastest route.
  • Bridge — a concept that appears across multiple Systems. 'Skills' is the largest bridge, spanning 7 Systems, with 'slash commands' and 'subagents' each linking 5 Systems. Following bridge concepts reveals the points where topics actually meet.

Hubs, bridges, and per-System aggregates are shown as tables on the knowledge map, recalculated live whenever a document is added. In short — the knowledge map is "the summarized table", the seven views are "visualizations of the same data" — and this document series explains the principles by which that data is made (previous part) and the way it is consumed (next part).
