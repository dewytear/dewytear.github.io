Quick Reference Card

A cheat sheet that groups the commands you use often by situation. Handy for finding something quickly while working.

Getting started

  • /deepinit — document the project structure
  • /deep-interview — clarify requirements
  • /omc-doctor — diagnose the installation

Planning

  • /plan — draw up a plan, then approve it (omc-plan)
  • ralplan: — planning based on expert consensus

Execution (in order of intensity)

  • autopilot: — autonomous execution (planning to verification)
  • ralph: — repeat until done
  • ulw — maximum parallel execution
  • team N:agent — team collaboration with N agents

Analysis & review

  • deep-analyze — debugging · root-cause analysis
  • review code — comprehensive code review
  • security review — check for security vulnerabilities
  • fix build — fix build · type errors
  • tdd: — test-driven development

Multi-AI

  • /omc-teams N:ai — use Codex · Gemini in parallel
  • /ccg — analysis by 3 models at once

Utilities

  • /cancel — cancel the current mode
  • /cancel --force — reset everything
  • /trace — evidence-based root-cause tracking
  • skillify — extract · reuse patterns (formerly learner)
  • /hud setup — install the status line (HUD)
At a glance Mode intensity: conversation < plan < autopilot < ralph < team ralph · model cost: haiku < sonnet < opus
