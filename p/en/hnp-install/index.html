Installation and Setup

The harness is distributed in the form of a Claude Code plugin. Once you register the marketplace and install it, you can use the /harness command.

What you need first Claude Code must be installed (see Getting Started). In the terminal, move to the project folder you will work in, run claude, and then enter the slash commands below.

Installation in 3 steps

Method 1 — two command lines (recommended)

# 1) Add the harness marketplace
/plugin marketplace add lev-factory/harness
# 2) Install the harness plugin
/plugin install harness

When the install screen appears, install with User scope (used across my whole account). If you want to use it only in a specific project, choose project scope.

Method 2 — from the /plugin screen

  1. Enter /plugin → move to the Marketplace tab with the right arrow key.
  2. Enter lev-factory/harness in Add Marketplace → Enter.
  3. Select harness from the list → Enter on the install screen → install with User scope.

After installing — reload and verify

# Apply the plugin to the current session
/reload
# If the following autocompletes/runs, the install succeeded
/harness

If autocomplete pops up when you type /harness, you are ready. Now move on to First harness run.

Caution — check the marketplace address The lev-factory/harness above is an example value mentioned in the lecture. For an actual install, check the publisher's GitHub repository path and enter that (search term: "하네스 100"). If the install does not work, try alternating between the command approach ↔ the /plugin screen approach.
Tip for in-house environments In an in-house network or proxy environment, GitHub access may be restricted. If adding the marketplace fails, first check the network/proxy policy and Git access permissions. The plugin must be installed separately on each machine (agent definitions can be shared via Git, but the plugin itself is a personal install).
