Progressive Loading (the Core Principle of Skills)

The most essential principle behind skills is progressive loading (progressive disclosure). Rather than putting the whole skill into the context, only the metadata is loaded up front and the rest is pulled out when it is needed.

The library book cover analogy

Only the metadata (name + description, 3 to 4 lines, about 100 tokens per skill) of a registered skill goes into the context. It is like a library where the books are lined up on the shelves and you only skim the covers (title and short description), pulling one out to read when you need it. The metadata is so small that even more than 100 of them barely take up any context. (In contrast to JSON tools, whose full schema occupies the context up front so that the burden grows as their number rises — which is why Claude Code lazy-loads MCP tool schemas too.)

Three-level loading

The higher up, the more it is always loaded; the lower down, the more it is only when needed — the moment of loading gets later at each level.
LevelContentWhen it loads
1Metadata (the name and description in SKILL.md)Always loaded (about 100 tokens per skill)
2Instructions (the SKILL.md body, usage in markdown)When that skill is invoked
3Resources · scripts · templates (bundled files)Only when needed (scripts are only executed, never loaded)

Bundled files are not mandatory. If words (markdown) alone are enough you can do without files, and if you need an executable script or a template you include one. The more files there are, the more deterministic the result you get. For reference, the official guide recommends keeping the SKILL.md body under 5K tokens and splitting long content out into bundled files.

The manual analogy (flat-pack products · the Matrix helicopter) When you buy a flat-pack product online you skip the manual and assemble it from the photo of the finished item, and only the moment a screw is left out do you pull the manual out. A skill's instructions are likewise pulled out exactly when it fires and left alone the rest of the time. It feels like the scene in the film The Matrix where they load a manual in an instant in front of a helicopter and fly it.
A tip for checking Typing /context in Claude Code shows what percentage the system prompt, custom tools, skills, and so on each take up. You can confirm that even a large number of installed skills uses barely any tokens.
