Install & Start

The fastest way to get started is the native installer — a single command with no dependencies, and it keeps Claude Code updated automatically.

  • macOS / Linux / WSL: curl -fsSL https://claude.ai/install.sh | bash
  • Windows (PowerShell): irm https://claude.ai/install.ps1 | iex
  • Go to your project: cd your-project
  • Launch it: claude
Homebrew (brew install --cask claude-code) and WinGet are also supported. Installing with npm (npm install -g @anthropic-ai/claude-code, requires Node.js 22 or newer) still works and installs the same native binary. On first launch, Claude Code walks you through authentication — you can log in with a Claude account (Pro/Max plan) or an Anthropic API key. After that, just describe what you want in plain language, for example: "explain the auth flow" or "add a dark mode toggle and run the tests". A few handy startup flags:
  • claude — start an interactive session
  • claude "your prompt" — run a one-off task
  • claude -c — continue the most recent conversation
  • claude --help — list all options
