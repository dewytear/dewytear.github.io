Extracting a design system

When building a web service, developers usually receive a design system made by a designer and build screens on top of it. With Claude Code you can run this process in reverse — pull just the design elements out of a site that already exists and turn them into a design system.

Requesting the extraction

Extract the design elements of this finished site
and build a separate design system from them.

What gets captured

It pulls only the design elements of the current site and defines them in a single document.

  • Color palette
  • Text (typography) styles
  • Components — button styles, layout styles
  • Animation effects

Why build one

Once you have a design system, you can keep stamping out future sites with the same design. It keeps the tone consistent when you develop an internal system or build a second or third site, and it is easy to hand over and share with colleagues.

Next step You can reuse a design system built this way as it is, but if you plan to "keep using it from now on," it is more convenient to turn it into a Skill. (Covered in the next document.)
