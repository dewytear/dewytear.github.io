Three Core Actions — Ingest · Query · Lint

These are the three important actions of the LLM wiki. (A concept put forward by Karpathy.)

The three actions loop, and queries grow stronger step by step from BM25 → vector → hypothesis check.

1) Ingest — digest and absorb

This is the work of splitting a single article or concept into chunks and turning it into cards that both AI and people find easy to read. Hand over raw material and source-based wiki cards are generated.

/ingest        # raw sources into wiki cards

2) Query — retrieving and using

Merely piling things up is useless, so you retrieve them with queries. An ordinary agent searches only with regular expressions (word frequency and matching), but here three kinds of search are used in stages through the QMD (markdown query) MCP.

MethodWhen
BM25 (lexicon)When the user states an explicit word — searching by high-frequency words.
Vector searchWhen it is vague — it brings in similar concepts too ("I want to drink water" → water glass).
Hypothesis check (hypothetical)When the user's level is below the level of the knowledge — the LLM reinterprets the question, makes keywords, and searches again.

Each step further along takes more time. If you know the file exactly, giving its address directly is fastest. Results are organized in the query folder, and they are kept source-based so you can pull them out again knowing what purpose the document was made for.

3) Lint — maintenance

This is maintenance work. On a new ingest, if an existing note (concept A, say) is related to a new note (A′) and has gone stale, it gets updated along with it. Run overall maintenance with /lint to keep things current enough to cite at any time. (The audit audit and verify verify skills come along too.)

Summary Ingest (raw material → cards) · Query (retrieving with BM25, vectors, and hypothesis checking) · Lint (staying current) — these three axes keep a living knowledge base running.
