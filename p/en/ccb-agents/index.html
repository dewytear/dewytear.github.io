Building an Agent

An agent is a specialist worker assigned to a specific role. Creating one is as easy as creating a skill — all you need is the idea, and the AI writes the rest. Here we build a paper analysis agent and use it to analyze a downloaded PDF.

1) Prepare the PDF

# Give it the URL of the paper's detail page
https://arxiv.org/abs/....  Download the PDF file of this paper.

Claude Code finds the PDF link on arXiv and downloads it into the current folder. (Reading the PDF is handled by the document-skills we installed earlier.)

2) Create the agent

To scope it to this project only, tell Claude Code to create it under .claude/.

Add an agent that analyzes papers under .claude.

The generated agent carries metadata like the following.

  • Name · description — what this agent does.
  • Tool permissions — reading files, running Bash commands, and so on.
  • Model selection — choose the model each agent uses (for example the best one, opus).
  • Persona · principles — e.g. "an expert in academic paper analysis", "produce a report that conveys the core in five minutes".

The analysis style (abstract-focused / limitation-focused / verification-heavy, and so on) can be refined further with follow-up requests.

3) Check the list · run it

An agent may not be loaded right after you create it. Use /agents to check which agents are available in the current folder, and if it does not show up, /exit and restart.

# Attach the PDF as a reference and analyze it with the agent you made
@paper.pdf  Analyze this paper using the paper-analyzer agent.

4) Parallel analysis — where Claude Code shines

A single orchestrator spawns several agents in parallel, analyzes concurrently, then aggregates the results.

You can analyze all the remaining papers at once as long as you know their links.

Analyze the remaining papers too and save them to files.

Claude Code spawns several agents in parallel (for example 12 papers across 5–6 agents) and analyzes them at the same time. This is something a web chat cannot do. You can also turn the analysis results into detail pages for the paper showcase site you built earlier and link them up.

Another reason to use agents — saving context An agent uses a separate context window from the main session. If you hand heavy analysis to an agent and take back only the result, you barely consume the main session's context, so quality holds up far longer. (See the next document.)
