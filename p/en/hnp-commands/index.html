Commands · Quick Reference

The commands, controls, and settings you look up most often while using the harness, gathered in one place.

Core commands

CommandWhat it does
/plugin marketplace add <repo>Registers the harness marketplace (e.g. lev-factory/harness)
/plugin install harnessInstalls the Harness plugin
/reloadApplies the installed plugin to the current session
/harness <intent>Gives an intent and runs the harness (starts forming the team)
ProceedApproves execution after reviewing the proposed team
/agentsChecks the list of created agents
/exitEnds the session (to re-enter when agents are not showing)

Controls · shortcuts

ControlWhat it does
TabAutocompletes after typing /harness
Shift + arrow keysPeeks into the work of each running agent
Shift + TabSwitches mode (auto / accept / plan)
A new terminal windowRuns another harness at the same time (parallel work)

Cheat sheet by situation

SituationDo this
First install/plugin marketplace add … → /plugin install harness → /reload → check /harness
First run/harness + the intent "I want to ~" → review the team → Proceed
Watching progressCheck the agents with Shift + arrow keys
Strengthening verification/harness Modify the QA agent to cross-verify with Codex CLI
Modifying the team/harness Modify <agent> to also verify/handle <condition>
Agents not showingRe-enter after /exit → check /agents
Intent sentence template (copy and use) /harness I want to proceed with a client customization in ERP <module> that does <what>. Please include impact analysis of the standard source and regression testing as well.
For the various scenarios, you only need to swap <module> and <what> in this template.
