Agents · Skills

The core of OMC is delegation. The main Claude takes the conductor role and splits the work among specialist agents with fixed roles. Each agent is automatically assigned a model matching the difficulty of the task (a high-performance model for design and analysis, a lightweight model for simple lookups), so it is more accurate and faster than having one person handle everything.

Agents fall broadly into four groups by role. Below are the main agents in each group and what each of them does.

The main Claude, as the conductor, splits the work among specialist agent groups with fixed roles.

Exploration · analysis

  • explore — skims the codebase and finds the files and structures relevant to the task.
  • analyst — analyzes code or requirements and lays out the essentials and the points at issue.
  • architect — sets the overall structure and design direction, and verifies that the result matches the design.
  • planner — breaks the work into executable steps and builds a plan.
  • critic — critically reviews a plan or a result to find missing parts and risks.
  • tracer — traces the cause of a bug or failure by following the code flow.

Implementation · fixing

  • executor — writes and modifies the actual code according to the plan. It is divided into lightweight, standard, and high-performance tiers depending on the difficulty of the task.
  • debugger — finds the cause of a bug and fixes it.
  • code-simplifier — tidies up tangled, complicated code into something simpler and easier to read (refactoring).

Verification · quality

  • qa-tester — tests whether a feature works as intended and gathers evidence of completion.
  • test-engineer — writes and configures automated test code.
  • code-reviewer — reviews code quality and style.
  • security-reviewer — checks for security vulnerabilities.

Documentation · design · data

  • writer — writes documents and explanatory text.
  • document-specialist — finds, checks, and organizes external library and API documentation.
  • designer — handles screen UI/UX design.
  • vision — analyzes images such as screen captures or diagrams.
  • scientist — analyzes data.
  • git-master — handles Git work such as branches, commits, and merges.
In one line You do not need to pick agents yourself. Modes like autopilot grasp the intent of the work and place the needed agents for you, so normally you only have to say "what to do".

skillify — turning repetitive work into a skill

/oh-my-claudecode:skillify is the command that extracts work patterns that were effective in one session into reusable skills. Organize a flow you repeat often just once, and you can call it up right away in your next task. The former name learner is a deprecated (support to be discontinued) compatibility alias, so use skillify in new documents and training.

# Extract patterns that were effective in the session into reusable skills
/oh-my-claudecode:skillify
