내 서버에서 도는 Claude Code — 셀프호스팅 공개 베타와 8월의 릴리스들

세 줄 요약

  • Claude Code의 셀프호스팅 환경(에이전트 세션을 Anthropic 클라우드가 아니라 내 조직의 인프라에서 돌리는 기능)이 2026년 8월 6일 공개 베타로 열렸다 — Team·Enterprise 플랜, 명령 하나(claude self-hosted-runner)로 내 머신이 실행층이 된다.
  • 같은 주에 GitLab 머지 리퀘스트 지원(--worktree가 MR URL을 받음)과 auto-continue(사용량 한도에 막힌 세션을 창이 리셋되면 자동 재개, 8월 14일)가 따라붙었다.
  • 셋의 결이 같다 — 실행 위치·대상 플랫폼·시간의 통제를 전부 조직 쪽으로 넘긴다. 승인 판정을 규칙으로 옮긴 auto 모드 기본값의 다음 수순이다.

세션이 조직의 경계 안으로 들어왔다

지금까지 Claude Code의 원격 세션은 Anthropic이 관리하는 격리 컨테이너에서 돌았다. 코드는 세션 시작 때 새로 클론되고, 끝나면 컨테이너가 회수된다 — 편하지만, 데이터가 조직 밖의 컴퓨터를 거친다는 사실 자체가 금융·의료·방산처럼 데이터 상주(데이터를 특정 위치 밖으로 내보내지 않는 요건)나 망 분리 규제가 있는 조직에는 도입 불가 사유였다.

8월 6일 공개 베타로 열린 셀프호스팅 환경은 이 경계를 옮긴다. Claude Code v2.1.224(8월 7일)에 들어온 claude self-hosted-runner 한 명령으로 내 머신이나 컨테이너가 세션의 실행층이 되고, 에이전트는 내부망의 서비스·툴체인·보안 통제 옆에서 일한다. 러너 운용은 두 모드다.

  • 고정(fixed) — 러너를 정해진 수만큼 상시 띄워 두고 세션을 분배.
  • 온디맨드(on-demand) — 대기 중인 세션을 감시하다가 일이 오면 러너를 띄우고, 끝나면 내린다.

기본값은 꺼짐이고 조직 관리자가 설정에서 켜야 하며, ZDR(Zero Data Retention — 데이터를 아예 저장하지 않는 계약 옵션)을 쓰는 조직은 아직 쓸 수 없다. 요컨대 "누구나 켜는 기능"이 아니라 컴플라이언스 요건 때문에 도입이 막혀 있던 조직을 위한 통로다.

같은 주의 나머지 — GitLab MR, auto-continue, Compliance API

GitLab 머지 리퀘스트 지원. claude --worktree가 GitHub PR뿐 아니라 GitLab MR URL을 받게 됐고, 에이전트 목록 화면에서 MR이 !N으로 표시된다. 플랫폼 판별은 git remote와 API 탐지로 하기 때문에 GitLab.com만이 아니라 자가 호스팅 GitLab 인스턴스도 잡는다 — 사내 GitLab을 쓰는 조직(이 위키의 AI 개발 지식 플랫폼 제안이 전제하는 바로 그 환경)에 직접 닿는 변화다.

auto-continue. 8월 14일 데스크톱 앱에 들어온 체크박스 하나다. 사용량 한도에 걸려 멈춘 세션을, 한도 창이 리셋되는 순간 자동으로 이어서 돌린다. 한도 자체(5시간 창·주간 한도)는 그대로다 — 바뀐 것은 리셋 뒤에 사람이 돌아와 다시 시키던 일이 자동이 됐다는 점뿐이다. 긴 자율 작업을 밤새 걸어 두는 사용에서 체감이 크다.

Compliance API 확장. 보안 팀이 감사·전자증거개시(eDiscovery)용으로 세션 내용과 메타데이터를 통합 조회하는 API가 Cowork와 Claude Code의 데스크톱·웹·모바일·CLI 전 표면으로 넓어졌다(Enterprise 베타).

왜 한 흐름인가

이번 주 릴리스들은 겉보기에 잡다하지만 방향이 하나다. auto 모드 기본값이 "무엇을 허용할지"의 판정을 매번 묻는 대화에서 미리 적어 둔 규칙으로 옮겼다면, 이번 주는 "어디서 돌지"(셀프호스팅), "무엇을 대상으로"(자가 호스팅 GitLab), "언제까지"(한도 창과 자동 재개)를 조직이 정하는 값으로 옮겼다. 에이전트가 강해질수록 통제 지점은 대화가 아니라 환경과 규칙으로 이동한다 — 이 위키가 Tip 고급 편에서 권한 편집과 검증 분리를 다루는 이유와 같은 줄기다.

이 위키에서 고친 것

  • Tip 고급 편 — 21번(워크트리)에 GitLab MR 지원을, 23번(예약·루틴)에 auto-continue를 반영했다.
  • 하네스 활용과 확장 — 도구 확장 절에 셀프호스팅 러너를 추가했다.

사실검증 노트

셀프호스팅 공개 베타(8/6)·플랜 범위·러너 2모드·기본 비활성·ZDR 제외는 Anthropic 공식 블로그(Run Claude Code sessions on your own compute)와 공식 문서(Self-hosted environments) 기준. v2.1.224의 claude self-hosted-runner 도입(8/7)은 nextdev 릴리스 분석과 Classmethod의 EC2 실습기로 교차 확인. auto-continue(8/14)는 Anthropic 개발자 채널 공지 기반이며 한도 자체는 불변이라는 해석은 explainx 정리와 일치. GitLab MR 지원의 세부(--worktree·!N 표기·자가 호스팅 판별)는 공개 릴리스 노트 요약 기준으로, 버전 단위 확정은 위 공식 문서를 우선한다.
