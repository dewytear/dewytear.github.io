하네스 엔지니어링 — 개요와 복습

이 자료는 "하네스 엔지니어링 / 황민호" 실습 강의를 영상 순서대로 파트별로 정리한 것입니다. 지난 Claude Code 기초 강의에 이어, 이번 주제는 하네스 엔지니어링(Harness Engineering) 입니다.

사람은 의도만 주고, 하네스가 짜 준 에이전트 팀이 스스로 오래 일해 검증된 결과물을 냅니다.
먼저 알아둘 점 하네스는 사람의 개입 없이 오랫동안 많은 일을 하는 구조라서, 실습처럼 느껴지지 않을 수 있습니다. 대신 "한 번 시켰더니 AI가 오래 작업해 좋은 결과물을 만들더라"를 직접 보는 시간이 됩니다.

지난 기초 강의 복습

  • AI 도구는 웹뿐 아니라 데스크톱 앱, 터미널(Claude Code) 형태가 있다.
  • 터미널 기본기 — pwd · cd · mkdir, 그리고 폴더에서 claude 실행.
  • 리서치 → 파일 → 웹사이트 제작, 디자인 시스템 스킬로 디자인 입히기.
  • 에이전트를 만들어 논문 분석, 여러 에이전트로 병렬 처리.
  • AI를 다룰 때 컨텍스트의 중요성과 토큰 사용량 관리.

강사 소개 — FDE

강사는 카카오의 FDE(Forward Deployed Engineer, 전방 배치 엔지니어) 조직 소속입니다. FDE는 팔란티어를 시작으로 OpenAI·Anthropic에서도 많이 채용하는 직군으로, 클라이언트(또는 내부 조직) 현장에 배치되어 필요한 시스템을 AI로 빠르게 구축하고 AX(AI 전환) 교육·정착을 돕습니다.
