Claude Code란 무엇인가

Claude Code는 내 로컬 환경(내 PC)에서 돌아가는 AI 에이전트라고 생각하면 됩니다. 웹 채팅과 달리 내 컴퓨터의 파일을 직접 읽고 수정하고, 명령을 실행하며 일을 처리합니다. 작업은 프로젝트마다 폴더 하나를 만들고 그 폴더 안에서 진행합니다. Windows에서는 보통 PowerShell 터미널에서 실행합니다.

기존 서비스와의 차이

형태특징자유도
웹 브라우저(Claude·ChatGPT·Gemini)브라우저 안의 제약된 환경에서 AI 사용. 파일을 일일이 업로드해야 함가장 제한적
Claude 데스크톱 앱로컬에서 동작하지만 터미널 대비 제약이 있음중간
Claude Code (터미널)실행한 폴더의 파일에 직접 접근. 내가 원하는 대로 자유롭게 작업가장 자유로움

터미널 환경에 조금만 익숙해지면, 평소 AI 채팅을 쓰듯이 훨씬 자유롭게 사용할 수 있습니다.

시연 — 회의록 세 개를 한 보고서로

파일 목록을 알려 주지 않아도 스스로 탐색·읽기·분석해 보고서를 만듭니다.

회의록 파일 3개가 든 폴더에서 Claude Code를 실행하고 이렇게 요청합니다.

이 회의록 세 개를 합쳐서 한 개의 보고서로 요약해줘. 한국어로.

여기서 핵심은 어떤 파일이 있는지 알려 주지 않았다는 점입니다. 웹 채팅이라면 파일을 직접 업로드해야 하지만, Claude Code는

  • 현재 폴더에 어떤 파일이 있는지 먼저 탐색(search) 하고,
  • 그 파일들을 하나하나 읽어 들이며,
  • 내용을 분석한 뒤 결과(보고서)를 만들어 줍니다.

즉, "실행한 위치의 폴더"가 곧 작업 공간이 되고, 그 안의 파일을 스스로 다룹니다.

기억할 점 Claude Code는 claude 를 실행한 그 폴더 전체에 접근합니다. 그래서 프로젝트별로 폴더를 나누고, 작업할 폴더 안에서 실행하는 습관이 중요합니다.
