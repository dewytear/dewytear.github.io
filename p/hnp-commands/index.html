명령어 · 빠른 참조

하네스를 쓰며 자주 찾게 되는 명령·조작·설정을 한자리에 모았습니다.

핵심 명령어

명령하는 일
/plugin marketplace add <repo>하네스 마켓플레이스 등록 (예: lev-factory/harness)
/plugin install harness하네스 플러그인 설치
/reload설치한 플러그인을 현재 세션에 반영
/harness <의도>의도를 주고 하네스 실행 (팀 구성 시작)
진행시켜제안된 팀을 검토한 뒤 실행 승인
/agents생성된 에이전트 목록 확인
/exit세션 종료(에이전트 안 보일 때 재진입용)

조작 · 단축키

조작하는 일
Tab/harness 입력 후 자동완성
Shift + 방향키실행 중인 각 에이전트의 작업 들여다보기
Shift + Tab모드 전환 (auto / accept / plan)
새 터미널 창또 다른 하네스를 동시에 실행(병렬 작업)

설정 · 산출물 위치

항목내용
에이전트 팀 켜기~/.claude/settings.json 의 env 에 "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
산출물 폴더_workspace — 분석·설계·구현·QA 리포트·근거 출처
에이전트·스킬 정의.claude 아래 (Git으로 공유 가능)
구성 변경 이력CLAUDE.md

상황별 치트시트

상황이렇게
처음 설치/plugin marketplace add … → /plugin install harness → /reload → /harness 확인
첫 실행/harness + "~하고자 합니다" 의도 → 팀 검토 → 진행시켜
진행 관찰Shift + 방향키 로 에이전트 확인
검증 강화/harness QA 에이전트는 Codex CLI 로 교차 검증하도록 수정
팀 수정/harness <에이전트> 는 <조건> 도 검증/처리하도록 수정
에이전트 안 보임/exit 후 재진입 → /agents 확인
의도 문장 템플릿 (복사해서 쓰기) /harness ERP <모듈> 에서 <무엇을> 하는 고객사 커스터마이징을 진행하고자 합니다. 표준 소스 영향도 분석과 회귀 테스트까지 포함해 주세요.
다양한 시나리오에 이 템플릿의 <모듈>·<무엇을> 만 바꿔 넣으면 됩니다.
